# What Is This Called? — UI

화면 속 그게 뭔지 알려주는 프론트엔드 UI/UX 도감입니다.

백엔드 개발자가 프론트엔드 화면에서 막히는 건 대개 **이름**입니다. 그래서 이름순 색인은 맨 뒤로 보내고, 입구에 **화면 지도**를 두었습니다. 지도에서 부품을 누르면 이름이 나옵니다.

👉 **<https://hyeongminpark2.github.io/what-is-this-called-ui/>**

## 항목 카드의 열 칸

모든 항목을 같은 열 칸 틀로 씁니다. 틀이 같아야 어느 항목에서든 같은 자리를 찾을 수 있습니다.

| 칸 | 내용 |
|---|---|
| ① 실물 | 눌러 볼 수 있는 예시. **폭 토글**로 390 / 768 / 넓게 |
| ② 이름 | 한국어 이름, 영어 이름, 같이 쓰는 말, 자주 잘못 부르는 이름 |
| ③ 가르는 기준 | 형제 부품들과 비교하는 축 |
| ④ 상태 | 기본, 열림, 처리 중, 에러 같은 상태를 나란히 (부에 따라 '단', '층', '쓰임') |
| ⑤ 해부도 | 부분마다 번호와 이름 |
| ⑥ 쓸 때 / 안 쓸 때 | 쓰는 경우, 쓰지 않는 경우, 대신 쓸 것 |
| ⑦ 자주 보는 모습 | 구조만 따라 그린 재현 그림 |
| ⑧ 마크업과 키보드 | 최소 마크업과 키마다 일어나야 하는 일 (부에 따라 지킬 규칙) |
| ⑨ 서버 쪽으로 치면 | 백엔드 개념과 짝지어 본 설명 |
| ⑩ 플랫폼 | 웹, iOS(HIG), 안드로이드(Material 3)에서 부르는 이름 |

## 화면 지도

빈 상자에 이름만 적으면 **생김새**를 알 수 없습니다. 그래서 진짜 앱처럼 채운 화면에 번호를 붙였습니다. 서비스 종류마다 부품이 달라 여덟 장을 그렸고, 장끼리 겹치는 이름은 거의 없습니다.

| 화면 | 여기서만 보는 것 |
|---|---|
| PC · 관리 도구 | 사이드바, 데이터 테이블, 필터 칩, 스탯 타일, 페이지네이션 |
| PC · 쇼핑몰 | 메가 메뉴, 히어로, 상품 카드, 별점, 리본, 쿠키 배너 |
| PC · OTT | 빌보드, 로우, 포스터 타일, 스크러버, 자막 버튼, 호버 프리뷰 카드 |
| PC · 기업 소개 | 스크롤 진행 표시줄, 패럴랙스, 스크롤 등장, 스티키 섹션, 아코디언 |
| PC · 설정 | 텍스트 필드, 라벨, 헬퍼 텍스트, 에러 상태, 스위치, 라디오, 슬라이더, 위험 구역 |
| PC · 메신저 | 말풍선과 꼬리, 읽음 표시, 타이핑 인디케이터, 반응 이모지, 답장 인용, 스레드, 멘션 자동완성 |
| PC · 글쓰기 도구 | 트리뷰, 툴바, 선택 영역, 플로팅 툴바, 댓글 핀, 상태 표시줄 |
| 폰 | 세이프 에어리어, FAB, 바텀시트, 바텀 탭바, 홈 인디케이터 |

OTT 화면만 어둡게 그려 다크 UI도 함께 보입니다.

- **부품을 짚으면 마우스 옆에 이름이 뜹니다.** 지도가 길어 아래 목록이 화면 밖에 있을 때가 많기 때문입니다.
- **목록의 이름을 짚으면 부품까지 지시선을 긋습니다.** 선은 짚은 것 하나에만 긋습니다. 겹친 부품은 안쪽을 고릅니다.
- 지시선 좌표는 JS가 매번 계산합니다. 손으로 적으면 폭이 바뀔 때 어긋납니다.
- 번호 배지는 부품을 덮지 않게 바깥으로 뺍니다. 덮는 넓이는 검사 스크립트가 잽니다.
- 좁은 화면에서는 지시선 없이 번호로만 잇고, PC 지도는 옆으로 밀어 봅니다.

## 구조

```
index.html          입구: 화면 지도, 혼동 쌍, 목차
items/*.html        항목 카드 181장 (tools/gen 으로 찍는다)
demos/*.html        각 항목 ① 칸에 들어가는 실물 예시 181장
appendix.html       부록 색인 (tools/appendix.js 로 항목 카드에서 다시 만든다)
tools/gen/          항목 카드 생성기 (tools/README.md 참고)
tools/check.js      브라우저 검사 (tools/README.md 참고)
assets/base.css     디자인 토큰과 도감 바깥 틀
assets/card.css     항목 카드 열 칸 틀
assets/demo.css     예시 안에서 쓰는 UI 부품
assets/map.css      화면 지도 속 가짜 앱 화면과 번호
assets/map.js       지시선 긋기
assets/card.js      폭 토글
```

빌드 도구 없이 `index.html`을 그냥 열면 됩니다.

## 원칙

- **상태까지 보여 줍니다.** 그림 한 장으로는 눌렀을 때, 비활성일 때의 모습을 알 수 없습니다.
- **돌아가는 HTML로 보여 줍니다.** 호버, 포커스, 애니메이션은 캡처로 전해지지 않습니다.
- **PC와 폰을 한 항목 안에서 비교합니다.** 폭 토글로 좁은 화면의 모습을 바로 봅니다.
- **다른 제품의 화면 캡처를 쓰지 않습니다.** 그림은 모두 색과 로고를 뺀 재현입니다.
