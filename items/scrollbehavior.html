Scroll behavior

굴림 자체를 다루는 값들. 칸 단위로 멎게 하거나 바깥까지 안 밀리게 하는 일이 CSS 한 줄로 됩니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

스냅을 켜면 굴림이 칸 단위로 멎습니다 — 세로 상자와 가로 줄 둘 다에서요.
끝에서 바깥까지 밀리기를 끄면 안쪽을 끝까지 굴려도 바깥이 안 따라 움직입니다 — 모달 안에서 특히 쓸모 있습니다.

2 이름부르는 말이 여러 개다

한국어스크롤 동작, 스냅, 스크롤 체이닝, 부드러운 굴림
영어scroll snap, overscroll behavior, scroll chaining, smooth scroll
같이 쓰는 말칸 단위로 멎게 하는 것이 스크롤 스냅, 안쪽을 끝까지 굴렸을 때 바깥이 따라 움직이는 것이 스크롤 체이닝입니다. 끝에서 더 당기면 튕기는 효과가 바운스·러버밴딩이고 overscroll-behavior: none으로 막습니다. 앵커로 뛸 때 붙박이 머리말에 가리지 않게 띄우는 값이 scroll-margin입니다.
자주 잘못 부름스크롤 연동 — 스크롤 연동은 굴림에 무언가를 매다는 일입니다. 이쪽은 굴림 자체입니다.
무한 스크롤 — 무한 스크롤은 더 받아오는 일입니다.
스크롤 가로채기 — 굴린 양과 다르게 움직이게 하는 것으로, 여기 있는 것들과 다릅니다.

한 줄로 — 굴림은 사용자 것입니다. 멎는 자리를 정하거나 새지 않게 막을 수는 있어도, 양을 바꾸면 안 됩니다.

4 네 가지 값무엇을 다루나

5 해부도부분 이름이 제일 안 알려진 지식

scroll-snap-type — 칸 단위로 멎게 한다
scroll-snap-align — 어디에 맞춰 멎나 (start · center)
overscroll-behavior: contain — 바깥까지 안 밀린다
scroll-behavior: smooth — 뛸 때 부드럽게
scroll-margin — 붙박이 머리말에 가리지 않게
굴림을 가로채지 않는다 — 매달기만 한다
  1. 스냅 scroll-snap-type칸 단위로 멎는다. 축과 세기를 적는다
  2. 맞춤 scroll-snap-align어디에 맞춰 멎나 — start · center
  3. 체이닝 overscroll-behaviorcontain이면 바깥이 안 밀린다
  4. 부드럽게 scroll-behavior뛸 때만 쓴다. 굴릴 때는 안 건드린다
  5. scroll-margin 가리지 않게붙박이 머리말만큼 띄운다
  6. 가로채기 하지 않는다굴린 양을 바꾸면 고장 난 느낌이 난다

scroll-margin은 작지만 자주 빠지는 값입니다. 붙박이 머리말이 있는 화면에서 앵커 링크로 뛰면 목표가 머리말 뒤에 숨어 버립니다 — 눌렀는데 아무 일도 안 일어난 것처럼 보이죠. 목표 요소에 scroll-margin-top을 머리말 높이만큼 주면 끝나고, 이건 키보드로 건너뛰기를 쓰는 사람에게도 똑같이 적용됩니다 — 포커스가 가려지면 어디에 있는지 알 수 없습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 캐러셀·사진첩에 스냅
  • 모달·드로어 안에 overscroll-behavior: contain
  • 붙박이 머리말이 있으면 scroll-margin-top

이럴 때는 안 쓴다

  • 긴 글에 스냅 — 읽다 멎어 답답하다
  • 굴림 양을 바꾸기 — 고장 난 느낌이 난다
  • scroll-behavior: smooth를 전역으로 — 줄이기에서 꺼야 한다
  • overscroll-behavior: none을 본문에 — 당겨서 새로고침이 막힌다

대신 이걸 — 굴림에 무언가를 매다는 것은 스크롤 연동, 붙는 머리말은 스티키, 더 받아오면 무한 스크롤.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 키보드이 굴림의 계약서

스냅은 두 줄, 체이닝은 한 줄입니다.

/* 가로 캐러셀 */
.carousel { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; }
.carousel > * { flex: none; scroll-snap-align: center; }

/* 모달 안에서 바깥이 밀리지 않게 */
.modal__body { overflow: auto; overscroll-behavior: contain; }

/* 붙박이 머리말에 가리지 않게 */
h2 { scroll-margin-top: 64px; }

/* 뛸 때만 부드럽게 — 줄이기에서는 끈다 */
html { scroll-behavior: smooth; }
@media (prefers-reduced-motion: reduce) { html { scroll-behavior: auto; } }
키일어나야 하는 일
PageDown·Home스냅을 걸어도 키보드 굴림은 그대로 돌아야 한다
가로 캐러셀의 Tab칸 안에 누를 것이 있으면 초점이 가며 저절로 굴러간다
scroll-margin초점이 머리말에 가리는 것도 함께 막는다
scroll-behavior: smooth모션 줄이기에서 auto로 되돌린다
overscroll-behavior: none당겨서 새로고침까지 막는다. 본문에는 쓰지 않는다
mandatory와 proximitymandatory는 늘 붙는다. 칸이 화면보다 크면 못 지나가는 자리가 생길 수 있다

9 서버 쪽으로 치면백엔드 감각으로 번역

스냅과 더 받아오기무한 스크롤과 같이 쓰면 칸이 늘 때마다 멎는 자리가 바뀝니다.
굴린 자리 복원돌아왔을 때 자리를 되살리려면 그린 뒤에 해야 합니다 — 검색 결과 화면.
