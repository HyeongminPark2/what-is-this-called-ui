스크롤 동작

Scroll behavior

스크롤 동작은 스크롤 자체를 다루는 CSS 값들입니다. 스크롤이 칸 단위로 멈추게 하거나 바깥 페이지까지 밀리지 않게 하는 일을 CSS 한 줄로 할 수 있습니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

스냅을 켜면 세로 상자와 가로 줄 모두에서 스크롤이 칸 단위로 멈춥니다.
바깥 페이지도 밀리게 하기를 끄면 안쪽을 끝까지 스크롤해도 바깥 페이지가 따라 움직이지 않는데, 이 설정은 모달 안에서 특히 쓸모가 있습니다.

2 이름같은 것을 부르는 여러 이름

한국어스크롤 동작, 스냅, 스크롤 체이닝, 부드러운 굴림
영어scroll snap, overscroll behavior, scroll chaining, smooth scroll
같이 쓰는 말스크롤이 칸 단위로 멈추게 하는 것은 스크롤 스냅, 안쪽을 끝까지 스크롤했을 때 바깥이 따라 움직이는 것은 스크롤 체이닝이라고 부릅니다. 끝에서 더 당기면 튕기는 효과는 바운스·러버밴딩이라고 하며 overscroll-behavior: none으로 막습니다. 앵커 링크로 이동할 때 목표가 붙박이 머리말에 가리지 않게 띄우는 값은 scroll-margin입니다.
자주 잘못 부르는 이름스크롤 연동 — 스크롤 연동은 스크롤 위치에 따라 다른 무언가를 움직이는 일이고, 스크롤 동작은 스크롤 자체를 다룹니다.
무한 스크롤 — 무한 스크롤은 목록 끝에 닿으면 데이터를 더 받아오는 일입니다.
스크롤 가로채기 — 사용자가 스크롤한 양과 다르게 화면을 움직이는 것으로, 이 항목에서 다루는 값들과는 다릅니다.

스크롤 동작을 한 줄로 정리하면 — 스크롤은 사용자가 조작하는 것입니다. 멈추는 자리를 정하거나 바깥으로 이어지지 않게 막을 수는 있어도, 스크롤되는 양을 바꾸면 안 됩니다.

4 스크롤을 다루는 값값마다 달라지는 스크롤의 움직임

5 해부도부분마다 붙은 이름

scroll-snap-type 칸 단위로 멈추게 함
scroll-snap-align 멈출 기준 (start·center)
overscroll-behavior: contain 바깥이 밀리지 않음
scroll-behavior: smooth 이동할 때 부드럽게
scroll-margin 붙박이 머리말에 가리지 않게 띄움
스크롤 양은 두고 멈출 자리만 정함
  1. 스냅 scroll-snap-type스크롤이 칸 단위로 멈춥니다. 축과 세기를 함께 적습니다
  2. 맞춤 scroll-snap-align칸의 어디에 맞춰 멈출지 start · center 같은 값으로 정합니다
  3. 체이닝 overscroll-behaviorcontain으로 두면 바깥이 밀리지 않습니다
  4. 부드러운 이동 scroll-behavior앵커나 버튼으로 이동할 때만 적용되고, 사용자가 직접 스크롤할 때는 영향을 주지 않습니다
  5. scroll-margin 가리지 않게 띄우기붙박이 머리말 높이만큼 띄웁니다
  6. 가로채기 쓰지 않음사용자가 스크롤한 양을 바꾸면 화면이 고장 난 것처럼 느껴집니다

scroll-margin은 작은 값이지만 자주 빠뜨립니다. 붙박이 머리말이 있는 화면에서 앵커 링크로 이동하면 목표 요소가 머리말 뒤에 가려져서, 링크를 눌렀는데 아무 일도 일어나지 않은 것처럼 보입니다. 목표 요소에 scroll-margin-top을 머리말 높이만큼 주면 해결됩니다. 이 설정은 키보드로 건너뛰기를 쓰는 사람에게도 똑같이 필요한데, 포커스가 머리말에 가려지면 지금 어디에 있는지 알 수 없기 때문입니다.

6 쓸 때 / 안 쓸 때

스크롤 동작을 따로 정하는 경우

  • 캐러셀이나 사진첩에 스냅을 걸 때
  • 모달·드로어 안의 스크롤이 바깥으로 이어지지 않게 할 때. overscroll-behavior: contain을 씁니다
  • 붙박이 머리말이 있는 화면에서 앵커 링크를 쓸 때. scroll-margin-top을 줍니다

스크롤 동작을 다룰 때 피할 것

  • 긴 글에 스냅을 걸 때. 읽는 도중에 스크롤이 칸 단위로 멈춰서 답답합니다
  • 스크롤되는 양을 바꿀 때. 화면이 고장 난 것처럼 느껴집니다
  • scroll-behavior: smooth를 전역으로 걸 때. 모션 줄이기 설정에서는 꺼야 합니다
  • overscroll-behavior: none을 본문에 걸 때. 당겨서 새로고침이 막힙니다

스크롤 동작 대신 다른 것을 써야 하는 경우 — 스크롤 위치에 따라 다른 요소를 움직이려면 스크롤 연동을, 머리말을 위에 붙여 두려면 스티키를 봅니다. 목록 끝에 닿았을 때 데이터를 더 받아오는 일은 무한 스크롤에서 다룹니다.

7 자주 보는 모습구조만 따라 그린 재현 그림

8 최소 코드와 키보드스크롤 동작을 다룰 때 지킬 것

스냅은 두 줄, 체이닝 막기는 한 줄이면 됩니다.

/* 가로 캐러셀 */
.carousel { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; }
.carousel > * { flex: none; scroll-snap-align: center; }

/* 모달 안에서 바깥이 밀리지 않게 */
.modal__body { overflow: auto; overscroll-behavior: contain; }

/* 붙박이 머리말에 가리지 않게 */
h2 { scroll-margin-top: 64px; }

/* 앵커로 이동할 때만 부드럽게. 모션 줄이기에서는 끈다 */
html { scroll-behavior: smooth; }
@media (prefers-reduced-motion: reduce) { html { scroll-behavior: auto; } }
키와 설정그때 일어나야 하는 일
PageDown·Home스냅을 걸어도 키보드로 하는 스크롤은 그대로 동작해야 합니다
가로 캐러셀에서 Tab을 누를 때칸 안에 누를 것이 있으면 초점이 옮겨 갈 때 저절로 스크롤됩니다
scroll-margin을 주었을 때초점이 머리말에 가리는 것도 함께 막습니다
scroll-behavior: smooth를 쓸 때모션 줄이기 설정에서는 auto로 되돌립니다
overscroll-behavior: none을 쓸 때당겨서 새로고침까지 막기 때문에 본문에는 쓰지 않습니다
mandatory와 proximity 중에 고를 때mandatory는 항상 칸에 맞춰 멈추기 때문에, 칸이 화면보다 크면 지나갈 수 없는 자리가 생길 수 있습니다
