여러 줄 입력

Textarea

입력 칸에 줄바꿈이 들어가면 한 줄 칸과는 다른 부품이 됩니다. 글이 길어지면 높이가 변하고, 글자 수 한도를 다뤄야 하고, Enter를 눌렀을 때 하는 일도 달라집니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

'160자짜리 글 붙여넣기'를 눌러 보세요. '아예 못 치게'를 켜 두면 붙여넣은 글이 아무 안내 없이 잘리고, 데모가 잘려 나간 글자 수를 세어 적어 줍니다. 한도를 넘더라도 글은 그대로 두고 빨갛게 알리는 편이 사용자가 고치기 쉽습니다.
내용만큼 늘어나기를 켜면 줄이 늘 때 칸도 함께 커집니다. 반면 메모 칸에 Enter로 보내기를 켜면 Enter가 보내기에 쓰이기 때문에 줄바꿈을 할 수 없게 됩니다. 두 기능은 같은 키를 쓰므로 함께 쓸 수 없습니다.

2 이름같은 것을 부르는 여러 이름

한국어여러 줄 입력, 텍스트 영역, 메모 칸
영어textarea, multi-line input, text area
같이 쓰는 말내용만큼 높이가 늘어나는 것은 오토그로(auto-grow), 모서리를 끌어 크기를 바꾸는 손잡이는 리사이저라고 부릅니다. 굵게나 목록 같은 서식이 들어가면 리치 텍스트 편집기라는 전혀 다른 부품이 됩니다.
자주 잘못 부르는 이름텍스트 필드 — 텍스트 필드는 한 줄만 받는 칸입니다.
에디터 — 굵게나 목록 같은 서식이 들어가면 여러 줄 입력이 아니라 리치 텍스트 편집기입니다.
코드 칸 — 코드를 받는 칸은 들여쓰기와 Tab 키를 다르게 처리해야 해서 따로 만듭니다.

4 상태상태마다 달라지는 모습

5 해부도부분마다 붙은 이름

rows — 처음 보이는 줄 수
내용만큼 늘어나기 — 작은 창에서 안 굴린다
남은 글자 수 — 넘치기 전에 보인다
maxlength — 붙여넣은 글이 소리 없이 잘린다
resize — 세로만 열어 두는 편이 안전하다
Enter 로 보내기와 줄바꿈은 같이 못 쓴다
  1. rows 처음 줄 수처음에는 두세 줄 높이로 시작합니다
  2. 자동 높이 안 굴림칸이 내용만큼 커지므로 작은 창 안에서 굴리지 않아도 됩니다
  3. 글자 수 미리 보임남은 글자 수를 넘치기 전에 보여 줍니다
  4. maxlength 소리 없이 잘림한도를 넘는 글을 자르는데, 붙여넣기에서 특히 문제가 됩니다
  5. resize 세로만가로로 늘리게 두면 칸이 레이아웃을 깨뜨립니다
  6. Enter 둘 중 하나Enter에는 보내기 또는 줄바꿈 중 하나만 맡깁니다

maxlength는 쓰기 쉬워 보이지만 붙여넣기에서 문제가 가장 큽니다. 다른 곳에 길게 써 둔 글을 붙여넣으면 한도까지만 들어가고 나머지는 아무 안내 없이 사라지기 때문에, 사용자는 글이 다 들어간 줄 알고 그대로 보냅니다.
그래서 한도는 입력을 막는 데 쓰지 말고 알리는 데 쓰는 편이 낫습니다. 글이 넘치면 칸을 빨갛게 표시하고 보내기를 막되, 쓴 글은 그대로 둡니다. 그래야 사용자가 전체 글을 보면서 어디를 줄일지 고를 수 있습니다.

6 쓸 때 / 안 쓸 때

여러 줄 입력을 쓰는 경우

  • 남은 글자 수를 미리 보여 주기
  • 한도를 넘어도 치게 두고 보내기만 막기
  • resize: vertical로 크기 조절을 세로만 열어 두기

여러 줄 입력을 쓰지 않는 경우

  • maxlength로 넘친 글을 잘라 버리기
  • 메모 칸에 Enter로 보내기 켜기. 줄바꿈을 할 수 없게 됩니다
  • 높이를 한 줄로 두기. 쓰는 동안 앞에 쓴 내용이 보이지 않습니다
  • 글자 수가 넘쳤다는 사실을 보낸 뒤에 알리기

여러 줄 입력 대신 다른 것을 써야 하는 경우 — 한 줄만 받으면 텍스트 필드, 서식이 들어가면 리치 텍스트 편집기, 검사 규칙은 입력 검증, 칸 안팎의 안내 문구는 자리글과 헬퍼 텍스트.

8 최소 마크업과 키보드구현할 때 지킬 최소 규칙

자동 높이는 CSS field-sizing 한 줄로 만들 수 있고, 이 속성을 지원하지 않는 브라우저에서는 scrollHeight를 재서 높이를 맞춥니다.

<label for="memo">정산 메모</label>
<textarea id="memo" rows="3" aria-describedby="memo-cnt"></textarea>
<p id="memo-cnt" role="status">118자 남음</p>

textarea { resize: vertical; field-sizing: content; max-height: 14em; }

// field-sizing을 못 쓰는 곳에서는 높이를 재서 맞춘다
el.addEventListener('input', () => {
  el.style.height = 'auto';
  el.style.height = Math.min(240, el.scrollHeight) + 'px';
});

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

한도는 서버에도화면에 보이는 한도는 사용자를 돕는 안내이고, 실제로 넘친 글을 막는 일은 서버 검사가 맡아야 합니다.
줄바꿈 보존저장하거나 보여 줄 때 줄바꿈이 사라지면 사용자가 쓴 모양과 달라집니다. 화면에 보여 줄 때는 white-space: pre-wrap이 필요합니다.
글자 수 세는 법이모지나 한글을 코드 단위로 세면 사람이 보는 글자 수와 어긋납니다. 서버와 화면이 같은 방식으로 세야 한도가 맞습니다.
