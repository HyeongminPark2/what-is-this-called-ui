셀렉트

Select · Dropdown

정해진 선택지 하나를 고르는 칸. 평소에는 접혀 있어 자리를 안 먹고, 열어야 선택지가 보입니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

세 칸을 비교해 보세요. 은행처럼 10개 안팎이면 셀렉트가 알맞고, 주기처럼 셋뿐이면 라디오나 세그먼티드가 낫습니다 — 열어 보지 않아도 다 보이니까요. 소재지는 229개라 셀렉트가 무너집니다. 그 지점이 콤보박스로 넘어갈 때입니다.

2 이름부르는 말이 여러 개다

한국어셀렉트, 선택 상자, 드롭다운
영어select, dropdown, picker
같이 쓰는 말선택지 묶음을 옵션 그룹(optgroup), 펼쳐진 목록을 리스트박스, 오른쪽 화살표를 셰브런이라 합니다.
자주 잘못 부름드롭다운 메뉴 — 메뉴는 동작을 고르는 것이고(이름 바꾸기, 삭제), 셀렉트는 값을 고릅니다. 생김새가 닮아 가장 자주 섞입니다.
콤보박스 — 타이핑으로 걸러지면 콤보박스입니다.
스피너 — 안드로이드에서는 셀렉트를 Spinner 라 부릅니다. 웹의 로딩 표시와는 전혀 다른 것입니다.

  1. 라벨 label접혀 있을 때 고른 값만 보이므로 무엇을 고르는 칸인지가 더 중요하다
  2. 셀렉트 상자 select · trigger접힌 상태. 높이는 44px 이상
  3. 고른 값 selected value여기에 보인다. 아직 안 골랐으면 '고르세요' 같은 안내
  4. 셰브런 chevron펼쳐진다는 어포던스. 이게 없으면 그냥 읽기 전용 칸처럼 보인다
  5. 리스트박스 listbox · popup브라우저(또는 OS)가 띄운다. 그래서 모양을 마음대로 못 바꾼다
  6. 옵션 그룹 optgroup선택지를 묶어 준다. 10개가 넘으면 거의 필수다
  7. 현재 항목 selected option지금 값. 열면 여기로 스크롤돼 있어야 한다

펼친 목록은 브라우저나 운영체제가 그립니다. 그래서 폰에서는 휠이나 전체 화면 목록이 뜨고, 모양을 꾸미려고 직접 만들면 그 편의를 전부 잃습니다 — 첫 글자로 건너뛰기, 폰의 큰 목록, 화면 밖으로 안 나가는 위치까지.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 선택지가 5~15개쯤일 때
  • 선택지가 바뀌지 않고 이름이 분명할 때 — 은행, 국가, 통화
  • 자리를 아껴야 할 때 — 폼이 길고 칸이 많을 때

이럴 때는 안 쓴다

  • 선택지가 2~4개 → 라디오나 세그먼티드. 열어 보지 않아도 다 보입니다
  • 수십 개가 넘을 때 → 콤보박스. 타이핑으로 좁혀야 합니다
  • 동작을 고를 때 → 드롭다운 메뉴입니다
  • 모양을 바꾸려고 직접 만들기 — 키보드·폰 목록을 전부 다시 만들어야 합니다

대신 이걸 — 둘셋이면 라디오나 세그먼티드, 많으면 콤보박스, 여럿 고르면 체크박스.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

브라우저가 주는 <select>를 쓰면 키보드 조작과 폰 목록이 전부 공짜입니다. 직접 만들면 그걸 다 다시 만들어야 합니다.

<label for="bank">입금 은행</label>
<select id="bank" name="bank" required>
  <option value="">고르세요</option>
  <optgroup label="시중은행">
    <option>신한</option>
    <option>하나</option>
  </optgroup>
</select>

/* 모양은 테두리까지만 바꾼다. 펼친 목록은 못 바꾼다 */
select { appearance: none; background-image: url(chevron.svg); }
키일어나야 하는 일

9 서버 쪽으로 치면백엔드 감각으로 번역

값과 라벨은 다른 것value는 코드(SHINHAN), 보이는 글자는 사람 말입니다. 보이는 글자를 그대로 보내면 이름이 바뀔 때 데이터가 깨집니다.
빈 값 = 안 고름value=""인 첫 옵션으로 '안 고름'을 나타냅니다. 기본값을 임의로 넣으면 사용자가 안 보고 보낸 값이 들어옵니다.
선택지 출처하드코딩이면 바뀔 때마다 배포해야 합니다. 서버에서 받으면 캐시와 '값은 있는데 목록에 없는' 경우를 다뤄야 합니다.
묶인 셀렉트 = 의존 질의앞 칸이 정해져야 뒤 칸을 가져올 수 있습니다. 앞을 바꾸면 뒤 값을 비워야 합니다 — 안 비우면 말이 안 되는 짝이 저장됩니다.
