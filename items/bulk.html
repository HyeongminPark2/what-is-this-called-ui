일괄 선택

Bulk selection

여러 건을 골라 한꺼번에 처리하는 장치. 사고는 거의 전부 '전체'가 무엇을 뜻하느냐에서 납니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

맨 위 체크박스를 눌러 보세요. 일부만 골랐을 때 반쯤 켜진 모양(indeterminate)이 됩니다 — 체크박스에 상태가 셋이라는 것을 모르면 못 만드는 모양입니다.
전체를 고르면 '이 쪽 5건'과 '조건에 맞는 128건' 중 어느 쪽인지 묻는 줄이 뜹니다. 이걸 묻지 않으면 사용자는 128건을 지운 줄 모르고 5건만 지운 줄 압니다.

2 이름부르는 말이 여러 개다

한국어일괄 선택, 다중 선택, 묶음 처리
영어bulk selection, multi-select, batch action
같이 쓰는 말고른 뒤 뜨는 막대가 벌크 액션 바·선택 툴바·컨텍스추얼 액션 바입니다. 맨 위 체크박스가 전체 선택(select all), 일부만 켜진 상태가 인디터미닛(indeterminate)입니다.
자주 잘못 부름체크박스 — 체크박스는 부품 하나, 일괄 선택은 줄들에 걸친 장치입니다.
필터 — 필터는 보이는 것을 줄이고, 일괄 선택은 처리할 것을 고릅니다. 걸러 놓고 전체 선택하면 둘이 만납니다.
멀티 셀렉트 — 입력 부품의 여러 값 고르기와는 다릅니다.

4 상태체크박스에 상태가 셋이다

5 해부도부분 이름이 제일 안 알려진 지식

가맹점
indeterminate — 일부만 골랐을 때의 세 번째 모양
5건 선택됨승인내보내기
'이 쪽 5건' 과 '조건에 맞는 128건' 은 다른 말이다
쪽을 넘기면 선택이 풀리는가 — 먼저 정한다
끝난 뒤 "5건 승인됨 · 되돌리기"
  1. 맨 위 체크박스 select all이 쪽을 켠다. 전부가 아니다
  2. 반쯤 켜진 모양 indeterminateel.indeterminate = true — 속성이 아니라 자바스크립트로만 켜진다
  3. 동작 막대 bulk action bar고른 게 있을 때만. 건수를 적는다
  4. 범위를 묻는 줄 this page / all'이 쪽 5건' 과 '조건에 맞는 128건'은 다른 말이다
  5. 쪽을 넘길 때 선택 유지 여부유지하면 안 보이는 선택이 생기고, 풀면 지금까지가 날아간다. 정하고 적어 둔다
  6. 결과와 되돌리기 undo묶음 처리는 되돌릴 수 있어야 쓴다

'전체 선택'의 뜻이 두 가지라는 것이 이 부품의 전부입니다. 맨 위 체크박스는 거의 늘 지금 보이는 쪽만 켭니다. 그런데 사용자는 조건에 맞는 전부라고 읽습니다. 그래서 지메일부터 깃허브까지 모두 전체를 켠 뒤 "조건에 맞는 128건 모두 고르기"라는 줄을 따로 띄웁니다 — 묻지 않고 넓히면 128건을 지우고도 5건인 줄 압니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 같은 동작을 여러 건에 되풀이할 때 — 승인, 내보내기, 태그 달기
  • 건수가 많아 하나씩 누르면 지치는 화면
  • 되돌릴 수 있는 동작 — 되돌리기가 없으면 범위를 더 좁게 묻는다

이럴 때는 안 쓴다

  • 건수가 서넛일 때 — 줄마다 버튼이 더 빠르다
  • 되돌릴 수 없는 삭제에 '전체 선택' — 적어도 건수를 치게 한다
  • 고른 게 없는데 막대를 띄우는 것
  • 쪽을 넘겼을 때 선택이 조용히 풀리는 것

대신 이걸 — 한 건이면 줄 안의 카드·메뉴 버튼, 거르기만 하면 필터, 확인이 필요하면 다이얼로그.

8 최소 마크업과 키보드이 선택의 계약서

indeterminate는 HTML 속성이 아니라 자바스크립트 프로퍼티입니다.

<input type="checkbox" id="all" aria-label="이 쪽 전체 선택">
…
<div role="status">5건 선택됨</div>

// 세 번째 상태는 속성으로 못 켠다
const n = rows.filter(r => r.checked).length;
all.checked = n === rows.length;
all.indeterminate = n > 0 && n < rows.length;

// 범위를 넓힐 때는 묻는다
if (all.checked && total > rows.length) showScopeBanner(total);

9 서버 쪽으로 치면백엔드 감각으로 번역

'전체'는 조건으로 보낸다128건의 ID 를 전부 보내면 요청이 터집니다. {"filter":{"status":"pending"}}로 조건을 보내고 서버가 고르게 합니다.
일부만 성공할 수 있다128건 중 3건이 실패하면 무엇이 실패했는지 돌려줘야 합니다. 전부 성공 아니면 전부 실패로 묶을지도 정해야 합니다.
오래 걸린다수천 건이면 요청 하나로 못 끝냅니다. 작업 번호를 먼저 돌려주고 진행률을 따로 묻게 합니다.
되돌리기묶음 처리의 되돌리기는 처리 전 상태를 기록해 둬야 가능합니다. 사후에 만들면 거의 불가능합니다.
두 번 눌림막대의 버튼도 두 번 눌립니다. 폼과 같은 고유 키를 씁니다.
