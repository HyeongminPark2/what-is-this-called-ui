5 해부도부분 이름이 제일 안 알려진 지식

받침이 있으면 을 · 이 · 은 · 과 · 으로
받침이 없으면 를 · 가 · 는 · 와 · 로
(code − 0xAC00) % 28 ≠ 0 — 받침이 있다
주어를 지운다 — ‘당신의 설정’이 아니라 ‘설정’
어절은 띄어쓰기로 — word-break: keep-all
‘모란상회을(를)’ — 조사를 하나로 박은 자국
  1. 받침 있음 을 · 이 · 은 · 과 · 으로마지막 글자에 받침이 있을 때
  2. 받침 없음 를 · 가 · 는 · 와 · 로없을 때
  3. 받침 판별 % 28 ≠ 0유니코드로 한 줄이면 된다
  4. 주어 생략 ‘당신의’를 지운다한국어는 주어 없이도 문장이 선다
  5. 어절 keep-all띄어쓰기에서 줄을 바꾼다 — 한글 조판
  6. 괄호 조사 을(를)틀리지는 않지만 읽기 나쁘다

문장을 조각내 이어 붙이면 어순에서 깨집니다. '삭제' + name + '하시겠습니까' 같은 식으로 짜면 영어로 바꿀 때 어순이 맞지 않습니다. 반대로 영어 틀('Delete ' + name + '?')을 그대로 쓰면 한국어에서 조사가 들어갈 자리가 사라집니다. 문장 전체를 한 덩어리로 두고 자리만 비워 두는 방식 ('‘{name}’을(를) 지울까요?')이 두 말 모두에서 덜 깨집니다 — 그리고 그 괄호를 없애는 것이 조사 함수 하나가 하는 일입니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 이름이 들어가는 문장에 조사 함수 쓰기
  • 소리 내어 읽어 보고 안 나오는 말 지우기
  • 문장을 한 덩어리로 두고 자리만 비우기

이럴 때는 안 쓴다

  • ‘을(를)’·‘이(가)’ — 함수 한 줄이면 없앨 수 있다
  • ‘당신의’·‘귀하의’ — 한국어는 주어를 생략한다
  • ‘~들’로 복수 만들기 — 한국어에는 복수형이 없다
  • 문장을 조각내 이어 붙이기

대신 이걸 — 글자를 어떻게 흘릴지는 한글 조판, 말투는 말투와 높임, 숫자는 숫자와 단위.

8 최소 코드와 규칙이 말의 계약서

조사는 받침 하나로 갈립니다.

// 마지막 글자에 받침이 있나
function hasFinal(word) {
  const c = word[word.length - 1].charCodeAt(0);
  if (c < 0xAC00 || c > 0xD7A3) return null;   // 한글이 아니다
  return (c - 0xAC00) % 28 !== 0;
}

function josa(word, withFinal, without) {
  const f = hasFinal(word);
  return f === null ? `${withFinal}(${without})` : (f ? withFinal : without);
}

josa('모란상회', '을', '를');   // '를'
josa('대림유통', '을', '를');   // '을'

/* 줄은 어절에서 바꾼다 */
body { word-break: keep-all; overflow-wrap: break-word; }

조사 함수 한 벌을/를 · 이/가 · 은/는 · 과/와 · 으로/로. 다섯이면 거의 다 덮는다
한글이 아니면외래어·숫자는 소리로 판단해야 한다. 표를 따로 두거나 괄호로 둔다

문장 전체를 키로t('store.delete.confirm', {name}). 조각을 이어 붙이지 않는다
스크린 리더괄호 조사는 '을괄호를괄호'처럼 읽힌다. 없애는 쪽이 낫다
폭같은 뜻이라도 한국어가 영어보다 짧거나 길다. 버튼 폭을 두 말로 재 본다

9 서버 쪽으로 치면백엔드 감각으로 번역

문구를 서버가 완성하지 않는다서버가 조사까지 붙여 보내면 말을 바꿀 때마다 배포해야 합니다. 이름만 주고 문장은 화면이 만듭니다.
정렬은 말에 따라 다르다한국어 가나다순은 단순 코드 순서가 아닙니다. localeCompare('ko')를 씁니다.
검색도 마찬가지'모란'으로 '모란상회'를 찾으려면 형태소나 n-gram이 필요합니다 — 검색.
문구 키를 쪼개지 않는다'delete' + '.' + type 식으로 키를 만들면 어떤 문구가 있는지 아무도 못 셉니다.
