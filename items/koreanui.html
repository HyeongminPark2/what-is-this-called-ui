4 자주 남는 어색한 표현영어 문장을 그대로 옮겼을 때 남는 말

5 해부도부분마다 붙은 이름

받침이 있으면 을 · 이 · 은 · 과 · 으로
받침이 없으면 를 · 가 · 는 · 와 · 로
(code − 0xAC00) % 28 ≠ 0이면 받침이 있음
주어를 빼고 ‘당신의 설정’ 대신 ‘설정’
word-break: keep-all로 띄어쓰기에서 줄바꿈
‘모란상회을(를)’은 조사를 하나로 박아 둔 결과
  1. 받침 있음 을 · 이 · 은 · 과 · 으로앞말의 마지막 글자에 받침이 있을 때 씁니다
  2. 받침 없음 를 · 가 · 는 · 와 · 로마지막 글자에 받침이 없을 때 씁니다
  3. 받침 판별 % 28 ≠ 0유니코드 값으로 계산하면 한 줄로 판별할 수 있습니다
  4. 주어 생략 ‘당신의’를 지움한국어는 주어 없이도 문장이 성립합니다
  5. 어절 keep-all어절 중간이 아니라 띄어쓰기 자리에서 줄을 바꿉니다(한글 조판)
  6. 괄호 조사 을(를)문법으로는 틀리지 않지만 읽기에 불편합니다

문장을 조각내 이어 붙이면 언어마다 다른 어순 때문에 문장이 깨집니다. '삭제' + name + '하시겠습니까'처럼 짜 두면 영어로 바꿀 때 어순이 맞지 않습니다. 반대로 영어 틀('Delete ' + name + '?')을 그대로 쓰면 한국어에서는 조사가 들어갈 자리가 없습니다. 문장 전체를 한 덩어리로 두고 이름이 들어갈 자리만 비워 두는 방식 ('‘{name}’을(를) 지울까요?')이 두 언어 모두에서 덜 깨집니다. 이렇게 만든 문장에 남는 '을(를)' 괄호는 조사 함수 하나로 없앨 수 있습니다.

6 쓸 때 / 안 쓸 때

한국어 UI 문구를 쓸 때 지킬 것

  • 이름이 들어가는 문장에 조사 함수 쓰기
  • 소리 내어 읽어 보고 어색한 말 지우기
  • 문장을 한 덩어리로 두고 자리만 비우기

한국어 UI 문구에서 피할 것

  • ‘을(를)’·‘이(가)’를 그대로 둘 때. 함수 한 줄이면 없앨 수 있습니다
  • ‘당신의’·‘귀하의’를 붙일 때. 한국어는 주어를 생략합니다
  • ‘~들’을 붙여 복수를 만들 때. 한국어에는 복수형이 없습니다
  • 문장을 조각내 이어 붙일 때

한국어 UI와 함께 보면 좋은 항목 — 글자를 어떻게 배치하고 줄을 바꿀지는 한글 조판에서, 말투를 고르는 일은 말투와 높임에서, 숫자를 적는 법은 숫자와 단위에서 다룹니다.

8 최소 코드와 규칙코드로 옮길 때 지킬 것

조사는 앞말에 받침이 있는지만 보면 고를 수 있습니다.

// 마지막 글자에 받침이 있나
function hasFinal(word) {
  const c = word[word.length - 1].charCodeAt(0);
  if (c < 0xAC00 || c > 0xD7A3) return null;   // 한글이 아니다
  return (c - 0xAC00) % 28 !== 0;
}

function josa(word, withFinal, without) {
  const f = hasFinal(word);
  return f === null ? `${withFinal}(${without})` : (f ? withFinal : without);
}

josa('모란상회', '을', '를');   // '를'
josa('대림유통', '을', '를');   // '을'

/* 줄은 어절에서 바꾼다 */
body { word-break: keep-all; overflow-wrap: break-word; }
지킬 규칙과 마크업지키는 방법과 이유
조사 함수 한 벌 만들기을/를 · 이/가 · 은/는 · 과/와 · 으로/로 다섯 쌍이면 화면 문구에 필요한 조사를 거의 다 처리할 수 있습니다
이름이 한글이 아닐 때외래어나 숫자는 읽을 때 나는 소리로 판단해야 하므로, 표를 따로 두거나 괄호 조사로 둡니다
word-break: keep-all어절 중간에서 줄이 끊기지 않습니다(한글 조판)
문장 전체에 키 하나 붙이기t('store.delete.confirm', {name})처럼 문장 전체에 키를 하나 붙이고, 조각을 이어 붙이지 않습니다
스크린 리더로 읽을 때괄호 조사는 '을괄호를괄호'처럼 읽히기 때문에 없애는 편이 낫습니다
버튼 폭 재기같은 뜻이라도 한국어 문구는 영어보다 짧을 때도 길 때도 있으므로, 버튼 폭은 두 언어로 모두 재 봅니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

문구를 서버가 완성하지 않기서버가 조사까지 붙인 문장을 보내면 문구를 바꿀 때마다 서버를 배포해야 합니다. 서버는 이름만 보내고 문장은 화면에서 만듭니다.
언어에 맞춰 정렬하기한국어 가나다순은 단순한 코드 순서와 같지 않으므로 localeCompare('ko')로 정렬합니다.
한국어 검색도 따로 챙기기'모란'으로 '모란상회'를 찾으려면 형태소나 n-gram 단위로 찾을 수 있어야 합니다(검색).
문구 키를 쪼개지 않기'delete' + '.' + type처럼 키를 조합해 만들면 코드에서 키를 검색할 수 없어서 어떤 문구가 있는지 셀 수 없습니다.
