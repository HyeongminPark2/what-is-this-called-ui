2 이름부르는 말이 여러 개다

한국어데이터 테이블, 표, 그리드, 목록 화면
영어data table, data grid, table view
같이 쓰는 말열 이름 줄이 헤더(thead), 값 줄이 행(row)입니다. 정렬·필터·쪽 넘김이 붙은 것을 데이터 그리드라 부르기도 합니다. 열을 고정하는 것은 프리즈(freeze · pinned column), 열 너비를 끌어 바꾸는 것은 리사이즈입니다.
자주 잘못 부름그리드 — CSS 의 레이아웃 그리드와 다릅니다. 이쪽은 데이터입니다.
리스트 — 리스트는 자유로운 세 자리, 표는 열이 정해져 있습니다.
엑셀 — 표가 곧 편집 가능한 시트는 아닙니다. 읽기용인지 편집용인지부터 정합니다.

  1. 표 table<table>이라야 '표, 5열 20행'으로 읽힌다. div 로 만들면 안 읽힌다
  2. 붙박이 열 이름 sticky thead굴려도 무슨 열인지 안 잊게. <th>에 건다
  3. 정렬 표시 aria-sort화살표와 함께. 눌렀는데 표시가 없으면 뭘 눌렀는지 모른다
  4. 숫자 열 오른쪽 + tabular-nums자릿수가 세로로 맞아야 크기를 눈으로 견줄 수 있다
  5. 고정 열 sticky left열이 많을 때. 이름 열을 왼쪽에 붙여 둔다
  6. 주소에 담기 ?sort=&dir=&page=새로고침·공유·뒤로가기가 되려면 필요하다

표를 <div>로 만들면 스크린 리더가 표로 읽지 못합니다. '3열 5행'도, '매출 열, 1,284,000'도 안 나오고 글자만 줄줄 읽힙니다. CSS 그리드로 모양을 내더라도 마크업은 <table>로 두는 것이 거의 늘 맞습니다 — display: grid를 <table>에 걸 수도 있습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 같은 모양의 건이 여럿이고 여러 값을 견줘야 할 때
  • 정렬·필터·쪽 넘김이 필요할 때
  • 숫자가 많은 화면 — 세로로 맞춰 봐야 할 때

이럴 때는 안 쓴다

  • 건마다 보여 줄 것이 다를 때 → 카드나 리스트
  • 폰에서 열 다섯 개를 그대로 — 가로 스크롤이거나 카드로 바뀌어야 합니다
  • 배치하려고 <table>을 쓰는 것
  • 모든 열에 정렬을 거는 것 — 정렬이 뜻 있는 열에만

대신 이걸 — 건마다 내용이 다르면 카드, 한 줄이면 리스트 아이템, 아주 길면 가상 스크롤.

8 최소 마크업과 키보드이 표의 계약서

<table>을 쓰고, 정렬 상태를 aria-sort와 주소에 함께 적습니다.

<table>
  <caption class="sr-only">정산 목록, 20건 중 1~5</caption>
  <thead><tr>
    <th scope="col">가맹점</th>
    <th scope="col" aria-sort="descending">
      <button>매출 ▼</button>
    </th>
  </tr></thead>
  <tbody>
    <tr><th scope="row">모란상회</th><td>1,284,000</td></tr>
  </tbody>
</table>

thead th { position: sticky; top: 0; z-index: 2; }
td.num { text-align: right; font-variant-numeric: tabular-nums; }

scope를 적는다col·row. 스크린 리더가 '매출 열, 1,284,000'으로 읽는다

9 서버 쪽으로 치면백엔드 감각으로 번역

정렬은 서버에서화면에 있는 20건만 정렬하면 쪽을 넘길 때마다 순서가 깨집니다. 전체를 기준으로 정렬해 그 쪽을 잘라 보내야 합니다.
정렬 기준을 열어 두지 않는다?sort=를 그대로 SQL 에 넣으면 주입이 됩니다. 허용 목록으로 받습니다.
같은 값의 순서매출이 같은 두 건의 순서가 요청마다 바뀌면 쪽을 넘길 때 같은 줄이 두 번 나옵니다. ID 를 2차 정렬로 붙입니다.
전체 건수'20건 중 1~5'를 보여 주려면 COUNT(*)가 필요한데 비쌉니다. 큰 표에서는 '100+ 건'으로 적거나 커서 방식으로 바꿉니다.
열 많은 표열이 늘수록 응답도 커집니다. 보이는 열만 요청하는 방식(필드 선택)을 두면 목록이 가벼워집니다.
