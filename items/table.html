데이터 테이블

Data table

데이터 테이블은 같은 모양의 건을 줄지어 놓고 여러 값을 세로로 견주어 보도록 만든 화면입니다. 관리 도구 화면의 절반 정도가 이런 표입니다.

줄바꿈 허용을 켜면 줄마다 높이가 달라져서 값을 세로로 훑어보기가 어려워집니다. 첫 열 고정을 끄고 표를 가로로 밀면 이름 열이 화면 밖으로 나가서 어느 가맹점의 줄인지 알 수 없게 됩니다.

2 이름같은 것을 부르는 여러 이름

한국어데이터 테이블, 표, 그리드, 목록 화면
영어data table, data grid, table view
같이 쓰는 말열 이름이 적힌 줄은 헤더(thead), 값이 적힌 줄은 행(row)이라고 부릅니다. 정렬과 필터, 쪽 넘김 기능까지 붙은 표는 데이터 그리드라고 부르기도 합니다. 열을 제자리에 고정하는 기능은 프리즈(freeze · pinned column), 열 너비를 끌어서 바꾸는 기능은 리사이즈라고 합니다.
자주 잘못 부르는 이름그리드 — CSS의 레이아웃 그리드는 화면 배치를 나누는 틀이고, 데이터 그리드는 데이터를 보여 주는 표라서 서로 다릅니다.
리스트 — 리스트 아이템은 앞·가운데·뒤 세 자리에 내용을 자유롭게 놓지만, 표는 열이 정해져 있어서 모든 줄이 같은 칸을 씁니다.
엑셀 — 표라고 해서 모두 엑셀처럼 칸을 고칠 수 있는 시트는 아닙니다. 만들기 전에 읽기용인지 편집용인지부터 정합니다.

6 쓸 때 / 안 쓸 때

데이터 테이블을 쓰는 경우

  • 같은 모양의 건이 여럿이고 여러 값을 견줘야 할 때
  • 정렬·필터·쪽 넘김이 필요할 때
  • 숫자가 많아서 세로로 맞춰 봐야 하는 화면일 때

데이터 테이블을 쓰지 않는 경우

  • 건마다 보여 줄 내용이 다를 때. 카드나 리스트가 맞습니다
  • 폰에서 열 다섯 개를 그대로 보여 줄 때. 가로 스크롤을 두거나 카드로 바꿔야 합니다
  • 화면 배치를 잡으려고 <table>을 쓸 때
  • 모든 열에 정렬을 걸 때. 정렬은 정렬해서 볼 뜻이 있는 열에만 겁니다

데이터 테이블 대신 다른 것을 써야 하는 경우 — 건마다 내용이 다르면 카드, 한 줄이면 리스트 아이템, 아주 길면 가상 스크롤.

8 최소 마크업과 키보드표가 꼭 갖출 것

마크업은 <table>로 쓰고, 정렬 상태는 aria-sort와 주소 양쪽에 함께 적습니다.

<table>
  <caption class="sr-only">정산 목록, 20건 중 1~5</caption>
  <thead><tr>
    <th scope="col">가맹점</th>
    <th scope="col" aria-sort="descending">
      <button>매출 ▼</button>
    </th>
  </tr></thead>
  <tbody>
    <tr><th scope="row">모란상회</th><td>1,284,000</td></tr>
  </tbody>
</table>

thead th { position: sticky; top: 0; z-index: 2; }
td.num { text-align: right; font-variant-numeric: tabular-nums; }
키와 동작그때 일어나야 하는 일
Tab정렬 버튼과 줄 안의 누를 수 있는 것들로 옮겨 갑니다. 셀마다 멈추지는 않습니다
scope를 적는다col·row를 적어 두면 스크린 리더가 '매출 열, 1,284,000'처럼 열 이름을 붙여 읽습니다
aria-sort정렬 기준인 열 하나에만 달고, 화살표와 함께 씁니다
<caption>표가 무엇인지 한 줄로 적습니다. 화면에는 보이지 않게 둬도 됩니다
정렬은 <button>으로<th>에 onclick을 걸면 키보드로 누를 수 없습니다
줄 높이를 맞춘다긴 글자는 말줄임으로 잘라 한 줄로 고정합니다. 줄 높이가 같은 것은 가상 스크롤의 전제 조건이기도 합니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

정렬은 서버에서화면에 받아 둔 20건만 정렬하면 쪽을 넘길 때마다 순서가 이어지지 않습니다. 서버가 전체 데이터를 기준으로 정렬한 뒤 해당 쪽만 잘라 보내야 합니다.
정렬 기준을 열어 두지 않는다?sort= 값을 그대로 SQL에 넣으면 SQL 주입 공격을 당할 수 있습니다. 정렬할 수 있는 열 이름을 허용 목록으로 정해 두고 그 안의 값만 받습니다.
같은 값의 순서매출이 같은 두 건의 순서가 요청마다 바뀌면 쪽을 넘길 때 같은 줄이 두 번 나옵니다. 그래서 ID를 2차 정렬 기준으로 붙여 순서를 고정합니다.
전체 건수'20건 중 1~5'처럼 전체 건수를 보여 주려면 COUNT(*)를 따로 돌려야 하는데, 행이 많은 표에서는 이 쿼리가 오래 걸립니다. 그래서 큰 표에서는 '100+ 건'처럼 대략 적거나 커서 방식으로 바꿉니다.
열 많은 표열이 늘수록 응답 크기도 커집니다. 화면에 보이는 열만 요청하는 방식(필드 선택)을 두면 목록 응답이 가벼워집니다.
