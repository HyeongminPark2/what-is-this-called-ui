5 해부도부분 이름이 제일 안 알려진 지식

보이는 값 — 하이픈·공백이 들어간 꼴
보낼 값 — 숫자만 남긴다
붙여넣은 기호는 알아서 걸러낸다
서식을 넣을 때 커서가 맨 뒤로 튀기 쉽다
자릿수를 다 채우면 다음 칸으로 넘기기도 한다
지우기(Backspace)에서 기호를 건너뛴다
  1. 보이는 값 서식 포함읽기 좋게
  2. 보낼 값 숫자만화면이 벗긴다
  3. 붙여넣기 걸러내기공백·괄호·점
  4. 커서 튀기 쉬움친 숫자 개수로 되돌린다
  5. 오토 탭 다 채우면다음 칸으로
  6. Backspace 기호 건너뛰기하이픈에서 멈추지 않게

커서가 튀는 것이 이 부품의 가장 흔한 버그입니다 — 값을 다시 쓰면 커서가 맨 뒤로 가서, 가운데 한 글자를 고치려던 사람은 매번 끝으로 끌려갑니다. 고치는 법은 간단합니다 — 서식을 넣기 전에 커서 앞의 숫자가 몇 개였는지를 세어 두고, 새 값에서 같은 개수만큼 지난 자리로 커서를 돌려놓으면 됩니다.
오토 탭은 편해 보이지만 조심해야 합니다 — 자동으로 넘어간 뒤 Backspace 를 누르면 앞 칸으로 못 돌아가는 구현이 많습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 보이는 값과 보낼 값을 나누기
  • 붙여넣은 기호를 걸러내기
  • 서식을 넣은 뒤 커서를 되돌리기

이럴 때는 안 쓴다

  • 기호가 섞인 채로 서버에 보내기
  • 커서를 맨 뒤로 보내기
  • type="number" 에 서식 넣기 — 값이 사라진다
  • 자리글로 서식을 흉내 내기 — 치면 사라진다

대신 이걸 — 서식 없는 숫자는 숫자 입력, 맞는지 보는 일은 입력 검증, 안내 글은 자리글과 헬퍼 텍스트, 오류 문구는 오류 문구.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

숫자만 뽑아 다시 꼴을 만들고, 커서를 되돌립니다.

const digits = s => s.replace(/[^\d]/g, '');
const fmt = raw => [raw.slice(0, 3), raw.slice(3, 5), raw.slice(5, 10)]
  .filter(Boolean).join('-');

input.addEventListener('input', () => {
  // 커서 앞의 숫자가 몇 개였는지 세어 둔다
  const before = digits(input.value.slice(0, input.selectionStart)).length;
  input.value = fmt(digits(input.value).slice(0, 10));
  // 같은 개수만큼 지난 자리로 커서를 되돌린다
  let pos = 0, seen = 0;
  while (pos < input.value.length && seen < before) {
    if (/\d/.test(input.value[pos])) seen++;
    pos++;
  }
  input.setSelectionRange(pos, pos);
});

9 서버 쪽으로 치면백엔드 감각으로 번역

숫자만 받는다"123-45-67890" 이 아니라 "1234567890" 으로 보냅니다.
관대하게 받기그래도 서버는 기호가 섞여 와도 걸러서 받는 편이 안전합니다.
검증은 서버에서사업자번호 체크섬 같은 것은 서버가 봐야 믿을 수 있습니다.
