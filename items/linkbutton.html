링크와 버튼

Link vs button

가르는 질문은 하나입니다 — 이동인가, 동작인가. 생김새는 자유지만 태그는 뜻을 따라야 합니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

주소가 바뀌면 링크(<a href>), 그 자리에서 일이 일어나면 버튼(<button>)입니다.
div 에 onclick 으로 만들면 보기에는 같지만 Tab 이 멈추지 않고 Enter 로도 안 눌립니다 — 'Tab 으로 훑어보기'를 누르면 초점이 몇 군데 멈추는지 세 줍니다.
서로 바꿔서 만들면 더 조용히 나쁩니다 — 링크로 만든 '저장'은 새 탭으로 열리고, 버튼으로 만든 '상세 보기'는 가운데 버튼·복사·공유가 안 됩니다.

2 이름부르는 말이 여러 개다

한국어링크와 버튼, 앵커와 버튼
영어link vs button, anchor vs button
같이 쓰는 말링크처럼 보이는 버튼을 링크 버튼·텍스트 버튼, 버튼처럼 보이는 링크를 버튼 링크라 부르는데 둘 다 생김새 이야기입니다. 태그 이름으로는 <a>가 앵커, <button>이 버튼입니다.
자주 잘못 부름버튼 위계 — 버튼 위계는 세기이고 이건 뜻입니다.
CTA — CTA 는 역할 이름이지 태그가 아닙니다.
링크 색 — 파란 밑줄은 관습이지 규칙이 아닙니다.

4 상태그림 한 장으로는 못 배운다

5 해부도부분 이름이 제일 안 알려진 지식

주소가 바뀌면 <a href> — 이동
그 자리에서 일이 일어나면 <button> — 동작
링크는 새 탭 · 복사 · 공유가 된다
버튼은 Space 로도 눌린다 — 링크는 Enter 만
div + onclick — Tab 이 안 멈추고 Enter 가 안 먹는다
생김새는 자유다 — 뜻만 지킨다
  1. 이동 <a href>주소가 바뀐다
  2. 동작 <button>그 자리에서 일이
  3. 링크만 새 탭 · 복사오른쪽 메뉴가 다르다
  4. 버튼만 Space링크는 Enter 만
  5. div 둘 다 안 됨Tab 도 Enter 도
  6. 생김새 자유뜻만 지킨다

서로 바꿔 쓰는 것이 div 보다 더 흔하고, 더 조용히 나쁩니다 — 링크로 만든 '저장'은 가운데 버튼으로 누르면 새 탭에서 열리고, 거기서 또 저장이 일어납니다. 버튼으로 만든 '상세 보기'는 링크 주소 복사도, 새 탭으로 열기도 안 됩니다. 둘 다 평소에는 안 드러나서 오래 남습니다.
판단이 애매하면 주소창을 보세요 — 누른 뒤 주소가 바뀐다면 링크입니다. '모달을 연다'는 주소를 바꾸기도 하는데, 그때는 라이트박스처럼 링크로 두는 편이 공유도 되고 뒤로가기도 됩니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 주소가 바뀌면 링크, 아니면 버튼
  • 폼 안의 버튼에는 type="button" 적기
  • div 에 onclick 을 달지 않기

이럴 때는 안 쓴다

  • 저장을 링크로 만들기 — 새 탭에서 또 저장된다
  • 상세 보기를 버튼으로 만들기 — 복사·새 탭이 안 된다
  • <a href="#"> 에 onclick — 주소가 더러워진다
  • role="button" 만 붙이고 키보드를 안 붙이기

대신 이걸 — 세기는 버튼 위계, 갈래가 붙으면 분할 버튼, 문구는 버튼 문구, 차례는 보이는 순서와 읽는 순서.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

생김새는 클래스로, 뜻은 태그로 가릅니다 — 둘은 따로입니다.

<!-- 이동 — 버튼처럼 보여도 링크다 -->
<a class="btn btn--primary" href="/orders/2411">주문 상세 보기</a>

<!-- 동작 — 링크처럼 보여도 버튼이다 -->
<button class="btn btn--text" type="button">도움말 보기</button>

/* 둘을 같은 모양으로 — 생김새는 클래스가 맡는다 */
.btn { display: inline-flex; align-items: center; justify-content: center;
  min-height: 44px; text-decoration: none; font: inherit; cursor: pointer; }

/* ✕ 이건 둘 다 아니다 */
<div onclick="save()">저장</div>
키일어나야 하는 일
Enter링크와 버튼 둘 다 눌린다
Space버튼만 눌린다 — 링크에서는 스크롤이 내려간다
⌘ · Ctrl + 클릭링크만 새 탭으로 열린다
type="button"폼 안에서 안 적으면 제출이 된다
role="button"붙였으면 Enter·Space도 손으로 붙여야 한다
확인하는 법Tab 으로 훑어 멈추지 않는 자리가 있는지 본다

9 서버 쪽으로 치면백엔드 감각으로 번역

이동이면 주소를응답에 url 이 있으면 화면이 링크로 만들 수 있습니다 — id 만 주면 화면이 주소를 지어야 합니다.
동작이면 결과를버튼이 부르는 API 는 무엇이 바뀌었는지를 돌려줘야 부분 로딩이 됩니다.

10 플랫폼마다 다른 이름같은 부품, 다른 말

웹에만 있는 구분입니다 — 앱에는 주소가 없습니다.

웹<a> vs <button>
상세 보기a저장button
주소가 있다는 것이 웹의 힘입니다 — 공유·새 탭·뒤로가기가 공짜로 됩니다.
iOSNavigationLink vs Button
›
NavigationLink 가 이동, Button 이 동작입니다 — 같은 구분이 있습니다.
안드로이드Navigation vs Button
화면 이동은 내비게이션, 동작은 버튼으로 코드에서 갈립니다.

자주 생기는 사고 — 앱에도 이동과 동작이라는 구분은 똑같이 있지만, 웹만큼 티가 안 납니다 — 주소가 없어 '새 탭으로 열기'나 '링크 복사'가 애초에 없기 때문입니다. 웹에서 이 구분을 지키면 공짜로 얻는 것이 많습니다: 공유 가능한 주소, 뒤로가기, 가운데 버튼, 검색 엔진. 앱 쪽에서 온 분들이 가장 자주 놓치는 자리이기도 합니다.
