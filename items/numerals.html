숫자 꼴

Numerals · tabular figures

숫자 꼴은 숫자 하나하나가 차지하는 너비를 다룹니다. 세로로 쌓이는 표나 1초마다 바뀌는 값에서 숫자마다 너비가 다르면 자릿수가 흔들려 읽기 어렵습니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

가운데 표는 글꼴마다 숫자 너비를 직접 재서 '원래 고름'인지, '켜니 고르게 됨'인지, '켜도 안 바뀌니 기능 없음'인지 알려 줍니다.
tabular-nums는 글꼴에 그 기능이 있을 때만 효과가 있습니다. 세리프 계열 글꼴에는 대개 그 기능이 없어서 켜도 아무 변화가 없습니다. 위의 큰 숫자에서 흔들린 폭이 실시간으로 쌓이는 것도 확인해 보세요.

2 이름같은 것을 부르는 여러 이름

한국어숫자 꼴, 등폭 숫자, 고정폭 숫자
영어tabular figures, tabular-nums, lining figures, oldstyle figures
같이 쓰는 말모든 숫자의 너비가 같은 것을 등폭 숫자(tabular figures), 숫자마다 너비가 다른 것을 비례 숫자(proportional figures)라고 합니다. 높이가 숫자마다 다른 옛 스타일 숫자는 올드스타일(oldstyle · text figures), 높이가 고른 숫자는 라이닝(lining)이라고 부릅니다. 글꼴 안에서 이 기능을 가리키는 이름은 tnum·pnum입니다.
자주 잘못 부르는 이름등폭 글꼴 — 코드에 쓰는 등폭 글꼴은 모든 글자의 너비가 같은 글꼴이고, 등폭 숫자는 숫자만 너비를 같게 맞추는 기능이라 서로 다릅니다.
text-align: right — 오른쪽 맞춤은 숫자를 끝자리에서 맞출 뿐이고, 숫자의 너비 자체는 바꾸지 않습니다.
천 단위 쉼표 — 자릿수를 읽기 쉽게 해 주지만, 숫자 너비가 달라 생기는 흔들림은 막지 못합니다.

3 숫자 자리가 맞는 경우와 어긋나는 경우글꼴과 설정에 따라 달라지는 결과

4 해부도부분마다 붙은 이름

₩1,284,000
font-variant-numeric: tabular-nums
글꼴에 tnum 기능이 없으면 효과 없음
text-align: right 끝자리를 오른쪽에 맞춤
toLocaleString('ko-KR') 천 단위 쉼표 넣기
등폭 글꼴 기능이 없는 글꼴의 대안
  1. 바뀌는 숫자 value금액, 시간, 카운트다운처럼 값이 바뀌어도 자리가 흔들리지 않아야 하는 숫자입니다
  2. 등폭 켜기 tabular-nums모든 숫자가 같은 너비를 쓰게 합니다
  3. 글꼴 지원 tnum feature글꼴에 이 기능이 없으면 켜도 아무 변화가 없습니다. 한글 글꼴에서 특히 흔한 일입니다
  4. 오른쪽 맞춤 text-align: right숫자를 끝자리에서 맞춥니다. 등폭 숫자와 함께 써야 표의 숫자가 잘 읽힙니다
  5. 천 단위 쉼표 toLocaleString큰 숫자를 읽기 쉽게 해 줍니다. 통화와 소수점 규칙도 같은 함수로 맞춥니다
  6. 등폭 글꼴 monospace글꼴에 등폭 숫자 기능이 없을 때 쓸 수 있는 확실한 대안입니다

가장 흔한 실수는 tabular-nums를 켜 두기만 하고 적용된 줄 아는 것입니다. 이 속성은 글꼴 안에 들어 있는 기능을 켜기만 하기 때문에, 그 기능이 없는 글꼴에서는 아무 변화도 없고 경고도 나오지 않습니다. 글꼴을 바꿀 때도 아무 경고 없이 숫자 정렬이 어긋날 수 있으므로, 개발자 도구에서 숫자 너비를 직접 재 보는 것이 유일한 확인 방법입니다.

5 쓸 때 / 안 쓸 때

숫자 꼴을 쓰는 경우

  • 표의 금액 열이나 목록의 값처럼 세로로 쌓이는 숫자를 보여 줄 때
  • 타이머, 카운트다운, 실시간 집계처럼 자주 바뀌는 숫자를 보여 줄 때
  • 자릿수가 같은 값들을 비교해야 할 때

숫자 꼴을 쓰지 않는 경우

  • 읽는 글의 문장 속 숫자에 쓸 때. 문장 안에서는 비례 숫자가 더 자연스럽습니다
  • 켜 두기만 하고 확인하지 않을 때. 글꼴이 지원하는지 직접 재 봐야 합니다
  • 오른쪽 맞춤 없이 등폭 숫자만 쓸 때. 자릿수가 다르면 여전히 어긋납니다
  • 숫자만 다른 글꼴로 바꿀 때. 글자와 숫자의 높이가 맞지 않을 수 있습니다

숫자 꼴과 이어지는 주제를 다루는 항목 — 표 전체를 어떻게 짜는지는 데이터 테이블(10부)에서 다루고, 큰 숫자 하나를 돋보이게 보여 주는 방법은 스탯 타일에 있습니다. 글꼴 파일을 받아 오는 문제는 웹폰트를 보세요.

6 자주 보는 모습구조만 따라 그린 재현 그림

7 최소 코드와 규칙기능을 켠 뒤 직접 재 보기

한 줄로 기능을 켜고, 정말 적용됐는지 재 보는 코드를 한 줄 더 둡니다.

/* 표·타이머처럼 자릿수가 맞아야 하는 곳 */
.amount, .timer, td {
  font-variant-numeric: tabular-nums;
  text-align: right;      /* 둘 다 있어야 자릿수가 읽힌다 */
}

// 천 단위 쉼표와 통화는 로케일에 맡긴다
new Intl.NumberFormat('ko-KR',
  { style: 'currency', currency: 'KRW' }).format(1284000);

// 글꼴이 정말 지원하는지 재 본다
const p = document.createElement('span');
p.style.cssText = 'position:absolute;visibility:hidden;font-variant-numeric:tabular-nums';
document.body.append(p);
p.textContent = '1111'; const a = p.offsetWidth;
p.textContent = '0000'; const ok = (a === p.offsetWidth);
지킬 규칙지키는 방법
표와 타이머에 켜기세로로 쌓이거나 자주 바뀌는 숫자에 켭니다
오른쪽 맞춤과 함께 쓰기등폭 숫자만으로는 자릿수가 다른 값끼리 끝이 맞지 않습니다
실제로 적용됐는지 재 보기글꼴에 기능이 없으면 경고 없이 아무 변화도 일어나지 않습니다
기능이 없으면 등폭 글꼴 쓰기숫자 부분만 font-family를 바꾸는 방법도 있습니다
문장 속 숫자는 그대로 두기읽는 글에서는 비례 숫자가 더 자연스럽습니다
쉼표는 Intl로 넣기통화 기호와 소수점, 자릿수 규칙이 나라마다 다르기 때문입니다

8 서버 쪽으로 치면백엔드 개념과 짝지어 보기

숫자 서식을 입히는 곳서버는 1284000처럼 숫자만 내려 주고, 서식은 화면에서 입히는 편이 낫습니다. 서버가 '₩1,284,000' 같은 문자열을 보내면 화면에서 정렬도 계산도 할 수 없습니다.
금액의 소수점과 반올림금액은 정수로 다루고, 나누는 계산은 화면에 보여 줄 때만 합니다. 부동소수점으로 돈을 계산하면 반올림 오차 때문에 1원이 어긋날 수 있습니다.
통화 기호와 로케일 맞추기Intl.NumberFormat을 쓰면 통화 기호 위치와 쉼표, 소수 자릿수를 한 번에 맞출 수 있습니다.
큰 수를 줄여 보여 주기'₩12.8억'처럼 줄여 보여 줄지는 화면에서 정합니다. 다만 어디서 반올림할지를 한 곳에 모아 두지 않으면 화면마다 숫자가 달라집니다.
