대소문자

Letter case

영어에는 네 가지 꼴이 있고 자리마다 관례가 다릅니다. 한국어에는 없는 구분이라 섞으면 어긋납니다.

한국어도 함께 보기를 켜 두면 알 수 있습니다 — 영어만 바뀌고 한국어는 그대로라, 한 줄 안에서 결이 어긋납니다.

2 이름부르는 말이 여러 개다

한국어대소문자, 문장형, 제목형, 전부 대문자
영어sentence case, title case, UPPERCASE / all caps, lowercase
같이 쓰는 말첫 글자만 대문자가 문장형(sentence case), 단어마다가 제목형(title case), 전부 대문자가 올 캡스(all caps)입니다. 높이가 같은 작은 대문자는 스몰 캡스(small caps)라 하고 CSS 에서는 font-variant-caps로 켭니다.
자주 잘못 부름볼드 — 굵기는 글자 굵기입니다. 강조 수단이 다릅니다.
캡스락 — 키보드 키 이름입니다. 글자 꼴 이야기와는 다릅니다.
대문자화 — capitalize는 단어마다 첫 글자를 올립니다. 제목형의 규칙(관사 처리)까지는 못 합니다.

4 네 가지 꼴어느 자리에 맞나

5 해부도부분 이름이 제일 안 알려진 지식

문장형 — Export settlements. 첫 글자만
제목형 — Export Settlements. 단어마다
대문자 — EXPORT SETTLEMENTS. 윤곽이 사라진다
text-transform 은 보이기만 바꾼다 — 값은 그대로
자간을 조금 벌린다 — 대문자는 빽빽해 보인다
한국어에는 대소문자가 없다 — 한 줄 안에서 결이 어긋난다
  1. 문장형 첫 글자만기본으로 삼는다. 번역해도 덜 깨진다
  2. 제목형 단어마다관사·전치사를 어떻게 할지 규칙이 또 필요하다
  3. 전부 대문자 윤곽이 사라짐글자가 다 네모가 되어 단어 모양으로 못 읽는다
  4. text-transform 보이기만값은 그대로다. 복사하면 원래 글자가 나온다
  5. 자간 조금 벌린다대문자는 빽빽해 보인다 — 자간
  6. 한국어 구분이 없다섞으면 결이 어긋난다

text-transform은 보이기만 바꿉니다. 값은 원래 글자 그대로라서, 복사해 붙이면 소문자가 나오고 검색도 원래 글자로 걸립니다 — 대개는 이게 좋은 일입니다. 다만 스크린 리더가 대문자를 약자로 읽어 버리는 경우가 있어 'EXPORT' 를 '이엑스피오알티'로 읽기도 합니다. 그래서 전부 대문자가 필요하면 글자는 문장형으로 쓰고 CSS 로만 올리는 쪽이 안전합니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 문장형을 기본값으로 정해 두기
  • 짧은 레이블·메뉴에만 제목형
  • 대문자를 쓸 때는 자간을 조금 벌리기

이럴 때는 안 쓴다

  • 본문이나 긴 제목에 전부 대문자 — 읽기가 느려진다
  • 글자 자체를 대문자로 적기 — CSS 로 한다
  • 한국어와 섞인 줄에 text-transform을 전역으로 걸기
  • 제목형을 손으로 — 관사 규칙이 사람마다 다르다

대신 이걸 — 강조는 글자 굵기, 크기 차이는 타입 스케일, 줄 사이는 행간.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙이 꼴의 계약서

글자는 문장형으로 적고, 보이기만 CSS 로 올립니다.

<!-- 글자는 그대로 — 복사·검색이 멀쩡하다 -->
<th class="col">Settlements</th>

.col {
  text-transform: uppercase;
  letter-spacing: .06em;   /* 대문자는 빽빽해 보인다 */
  font-size: 11px;
}

/* 한국어가 섞이는 줄에는 걸지 않는다 — 영어만 바뀌어 결이 어긋난다 */
.title { text-transform: none; }
키일어나야 하는 일
값은 안 바뀐다text-transform은 보이기만. 복사하면 원래 글자가 나온다
약자로 읽힐 수 있다대문자를 한 글자씩 읽는 스크린 리더가 있다
capitalize의 한계단어마다 첫 글자만 올린다. 관사 규칙은 못 한다
font-variant-caps스몰 캡스는 글꼴이 지원해야 한다. 없으면 억지로 줄인 가짜가 나온다
한국어 줄바뀌는 것이 없다. 전역으로 걸면 영어만 튄다
번역영어 기준으로 꼴을 정하면 다른 말에서 규칙이 다르다 — 독일어는 명사가 늘 대문자다

9 서버 쪽으로 치면백엔드 감각으로 번역

저장은 원래 꼴로화면에서 올려 보일 뿐 값은 그대로 둡니다. 대문자로 저장하면 되돌릴 수 없습니다.
검색·정렬대소문자를 무시하고 비교할지 정해 둡니다. DB 설정(collation)에 따라 다릅니다.
아이디·이메일대소문자를 가릴지가 로그인에 영향을 줍니다 — 이메일은 보통 안 가립니다.
