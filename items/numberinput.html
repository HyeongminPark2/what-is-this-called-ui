숫자 입력

Number input

type="number"는 숫자 칸을 쉽게 만들어 주는 것처럼 보이지만 문제가 많습니다. 마우스 휠을 굴리면 값이 바뀌고, 쉼표가 들어가면 값 전체가 사라집니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

데모가 지금 칸에서 읽히는 값을 그대로 적어 줍니다. type="number" 칸에 쉼표를 넣으면 값이 빈 문자열로 바뀌는 것을 볼 수 있습니다.
그래서 돈이나 전화번호처럼 세어서 쓰지 않는 숫자는 text 칸에 inputmode="numeric"을 다는 편이 안전합니다. 이렇게 해도 폰에서는 똑같이 숫자 자판이 뜹니다.
단위는 칸 밖에 두어야 칸에 숫자 값만 남습니다.

2 이름같은 것을 부르는 여러 이름

한국어숫자 입력, 숫자 칸
영어number input, numeric input
같이 쓰는 말브라우저가 칸 옆에 띄우는 작은 화살표는 스피너, 폰 자판을 숫자 자판으로 바꾸는 속성은 inputmode입니다. 세 자리마다 쉼표를 넣는 것은 천 단위 구분, 숫자마다 폭을 같게 맞추는 글꼴 설정은 tabular-nums라고 합니다.
자주 잘못 부르는 이름수량 스테퍼 — 칸 양옆에 − · ＋ 단추가 붙어 있으면 수량 스테퍼입니다.
자동 서식 입력 — 치는 동안 하이픈을 넣어 주는 칸은 자동 서식 입력입니다.
슬라이더 — 슬라이더는 숫자를 치지 않고 손잡이를 끌어 범위 안에서 고릅니다.

4 상태상태마다 달라지는 모습

5 해부도부분마다 붙은 이름

text + inputmode="numeric"이 안전한 기본
type="number"는 휠로 값이 바뀜
쉼표를 넣으면 값이 빈 문자열이 됨
단위는 칸 밖에 두어 값만 남김
숫자는 오른쪽 맞춤에 tabular-nums
세어서 쓰지 않는 숫자는 text로 받음
  1. text + inputmode 안전한 기본number와 똑같이 폰에서 숫자 자판이 뜹니다
  2. type=number 휠로 값이 바뀜칸 위에서 스크롤하다가 값이 바뀝니다
  3. 쉼표 값이 사라짐number 칸에 쉼표를 넣으면 값이 빈 문자열이 됩니다
  4. 단위 칸 밖에단위를 칸 밖에 두어야 칸에 숫자 값만 남습니다
  5. 맞춤 오른쪽 맞춤과 tabular-nums오른쪽으로 맞추고 숫자 폭을 고정해 자릿수가 흔들리지 않게 합니다
  6. 세어 쓰는 숫자 number를 써도 됨수량이나 나이처럼 세어서 쓰는 수에는 number를 써도 됩니다

수량이나 나이처럼 세어서 쓰는 작은 수에는 type="number"의 화살표와 범위 검사가 편리합니다. 문제가 생기는 것은 돈·전화번호·카드번호처럼 숫자로 이루어져 있지만 계산하지는 않는 값에 쓸 때입니다. 이런 값에는 쉼표나 하이픈이 들어가고, 맨 앞의 0도 값의 일부이며, 자릿수가 깁니다. 세 가지 모두 number 칸이 제대로 다루지 못하는 것들입니다.
어느 쪽을 쓸지는 이 값을 더하거나 뺄 일이 있는지 물어보면 정할 수 있습니다. 계산할 일이 없으면 text 칸을 씁니다.

6 쓸 때 / 안 쓸 때

숫자 입력을 쓰는 경우

  • 세어서 쓰지 않는 숫자를 text + inputmode="numeric"으로 받기
  • 단위를 칸 밖에 두기
  • 오른쪽 맞춤 + tabular-nums로 자릿수 맞추기

숫자 입력을 쓰지 않는 경우

  • 금액에 type="number" 쓰기. 쉼표를 넣으면 값이 지워집니다
  • 전화번호에 type="number" 쓰기. 숫자로 읽히면서 앞의 0이 사라집니다
  • 단위를 칸 안에 넣기
  • 휠로 값이 바뀌게 두기. 화면을 스크롤하다가 값이 바뀌어 버립니다

숫자 입력 대신 다른 것을 써야 하는 경우 — 칸 양옆에 − ＋ 단추를 붙여 하나씩 고치게 하려면 수량 스테퍼를, 치는 동안 하이픈을 넣어 주어야 하면 자동 서식 입력을 씁니다. 정해진 범위 안에서 고르게 하려면 슬라이더가 맞고, 숫자를 화면에 어떤 형식으로 적을지는 숫자와 단위 쓰기에서 다룹니다.

8 최소 마크업과 키보드구현할 때 지킬 최소 규칙

세어서 쓰지 않는 숫자는 text 칸으로 받고, 값을 읽을 때 숫자만 뽑아 씁니다.

<!-- 돈 · 전화번호 · 카드번호처럼 계산하지 않는 숫자 -->
<label for="amount">정산 금액</label>
<input id="amount" type="text" inputmode="numeric"
       autocomplete="off" value="1,284,000">
<span>원</span>          <!-- 단위는 칸 밖에 -->

// 보낼 때는 숫자만 남긴다
const raw = input.value.replace(/[^\d]/g, '');

input { text-align: right; font-variant-numeric: tabular-nums; }

/* type=number를 쓴다면 휠만은 막는다 */
el.addEventListener('wheel', e => el === document.activeElement && e.preventDefault());

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

서버에는 숫자만 보내기서버에는 "1,284,000"이 아니라 1284000으로 보냅니다. 쉼표 같은 서식은 화면에서 붙입니다.
금액은 정수로 다루기금액을 소수점 실수로 다루면 반올림 오차가 생기기 때문에, 원 단위 정수나 문자열로 다루는 편이 안전합니다.
값의 범위를 서버가 알려 주기서버가 min·max를 내려 주면 화면에서 범위 밖의 값을 미리 막을 수 있습니다.

10 플랫폼마다 다른 이름웹 · iOS · 안드로이드에서 부르는 이름

숫자 자판을 띄우는 방법은 플랫폼마다 다릅니다.

웹inputmode
1,284,000원
type과 inputmode가 따로 있어서 둘을 골라 조합할 수 있습니다.
iOSkeyboardType
.numberPad나 .decimalPad를 칸마다 골라 지정합니다.
안드로이드inputType
numberDecimal 같은 값으로 자판 종류를 정하며, 이 역시 칸마다 지정합니다.

플랫폼 차이 때문에 자주 생기는 문제 — 앱에서는 처음부터 자판 종류와 값의 타입을 따로 정하기 때문에, 숫자 자판을 띄워도 값은 문자열로 받습니다. 웹에 inputmode가 생긴 것도 같은 생각에서 나왔고, 그 덕분에 type=text 칸에 숫자 자판을 띄우는 조합을 쓸 수 있게 되었습니다. 돈이나 전화번호를 받을 때는 이 조합이 가장 잘 맞습니다.
