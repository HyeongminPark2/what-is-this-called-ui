2 이름부르는 말이 여러 개다

한국어위험한 동작, 파괴적 동작, 삭제 확인
영어destructive action, confirmation dialog, type-to-confirm
같이 쓰는 말되묻는 창이 확인 다이얼로그, 이름을 그대로 치게 하는 것이 타이프 투 컨펌(type-to-confirm)입니다. 지운 것을 잠시 두는 곳이 휴지통·소프트 삭제(soft delete), 되돌릴 틈을 주는 줄이 언두 스낵바입니다. 설정 맨 아래 모아 두는 자리는 위험 구역(danger zone)입니다.
자주 잘못 부름경고 — 경고는 알리는 것이고, 이건 막는 장치입니다.
모달 — 모달은 띄우는 방식이고, 확인은 그 안에 담는 내용입니다.
되돌리기 — 되돌리기는 확인의 반대말이 아니라 대안입니다. 둘 다 쓰면 과합니다.

4 확인 방식 넷무엇을 막고 무엇을 치르나

5 해부도부분 이름이 제일 안 알려진 지식

무엇이 사라지는지 — ‘정산 내역 128건이 함께’
되돌릴 수 있는지 — 있으면 그렇게 적는다
취소삭제
버튼 이름은 동사로 — ‘확인’이 아니라 ‘삭제’
되돌리기가 있으면 묻지 않아도 된다
세 번째부터는 읽지 않고 누른다
  1. 무엇이 사라지나 숫자로'정산 내역 128건이 함께'. 막연하면 안 읽는다
  2. 되돌릴 수 있나 그대로 적는다있으면 쓰고, 없으면 없다고 쓴다
  3. 버튼 두 개 취소 · 삭제취소가 기본이고 약하게
  4. 버튼 이름 동사로'확인'이 아니라 '삭제'. 무엇을 하는지 적는다
  5. 되돌리기 묻기의 대안있으면 안 물어도 된다. 둘 다는 과하다
  6. 길들여짐 세 번째부터되물을수록 안 읽고 누른다

확인 창은 쓸수록 약해집니다. 세 번쯤 보고 나면 문구를 읽지 않고 오른쪽 버튼을 누르는 손버릇이 생기고, 그때부터는 창이 있어도 사고가 납니다. 그래서 되돌릴 수 있는 일에는 묻지 말고 되돌리기를 주고, 확인 창은 정말 되돌릴 수 없는 것에만 남겨 두는 쪽이 좋습니다 — 드물게 뜨는 창이라야 읽힙니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 되돌릴 수 있는 일 → 묻지 말고 되돌리기
  • 되돌릴 수 없는 일 → 한 번 묻기
  • 큰 것을 지울 때 → 이름 치기나 메일 한 단계 더

이럴 때는 안 쓴다

  • 모든 것에 확인 창 — 안 읽고 누르게 된다
  • '확인 / 취소' — 무엇을 확인하는지 모른다
  • 삭제를 기본 버튼으로 — 엔터로 지워진다
  • 되돌리기와 확인 창을 둘 다 — 번거롭기만 하다

대신 이걸 — 알리기만 하면 오류 메시지, 결과와 되돌리기는 토스트, 여러 건이면 일괄 선택의 범위 확인.

8 최소 마크업과 키보드이 확인의 계약서

<dialog>를 쓰고 취소를 기본으로 둡니다.

<dialog id="confirm" aria-labelledby="t" aria-describedby="d">
  <h2 id="t">‘모란상회’를 지울까요?</h2>
  <p id="d">정산 내역 128건이 함께 지워집니다. 되돌릴 수 없습니다.</p>

  <form method="dialog">
    <button value="cancel" autofocus>취소</button>
    <button value="delete" class="danger">삭제</button>
  </form>
</dialog>

// 되돌릴 수 있으면 묻지 말고 — 5초 뒤에 진짜로 보낸다
function removeWithUndo(id) {
  hideFromList(id);
  const t = setTimeout(() => api.remove(id), 5000);
  showUndoBar(() => { clearTimeout(t); restore(id); });
}

aria-describedby무엇이 사라지는지까지 읽히게 한다. 제목만 읽히면 모른다

되돌리기 줄은 role="status"토스트와 같다. 초점을 뺏지 않는다

9 서버 쪽으로 치면백엔드 감각으로 번역

되돌리기는 안 보내는 것으로화면에서 지우고 5초 뒤에 보내면 되돌리기는 타이머 취소뿐입니다. 가장 간단합니다.
소프트 삭제바로 못 미루면 deleted_at을 찍어 두고 나중에 비웁니다. 대신 모든 질의가 그 칸을 봐야 합니다.
딸린 것들가맹점을 지우면 정산·사용자가 같이 지워집니다. 무엇이 딸려 가는지를 화면 문구에도 적습니다.
권한을 다시 본다삭제는 서버가 다시 확인합니다. 버튼을 숨긴 것은 방어가 아닙니다.
기록을 남긴다누가 언제 무엇을 지웠는지 남겨 두면 복구 요청에 답할 수 있습니다.
되돌릴 수 없는 것계정·조직 삭제는 유예 기간(30일)을 두는 쪽이 민원이 적습니다.
