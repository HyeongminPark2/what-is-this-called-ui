Multi-select

고르는 것보다 고른 것을 보이는 쪽이 어렵습니다 — 알약은 늘어나고, 숫자는 모호합니다.

알약으로 늘어놓으면 무엇을 골랐는지는 한눈에 보이지만 줄이 늘어납니다 — 데모가 고른 것 칸의 높이를 재서 적습니다.
'최대 보일 알약'을 줄이면 +N 으로 접힙니다. 숫자만 보이는 쪽은 높이가 안 변하지만 무엇을 골랐는지 모릅니다.
브라우저 기본 multiple 셀렉트는 Ctrl 을 눌러야 여러 개가 골라집니다 — 체크박스 목록이 훨씬 분명합니다.

2 이름부르는 말이 여러 개다

한국어여러 개 고르기, 다중 선택, 멀티 셀렉트
영어multi-select, multiple selection, token input
같이 쓰는 말고른 것이 알약으로 쌓이는 꼴은 토큰 입력(token input), 쳐서 걸러 가며 고르는 꼴은 멀티 콤보박스입니다. 넘치는 것을 +N 으로 접는 것을 오버플로 카운트라 합니다.
자주 잘못 부름체크박스 — 체크박스는 다 보이는 쪽입니다.
콤보박스 — 콤보박스는 하나만 고릅니다.
태그 — 태그는 보여 주는 부품입니다.

5 해부도부분 이름이 제일 안 알려진 지식

고른 것 — 알약으로 보이면 무엇인지 안다
+N — 넘치면 접어 높이를 지킨다
목록 — 체크박스가 가장 분명하다
기본 multiple 셀렉트는 Ctrl 을 눌러야 한다
숫자만 보이면 높이는 고정이지만 이름을 모른다
많으면 검색 칸을 붙인다
  1. 고른 것 알약으로무엇인지 보인다
  2. +N 넘치면 접기높이를 지킨다
  3. 목록 체크박스가장 분명하다
  4. multiple Ctrl 필요모르는 사람이 많다
  5. 숫자만 높이 고정대신 이름을 모른다
  6. 검색 많을 때스무 개 넘으면

브라우저 기본 <select multiple> 은 거의 쓰이지 않습니다 — Ctrl(⌘)을 누른 채 눌러야 여러 개가 골라지는데, 그걸 아는 사람이 적고 어디에도 안 적혀 있습니다. 게다가 실수로 그냥 누르면 고른 것이 전부 풀립니다.
그래서 체크박스 목록이나 토큰 입력으로 만드는 편이 낫고, 항목이 스무 개를 넘으면 검색 칸을 붙입니다. 고른 것을 위에 알약으로 쌓아 두면 목록을 안 열고도 무엇을 골랐는지 알 수 있습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 고른 것을 알약으로 보이기
  • 넘치면 +N 으로 접기
  • 스무 개 넘으면 검색 칸 붙이기

이럴 때는 안 쓴다

  • <select multiple> 그냥 쓰기 — Ctrl 을 모른다
  • 숫자만 보이기 — 확인하려고 다시 연다
  • 알약을 다 늘어놓기 — 칸이 화면을 먹는다
  • 고른 것을 지울 길을 안 주기

대신 이걸 — 다 보이면 체크박스, 하나만 고르면 콤보박스, 보여 주기만 하면 태그, 거르기 화면은 필터와 패싯.

8 최소 마크업과 키보드이 부품의 계약서

체크박스 목록이 가장 분명합니다. 고른 것은 위에 알약으로 쌓습니다.

<fieldset>
  <legend>정산에 넣을 가게</legend>

  <ul class="tokens" aria-label="고른 가게">
    <li>모란상회
      <button type="button" aria-label="모란상회 빼기">✕</button>
    </li>
  </ul>

  <label><input type="checkbox" value="moran" checked> 모란상회</label>
  <label><input type="checkbox" value="hanbit"> 한빛아웃도어</label>
</fieldset>
키일어나야 하는 일
Space체크박스를 켜고 끈다
Tab체크박스 하나하나에 멈춘다 — 많으면 묶음을 접는다
Backspace토큰 입력에서 마지막 알약을 지우는 관습
<fieldset>묶음에 이름을 준다 — 무엇을 고르는지가 들린다
aria-label✕ 에 무엇을 빼는지 적는다
확인하는 법소리로 들어 몇 개 골랐는지 알 수 있는지 본다

9 서버 쪽으로 치면백엔드 감각으로 번역

배열로 받는다shops: ["moran", "hanbit"] — 쉼표로 이은 문자열은 이름에 쉼표가 있으면 깨집니다.
최대 개수한도가 있으면 서버가 줘야 화면이 미리 막을 수 있습니다.
전체 선택'조건에 맞는 전부'는 개수만 주고받는 편이 가볍습니다 — 일괄 선택 참고.
