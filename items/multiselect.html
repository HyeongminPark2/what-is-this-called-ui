여러 개 고르기

Multi-select

여러 개 고르기에서는 고르는 동작보다 고른 것을 보여 주는 방법이 더 어렵습니다. 고른 것을 알약으로 늘어놓으면 칸이 점점 길어지고, 개수만 숫자로 보여 주면 무엇을 골랐는지 알 수 없기 때문입니다.

고른 것을 알약으로 늘어놓으면 무엇을 골랐는지 한눈에 보이지만 줄 수가 늘어납니다. 데모가 고른 것 칸의 높이를 재서 적어 주니 확인해 보세요.
'한 번에 보일 알약 수'를 줄이면 넘치는 알약이 +N으로 접힙니다. 개수만 숫자로 보여 주면 높이는 변하지 않지만 무엇을 골랐는지 알 수 없습니다.
브라우저 기본 multiple 셀렉트는 Ctrl을 누른 채 눌러야 여러 개가 골라지기 때문에, 체크박스 목록으로 만드는 편이 훨씬 알아보기 쉽습니다.

2 이름같은 것을 부르는 여러 이름

한국어여러 개 고르기, 다중 선택, 멀티 셀렉트
영어multi-select, multiple selection, token input
같이 쓰는 말고른 것이 알약으로 쌓이는 꼴은 토큰 입력(token input), 글자를 쳐서 목록을 걸러 가며 고르는 꼴은 멀티 콤보박스라고 부릅니다. 넘치는 알약을 +N으로 접는 것은 오버플로 카운트라고 합니다.
자주 잘못 부르는 이름체크박스 — 체크박스는 고를 수 있는 항목이 처음부터 모두 보이는 부품입니다.
콤보박스 — 콤보박스는 하나만 고릅니다.
태그 — 태그는 고르는 부품이 아니라 값을 보여 주는 부품입니다.

5 해부도부분마다 붙은 이름

고른 것이 알약으로 보이면 무엇인지 앎
넘치면 +N으로 접어 높이를 유지함
목록은 체크박스가 가장 분명함
기본 multiple 셀렉트는 Ctrl을 눌러야 함
숫자만 보이면 높이는 고정이지만 이름을 모름
항목이 많으면 검색 칸을 붙임
  1. 고른 것 알약으로 보여 주기고른 것이 무엇인지 이름으로 보입니다
  2. +N 넘치면 접기넘치는 알약을 접어 칸 높이가 늘어나지 않게 합니다
  3. 목록 체크박스로 만들기무엇이 골라졌는지 가장 분명하게 보입니다
  4. multiple Ctrl을 눌러야 함Ctrl을 눌러야 한다는 것을 모르는 사람이 많습니다
  5. 숫자만 높이는 고정됨칸 높이는 일정하지만 고른 것의 이름을 알 수 없습니다
  6. 검색 항목이 많을 때항목이 스무 개를 넘으면 검색 칸을 붙입니다

브라우저 기본 <select multiple>은 실제 화면에서 거의 쓰이지 않습니다. Ctrl(⌘)을 누른 채 눌러야 여러 개가 골라지는데, 이 방법을 아는 사람이 적고 화면 어디에도 안내가 없기 때문입니다. 게다가 Ctrl 없이 한 항목을 그냥 누르면 이미 고른 것이 모두 풀립니다.
그래서 체크박스 목록이나 토큰 입력으로 만드는 편이 낫고, 항목이 스무 개를 넘으면 검색 칸을 붙입니다. 고른 것을 목록 위에 알약으로 쌓아 두면 목록을 열지 않고도 무엇을 골랐는지 알 수 있습니다.

6 쓸 때 / 안 쓸 때

여러 개 고르기를 쓰는 경우

  • 고른 것을 알약으로 보여 주기
  • 알약이 넘치면 +N으로 접기
  • 항목이 스무 개를 넘으면 검색 칸 붙이기

여러 개 고르기를 쓰지 않는 경우

  • <select multiple>을 그대로 쓰기. 사용자 대부분이 Ctrl을 눌러야 한다는 것을 모릅니다
  • 개수를 숫자로만 보여 주기. 고른 것을 확인하려고 목록을 다시 열어야 합니다
  • 알약을 모두 늘어놓기. 칸이 길어져 화면을 많이 차지합니다
  • 고른 것을 빼는 방법을 주지 않기

여러 개 고르기 대신 다른 것을 써야 하는 경우 — 항목을 모두 늘어놓아도 자리가 충분하면 체크박스를 쓰고, 하나만 고르면 되는 칸에는 콤보박스를 씁니다. 고르는 기능 없이 값을 보여 주기만 하려면 태그가 맞고, 조건을 골라 목록을 거르는 화면은 필터와 패싯에서 다룹니다.

8 최소 마크업과 키보드구현할 때 지킬 최소 규칙

체크박스 목록으로 만들면 무엇이 골라졌는지 가장 분명하게 보입니다. 고른 것은 목록 위에 알약으로 쌓습니다.

  <ul class="tokens" aria-label="고른 가게">
    <li>모란상회
      <button type="button" aria-label="모란상회 빼기">✕</button>
    </li>
  </ul>

  <label><input type="checkbox" value="moran" checked> 모란상회</label>
  <label><input type="checkbox" value="hanbit"> 한빛아웃도어</label>
</fieldset>
키와 마크업그때 일어나야 하는 일

Tab체크박스 하나하나에 멈추기 때문에, 항목이 많으면 묶음을 접어 둡니다
Backspace토큰 입력에서는 관습적으로 마지막 알약을 지웁니다
<fieldset>묶음에 이름을 붙여 스크린 리더가 무엇을 고르는 묶음인지 읽어 줍니다
aria-label✕ 단추에 무엇을 빼는지 적습니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

고른 값은 배열로 주고받기고른 값은 shops: ["moran", "hanbit"]처럼 배열로 주고받습니다. 쉼표로 이은 문자열로 보내면 이름에 쉼표가 든 값에서 나누는 자리가 틀어집니다.
고를 수 있는 최대 개수를 서버가 알려 주기고를 수 있는 개수에 한도가 있으면 서버가 그 값을 내려 줘야 화면에서 미리 막을 수 있습니다.
조건에 맞는 전부를 고를 때'조건에 맞는 전부'를 고를 때는 항목 목록 대신 개수만 주고받는 편이 가볍습니다. 자세한 내용은 일괄 선택 항목에 있습니다.
