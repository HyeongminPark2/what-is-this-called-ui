아이콘 크기

Icon size scale

아이콘은 글자 크기가 아니라 줄 높이에 맞춥니다. 그리고 그림 크기와 누르는 자리는 다른 값입니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

그림은 viewBox 24 에 선 굵기 1.5 로 그렸습니다. 그대로 줄이면 선도 같이 얇아져 12px 에서는 0.75px 가 됩니다 — 화면에서 흐려 보이는 이유입니다. '선 굵기를 고정'을 켜면 1.5px 로 되돌아옵니다.
인라인 SVG 는 글자처럼 베이스라인에 앉아 글자 가운데보다 몇 px 위로 뜹니다. 눈으로는 잘 안 보이는데, 아이콘과 글자를 나란히 두는 자리마다 생기는 어긋남입니다.

2 이름부르는 말이 여러 개다

한국어아이콘 크기, 아이콘 단
영어icon size, icon scale, optical size
같이 쓰는 말선으로 그린 것이 라인 아이콘(outline · stroke), 면으로 채운 것이 솔리드(filled)입니다. 크기마다 다시 그린 그림을 쓰는 것을 광학 크기(optical size)라 하고, Material Symbols 는 이것을 opsz 축으로 넣어 두었습니다.
자주 잘못 부름터치 타깃 — 터치 타깃은 누르는 넓이이고 이건 그림의 크기입니다.
아이콘 글꼴 — 아이콘 글꼴은 그림을 글자로 다루는 방식입니다.
파비콘 — 브라우저 탭에 쓰는 아이콘이라 별개입니다.

토큰은 눈에 보이는 부품이 아니라 값의 약속입니다. 이 네 가지만 물어보면 어떤 약속인지 갈립니다.

테두리와 구분선가르는 선선 1~2종목록 · 카드 · 표선이 두 겹이 되고 화면이 어수선하다
불투명도흐린 정도2~3단비활성 · 가림막 · 흐린 글글이 안 읽히고 z-index 가 안 먹는다
아이콘 크기그림의 크기3~4단(16·20·24)버튼 · 목록 · 앱바선이 흐리고 글자와 가운데가 안 맞는다
상태 색성공 · 주의 · 오류 · 정보4가지 × 3자리알림 · 배지 · 입력 오류색을 못 보면 상태를 못 읽는다
토큰 이름 짓기이름의 규칙층 3겹토큰 전부이름과 값이 어긋나 아무도 못 고친다

한 줄로 — 세 단이면 충분합니다 — 16 · 20 · 24. 그리고 누르는 자리는 언제나 44px 입니다.

4 단자리마다 쓰는 크기가 있다

5 해부도부분 이름이 제일 안 알려진 지식

viewBox="0 0 24 24" ← 그린 좌표계
width · height ← 화면에서의 크기
stroke-width 는 같이 줄어든다
stroke="currentColor" ← 글자색을 따라간다
인라인 SVG 는 베이스라인에 앉는다
누르는 자리는 44px ← 그림 크기와 별개
  1. viewBox 그린 좌표계보통 24 로 통일한다
  2. width·height 화면 크기여기만 바꾼다
  3. stroke-width 같이 줄어듦작게 쓰면 흐려진다
  4. currentColor 글자색 따라감색을 따로 안 적어도 된다
  5. 베이스라인 위로 뜸display: block으로 막는다
  6. 누르는 자리 44px그림 크기와 따로 둔다

24 로 그려 16 으로 줄이는 것이 가장 흔한 실수입니다. 모양은 같아 보여도 선이 1.5 에서 1.0 으로 얇아져 다른 아이콘처럼 보입니다. 같은 줄에 24px 짜리와 16px 짜리를 나란히 두면 굵기가 달라 금방 티가 납니다.
해법은 둘입니다 — 크기마다 굵기를 되돌리거나, 아예 크기별로 다시 그린 그림을 쓰는 것입니다. 후자가 광학 크기이고, 작은 아이콘일수록 획을 덜어내 더 또렷해집니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 크기를 16 · 20 · 24 세 단으로 두기
  • SVG 에 display: block을 깔아 베이스라인 어긋남 막기
  • stroke="currentColor"로 글자색을 따라가게 하기

이럴 때는 안 쓴다

  • 24px 그림을 12px 로 줄여 쓰기 — 선이 흐려진다
  • 아이콘 크기를 누르는 자리로 쓰기 — 44px 미달이 된다
  • 같은 줄에 굵기가 다른 아이콘 섞기
  • 아이콘만 두고 이름을 안 붙이기 — 소리로는 아무것도 안 들린다

대신 이걸 — 누르는 넓이는 터치 타깃, 글자로 다루는 법은 아이콘 글꼴, 이름 붙이기는 이름 붙이기.

8 최소 코드와 규칙이 단의 계약서

크기는 단으로, 굵기는 크기에 맞춰 되돌립니다.

/* 세 단이면 거의 다 덮는다 */
:root { --icon-1: 16px; --icon-2: 20px; --icon-3: 24px; }

/* 베이스라인에 안 앉게 — 이 한 줄이 가운데 어긋남을 없앤다 */
svg { display: block; }

/* 누르는 자리는 그림 크기와 따로 둔다 */
.icon-btn { display: grid; place-items: center;
  min-width: 44px; min-height: 44px; }

<button class="icon-btn" aria-label="영수증 내려받기">
  <svg width="20" height="20" viewBox="0 0 24 24"
       stroke="currentColor" stroke-width="1.8" aria-hidden="true">…</svg>
</button>
키일어나야 하는 일
aria-hidden="true"그림은 안 읽는다. 버튼 쪽에 이름을 붙인다
aria-label아이콘만 있는 버튼에는 반드시 필요하다
currentColor호버·비활성에서 색이 저절로 따라온다
vector-effectnon-scaling-stroke — 확대해도 선 굵기를 지킨다
1em글자 크기를 따라가게 하는 법. 줄 높이와는 다르니 주의
확인하는 법두 크기를 나란히 놓고 선 굵기가 같아 보이는지 본다

9 서버 쪽으로 치면백엔드 감각으로 번역

서버와는 상관없다아이콘은 화면이 가진 자산입니다. 다만 상태 이름은 서버가 정합니다.
상태 이름status: "pending" 처럼 이름으로 주면 화면이 아이콘을 고릅니다 — 아이콘 파일명을 주고받지 않습니다.

10 플랫폼마다 다른 이름같은 부품, 다른 말

20px
정해진 규격이 없습니다. 쓰는 아이콘 묶음(Lucide · Heroicons)의 viewBox 24 를 따라가는 편입니다.
iOSSF Symbols
글자와 같은 축으로 다룹니다. 굵기·크기가 본문 글꼴을 따라 저절로 맞춰집니다.
안드로이드24dp 기본
24dp 가 기본이고 그 안에 20dp 그림이 들어갑니다 — 바깥 2dp 가 여백입니다.

자주 생기는 사고 — iOS 의 SF Symbols 는 아이콘을 글자처럼 다뤄, 글자 크기를 키우면 아이콘도 같이 커지고 굵기도 따라옵니다. 웹에는 그런 장치가 없어서 단을 손으로 정해 둬야 합니다. 안드로이드의 24dp 안에 20dp 그림이라는 규칙은 웹에서도 쓸 만합니다 — 아이콘 둘레에 여백을 넣어 두면 어느 자리에 놓아도 서로 같은 크기로 보입니다.
