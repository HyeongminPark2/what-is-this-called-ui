아이콘 크기

Icon size scale

아이콘 크기는 글자 크기가 아니라 줄 높이에 맞춥니다. 또 아이콘의 그림 크기와 누르는 자리의 크기는 따로 정하는 값입니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

이 아이콘은 viewBox 24에 선 굵기 1.5로 그렸습니다. 그대로 줄이면 선도 함께 얇아져서 12px에서는 0.75px이 되는데, 작은 아이콘이 화면에서 흐려 보이는 이유가 이것입니다. '선 굵기를 고정'을 켜면 선이 다시 1.5px로 그려집니다.
인라인 SVG는 글자처럼 베이스라인 위에 놓여 글자의 세로 가운데보다 몇 px 위로 뜹니다. 눈으로는 잘 보이지 않지만, 아이콘과 글자를 나란히 두는 자리마다 이 어긋남이 생깁니다.

2 이름같은 것을 부르는 여러 이름

한국어아이콘 크기, 아이콘 단
영어icon size, icon scale, optical size
같이 쓰는 말선으로 그린 아이콘은 라인 아이콘(outline · stroke), 면을 채운 아이콘은 솔리드(filled)라고 합니다. 크기마다 따로 다시 그린 그림을 쓰는 방식은 광학 크기(optical size)라고 하는데, Material Symbols는 이것을 opsz 축으로 넣어 두었습니다.
자주 잘못 부르는 이름터치 타깃 — 터치 타깃은 누르는 넓이이고, 아이콘 크기는 그림의 크기입니다.
아이콘 글꼴 — 아이콘 글꼴은 크기가 아니라 그림을 글자로 다루는 방식을 가리킵니다.
파비콘 — 파비콘은 브라우저 탭에 쓰는 아이콘이라 화면 안 아이콘의 크기 단과는 별개입니다.

3 아이콘 크기 단계별 쓰는 자리자리마다 쓰는 크기

4 해부도부분마다 붙은 이름

viewBox="0 0 24 24" ← 그린 좌표계
width · height ← 화면에서의 크기
stroke-width도 같이 줄어듦
stroke="currentColor" ← 글자색을 따라감
인라인 SVG는 베이스라인에 놓임
누르는 자리는 44px ← 그림 크기와 별개
  1. viewBox 그린 좌표계보통 24로 통일합니다
  2. width·height 화면 크기크기를 바꿀 때는 이 값만 바꿉니다
  3. stroke-width 같이 줄어듦아이콘을 작게 쓰면 선이 얇아져 흐려 보입니다
  4. currentColor 글자색 따라감글자색을 따라가므로 아이콘 색을 따로 적지 않아도 됩니다
  5. 베이스라인 위로 뜸display: block을 주면 위로 뜨지 않습니다
  6. 누르는 자리 44px그림 크기와 따로 정합니다

가장 흔한 실수는 24로 그린 아이콘을 16으로 줄여 쓰는 것입니다. 모양은 같아 보여도 선이 1.5에서 1.0으로 얇아져서 다른 아이콘처럼 보입니다. 그래서 같은 줄에 24px짜리와 16px짜리를 나란히 두면 굵기가 달라 금방 티가 납니다.
해결 방법은 두 가지로, 크기마다 선 굵기를 원래대로 되돌리거나 아예 크기별로 다시 그린 그림을 쓰는 것입니다. 뒤의 방법이 광학 크기인데, 작은 아이콘일수록 획을 덜어 내서 더 또렷하게 보이도록 그립니다.

5 쓸 때 / 안 쓸 때

아이콘 크기를 정할 때 지킬 것

  • 크기를 16 · 20 · 24 세 단으로 두기
  • SVG에 display: block을 주어 베이스라인 어긋남 막기
  • stroke="currentColor"로 글자색을 따라가게 하기

아이콘 크기를 정할 때 피할 것

  • 24px 그림을 12px로 줄여 쓰기. 선이 얇아져 흐려 보입니다
  • 아이콘 크기를 그대로 누르는 자리로 쓰기. 누르는 자리가 44px보다 작아집니다
  • 같은 줄에 굵기가 다른 아이콘 섞기
  • 아이콘만 두고 이름을 붙이지 않기. 스크린 리더로는 이 버튼이 무엇인지 알 수 없습니다

함께 보면 좋은 항목 — 누르는 넓이는 터치 타깃 항목에서, 아이콘을 글자로 다루는 방식은 아이콘 글꼴 항목에서 다룹니다. 아이콘 버튼에 이름을 붙이는 방법은 이름 붙이기 항목을 봅니다.

6 자주 보는 모습구조만 따라 그린 재현 그림

7 최소 코드와 지킬 규칙아이콘 크기를 코드로 옮기는 방법

크기는 정해 둔 단에서 고르고, 선 굵기는 크기에 맞춰 원래대로 되돌립니다.

/* 세 단이면 거의 모든 자리에 충분하다 */
:root { --icon-1: 16px; --icon-2: 20px; --icon-3: 24px; }

/* 베이스라인에 놓이지 않게 해서 세로 가운데 어긋남을 없앤다 */
svg { display: block; }

/* 누르는 자리는 그림 크기와 따로 둔다 */
.icon-btn { display: grid; place-items: center;
  min-width: 44px; min-height: 44px; }

<button class="icon-btn" aria-label="영수증 내려받기">
  <svg width="20" height="20" viewBox="0 0 24 24"
       stroke="currentColor" stroke-width="1.8" aria-hidden="true">…</svg>
</button>
속성과 값쓰면 일어나는 일
aria-hidden="true"스크린 리더가 그림은 읽지 않게 하고, 이름은 버튼 쪽에 붙입니다
aria-label아이콘만 있는 버튼에는 반드시 필요합니다
currentColor호버나 비활성 상태에서 글자색이 바뀌면 아이콘 색도 저절로 바뀝니다
vector-effectnon-scaling-stroke를 주면 크기를 바꿔도 선 굵기가 그대로 유지됩니다
1em아이콘이 글자 크기를 따라가게 하는 방법입니다. 다만 줄 높이와는 다른 값이니 주의합니다
확인하는 방법크기가 다른 두 아이콘을 나란히 놓고 선 굵기가 같아 보이는지 봅니다

8 서버 쪽으로 치면백엔드 개념과 짝지어 보기

화면 쪽에 두는 아이콘 파일아이콘 파일은 화면 쪽에 두는 자산입니다. 다만 어떤 아이콘을 보여 줄지 가르는 상태 이름은 서버가 정합니다.
서버는 상태 이름만 보내기서버가 status: "pending"처럼 상태 이름을 보내면 화면이 거기에 맞는 아이콘을 고릅니다. 아이콘 파일명을 직접 주고받지는 않습니다.

9 플랫폼마다 다른 이름웹 · iOS · 안드로이드에서 부르는 이름

기본 단이 플랫폼마다 다릅니다.

웹16 · 20 · 24
20px
정해진 규격이 없어서, 보통 쓰고 있는 아이콘 묶음(Lucide · Heroicons)의 viewBox 24를 따릅니다.
iOSSF Symbols
아이콘을 글자와 같은 방식으로 다룹니다. 그래서 아이콘의 굵기와 크기가 본문 글꼴에 맞춰 저절로 정해집니다.
안드로이드24dp 기본
24dp가 기본 크기이고, 그 안에 20dp 그림이 들어가서 바깥쪽 2dp가 여백이 됩니다.

플랫폼 차이 때문에 자주 생기는 문제 — iOS의 SF Symbols는 아이콘을 글자처럼 다루기 때문에, 글자 크기를 키우면 아이콘도 함께 커지고 굵기도 글자에 맞춰집니다. 웹에는 그런 장치가 없어서 단을 직접 정해 두어야 합니다. 안드로이드의 24dp 안에 20dp 그림이라는 규칙은 웹에서도 쓸 만합니다. 아이콘 둘레에 여백을 넣어 두면 어느 자리에 놓아도 아이콘끼리 같은 크기로 보입니다.
