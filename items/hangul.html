한글 조판

Korean typography

브라우저의 기본 줄바꿈은 영문 기준입니다. 그대로 두면 한글은 어절 한가운데서 줄이 넘어갑니다.

칸 너비를 줄여 보세요. 세 상자 아래에 어절이 몇 군데 쪼개졌는지 재서 알려 줍니다 — 기본값(normal)과 break-all은 '입금됩 / 니다'처럼 끊기고, keep-all만 어절을 지킵니다.
아래 두 상자는 긴 영문 덩어리가 섞였을 때입니다. keep-all만 쓰면 칸을 밀어내고(넘친 px 을 재서 보여 줍니다), overflow-wrap을 함께 써야 막힙니다.

2 이름부르는 말이 여러 개다

한국어한글 조판, 한글 타이포그래피, 줄바꿈
영어Korean typography, word-break, line breaking, CJK
같이 쓰는 말띄어쓰기로 나뉘는 덩어리를 어절이라 하고, 줄을 넘길 수 있는 자리를 줄바꿈 기회(line break opportunity)라 합니다. 한중일 글자를 묶어 CJK라 부르고, 글자가 네모 칸에 꽉 차는 성질 때문에 전각(full-width)이라 합니다.
자주 잘못 부름word-break: break-all — 이름 때문에 '단어를 지킨다'로 오해하기 쉬운데 반대로 아무 데서나 쪼갭니다. 한국어 화면에 쓰면 안 됩니다.
white-space: nowrap — 줄바꿈을 아예 막는 것입니다. 어절 보호와 다릅니다.
자간 — 한글이 답답해 보이는 이유는 대개 자간이 아니라 행간입니다.

5 해부도부분 이름이 제일 안 알려진 지식

정산 요청이 승인되면 영업일 기준 2일 안에 등록하신 계좌로 입금됩니다.

word-break: keep-all
overflow-wrap: break-word
line-height: 1.8 — 받침 때문에 더 넓게
letter-spacing: 0 — 한글은 건드리지 않는다
lang="ko" — 줄바꿈·글꼴 고르기의 기준
  1. 한국어 문단 paragraph이 네댓 줄에 걸리는 값이 아래의 다섯 가지다
  2. 어절 지키기 word-break: keep-all한국어 화면의 첫 줄. 띄어쓰기에서만 줄을 넘긴다
  3. 긴 덩어리 쪼개기 overflow-wrap: break-word주문번호·URL 처럼 띄어쓰기 없는 영문만 어쩔 수 없이 쪼갠다
  4. 행간 line-height한글은 받침이 있어 글자가 아래로 길다. 영문 기준보다 한 단계 넓게
  5. 자간 letter-spacing본문은 0. 한글은 조금만 벌려도 낱글자로 흩어진다
  6. 언어 표시 lang="ko"줄바꿈 규칙·글꼴 고르기·스크린 리더 발음이 이것부터 갈린다

keep-all과 overflow-wrap은 둘 다 있어야 합니다. keep-all 만 있으면 긴 영문 한 덩어리가 칸을 밀어내 가로 스크롤을 만들고, overflow-wrap 만 있으면 한글이 여전히 어절 한가운데서 끊깁니다. 이 도감도 base.css 맨 위에 두 줄을 함께 깔아 두고 시작합니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 한국어가 들어가는 모든 화면 — 예외가 없습니다
  • 좁은 칸에 긴 문장이 들어갈 때 — 카드 제목, 알림, 빈 상태 문구
  • 영문·주문번호·URL 이 섞이는 글

이럴 때는 안 쓴다

  • break-all을 쓰는 것 — 이름만 보고 고르면 정반대가 됩니다
  • 문장을 <br>로 손수 끊는 것 — 화면 폭이 바뀌면 엉뚱한 데서 끊깁니다
  • 자간을 벌려 '시원하게' 만드는 것 — 한글은 흩어져 보입니다
  • lang을 안 적는 것 — 브라우저가 어느 규칙을 쓸지 모릅니다

대신 이걸 — 줄 사이는 행간, 글자 사이는 자간, 넘친 글의 끝은 말줄임이 맡습니다.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙한국어 화면의 첫 두 줄

두 줄이면 거의 끝납니다. 문서 맨 위에 한 번 깔고 시작합니다.

<html lang="ko">   <!-- 줄바꿈·글꼴·발음의 기준 -->

body {
  word-break: keep-all;        /* 어절을 지킨다 */
  overflow-wrap: break-word;   /* 긴 영문 덩어리만 쪼갠다 */
  line-height: 1.7;             /* 받침 때문에 넓게 */
}

/* 제목은 좁게, 자간만 살짝 */
h1, h2 { line-height: 1.3; letter-spacing: -0.02em; }

/* 본문 자간은 건드리지 않는다 */
p { letter-spacing: 0; }
규칙지켜야 하는 것
keep-all을 깐다한국어 화면이면 예외 없이. 이름이 헷갈리는 break-all과 반대다
overflow-wrap을 함께둘 중 하나만 쓰면 절반만 해결된다
lang="ko"줄바꿈 규칙과 글꼴 고르기, 스크린 리더 발음이 여기서 갈린다
행간을 한 단계 넓게영문 기준 1.5 면 한글은 1.7~1.8
<br>로 끊지 않는다폭이 바뀌면 엉뚱한 자리에서 끊긴다. 줄바꿈은 브라우저에 맡긴다
자간은 0본문에서 벌리면 낱글자로 흩어진다. 큰 제목만 조금 좁힌다

9 서버 쪽으로 치면백엔드 감각으로 번역

글 길이는 데이터가 정한다'가맹점명'이 3자일 때와 30자일 때 화면이 다릅니다. 가장 긴 값으로 한 번 그려 보는 것이 최소 테스트입니다.
문장을 쪼개 보내지 않는다'…되면'과 '입금됩니다'를 따로 내려 화면에서 이어 붙이면 번역과 줄바꿈이 둘 다 깨집니다. 문장 단위로 보냅니다.
다국어같은 문장이 영어로는 1.3배, 일본어로는 비슷합니다. 칸 크기를 한국어 기준으로만 잡으면 다른 언어에서 터집니다.
검색과 정렬한글 정렬은 localeCompare('ko')를 써야 'ㄱㄴㄷ' 순이 됩니다. 바이트 순으로 하면 자모가 뒤섞입니다.
글꼴 파일한글은 완성형만 1만 1172자라 파일이 수 MB입니다. 서브셋이 거의 필수입니다 — 웹폰트 참고.
