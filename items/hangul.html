한글 조판

Korean typography

브라우저의 기본 줄바꿈 규칙은 영문 기준이라서, 설정을 그대로 두면 한글은 어절 한가운데서 줄이 넘어갑니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

칸 너비를 줄여 보세요. 세 상자 아래에 어절이 몇 군데 쪼개졌는지 재서 알려 줍니다. 기본값(normal)과 break-all은 '입금됩 / 니다'처럼 어절 중간에서 끊기고, keep-all만 어절을 지킵니다.
아래 두 상자는 긴 영문 덩어리가 섞인 경우입니다. keep-all만 쓰면 영문 덩어리가 칸을 밀어내는데(넘친 px을 재서 보여 줍니다), overflow-wrap을 함께 써야 넘치지 않습니다.

2 이름같은 것을 부르는 여러 이름

한국어한글 조판, 한글 타이포그래피, 줄바꿈
영어Korean typography, word-break, line breaking, CJK
같이 쓰는 말띄어쓰기로 나뉘는 덩어리를 어절이라고 하고, 줄을 넘길 수 있는 자리를 줄바꿈 기회(line break opportunity)라고 합니다. 한중일 글자는 묶어서 CJK라고 부르며, 글자가 네모 칸을 꽉 채우기 때문에 전각(full-width) 글자라고도 합니다.
자주 잘못 부르는 이름word-break: break-all — 이름 때문에 '단어를 지킨다'로 오해하기 쉽지만 실제로는 반대로 아무 데서나 쪼갭니다. 그래서 한국어 화면에 쓰면 안 됩니다.
white-space: nowrap — 줄바꿈을 아예 막는 속성이라서, 어절에서만 줄을 넘기는 어절 보호와는 다릅니다.
자간 — 한글이 답답해 보이는 이유는 대개 자간이 아니라 행간입니다.

3 줄바꿈 설정에 따른 차이같은 글을 줄바꿈 설정만 바꿔 본 모습

4 해부도부분마다 붙은 이름

정산 요청이 승인되면 영업일 기준 2일 안에 등록하신 계좌로 입금됩니다.

word-break: keep-all
overflow-wrap: break-word
line-height: 1.8 받침 때문에 더 넓게 잡음
letter-spacing: 0 한글은 건드리지 않음
lang="ko" 줄바꿈과 글꼴을 고르는 기준
  1. 한국어 문단 paragraph이 네댓 줄짜리 문단에 아래 다섯 가지 값이 함께 적용됩니다
  2. 어절 지키기 word-break: keep-all한국어 화면에서 가장 먼저 적는 줄로, 띄어쓰기 자리에서만 줄을 넘깁니다
  3. 긴 덩어리 쪼개기 overflow-wrap: break-word주문번호나 URL처럼 띄어쓰기 없는 영문이 칸에 들어가지 않을 때만 쪼갭니다
  4. 행간 line-height한글은 받침이 있어 글자가 아래로 길기 때문에 영문 기준보다 한 단계 넓게 잡습니다
  5. 자간 letter-spacing본문은 0으로 둡니다. 한글은 조금만 벌려도 낱글자로 흩어져 보입니다
  6. 언어 표시 lang="ko"브라우저는 이 값을 보고 줄바꿈 규칙과 글꼴, 스크린 리더 발음을 정합니다

keep-all과 overflow-wrap은 둘 다 있어야 합니다. keep-all만 있으면 긴 영문 한 덩어리가 칸을 밀어내 가로 스크롤이 생기고, overflow-wrap만 있으면 한글이 여전히 어절 한가운데서 끊깁니다. 그래서 이 도감도 base.css 맨 위에 두 줄을 함께 적어 두고 시작합니다.

5 쓸 때 / 안 쓸 때

한글 조판 규칙을 적용할 때

  • 한국어가 들어가는 모든 화면을 만들 때. 예외가 없습니다
  • 카드 제목이나 알림, 빈 상태 문구처럼 좁은 칸에 긴 문장이 들어갈 때
  • 영문이나 주문번호, URL이 섞인 글을 보여 줄 때

한글 조판에서 피할 것

  • 어절을 지키려고 break-all을 고를 때. 이름만 보고 고르면 정반대로 동작합니다
  • 문장을 <br>로 직접 끊을 때. 화면 폭이 바뀌면 엉뚱한 자리에서 끊깁니다
  • 자간을 벌려 '시원하게' 보이게 하려 할 때. 한글은 흩어져 보입니다
  • lang을 적지 않을 때. 브라우저가 어느 언어의 규칙을 써야 할지 알 수 없습니다

한글 조판과 이어지는 주제를 다루는 항목 — 줄과 줄 사이의 거리는 행간에서, 글자와 글자 사이의 거리는 자간에서 다룹니다. 칸을 넘친 글의 끝을 처리하는 방법은 말줄임에 있습니다.

6 자주 보는 모습구조만 따라 그린 재현 그림

7 최소 코드와 규칙한국어 화면에 먼저 적는 두 줄

한글 조판은 CSS 두 줄로 대부분 해결됩니다. 문서 맨 위에 한 번 적어 두고 시작합니다.

<html lang="ko">   <!-- 줄바꿈·글꼴·발음의 기준 -->

body {
  word-break: keep-all;        /* 어절을 지킨다 */
  overflow-wrap: break-word;   /* 긴 영문 덩어리만 쪼갠다 */
  line-height: 1.7;             /* 받침 때문에 넓게 */
}

/* 제목은 좁게, 자간만 살짝 */
h1, h2 { line-height: 1.3; letter-spacing: -0.02em; }

/* 본문 자간은 건드리지 않는다 */
p { letter-spacing: 0; }
지킬 규칙지키는 방법
keep-all을 기본으로 적기한국어 화면이면 예외 없이 씁니다. 이름이 헷갈리는 break-all과는 반대로 동작합니다
overflow-wrap을 함께 적기둘 중 하나만 쓰면 어절 쪼개짐과 영문 넘침 가운데 하나만 해결됩니다
lang="ko" 적어 두기브라우저가 이 값을 보고 줄바꿈 규칙과 글꼴, 스크린 리더 발음을 정합니다
행간을 한 단계 넓게 잡기영문 기준이 1.5라면 한글은 1.7~1.8을 씁니다
<br>로 직접 끊지 않기화면 폭이 바뀌면 엉뚱한 자리에서 끊기므로, 줄바꿈은 브라우저에 맡깁니다
본문 자간은 0으로 두기본문에서 벌리면 낱글자로 흩어져 보입니다. 큰 제목만 조금 좁힙니다

8 서버 쪽으로 치면백엔드 개념과 짝지어 보기

데이터에 따라 달라지는 글 길이'가맹점명'이 3자일 때와 30자일 때는 화면이 달라집니다. 그래서 적어도 한 번은 가장 긴 값을 넣어 화면을 그려 봐야 합니다.
문장을 한 덩어리로 보내기'…되면'과 '입금됩니다'를 따로 내려보내 화면에서 이어 붙이면 번역과 줄바꿈이 둘 다 어긋납니다. 그래서 문장은 한 덩어리로 보냅니다.
언어마다 다른 글 길이같은 문장이라도 영어로는 길이가 1.3배쯤 되고, 일본어로는 비슷합니다. 칸 크기를 한국어 기준으로만 잡으면 다른 언어에서는 글이 칸을 넘칩니다.
한글을 가나다순으로 정렬하기한글은 localeCompare('ko')로 정렬해야 'ㄱㄴㄷ' 순이 됩니다. 바이트 순으로 정렬하면 자모 순서가 뒤섞입니다.
한글 글꼴 파일의 크기한글은 완성형만 1만 1172자라서 글꼴 파일이 수 MB나 됩니다. 그래서 쓰는 글자만 남기는 서브셋이 거의 필수입니다. 자세한 내용은 웹폰트 항목을 보세요.

두 OS는 한글 줄바꿈을 기본 설정에서 맞게 처리하기 때문에, 따로 설정이 필요한 것은 웹뿐입니다.

플랫폼 차이 때문에 자주 생기는 문제 — 두 OS 모두 기본으로 어절을 지키기 때문에, 앱 개발자에게 "한글이 중간에서 끊겨요"는 낯선 증상입니다. 웹에서만 생기는 문제라서 같은 화면을 웹과 두 앱에서 만들면 웹만 줄바꿈이 다르게 보이는 일이 흔합니다.
