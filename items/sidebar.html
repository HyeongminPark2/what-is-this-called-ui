사이드바 내비게이션

Sidebar navigation

화면 옆에 늘 붙어 있는 메뉴. 지금 어디인지와 갈 수 있는 곳이 한눈에 남아, 항목이 열 개를 넘어도 버팁니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

사이드바는 늘 보입니다. 같은 내용이 좁은 화면에서 숨었다 나오면 그건 드로어입니다.
아이콘만 보기를 눌러 보세요. 자리를 아끼되 길은 남기는 레일(rail)이 됩니다 — 다만 아이콘만으로는 뜻이 안 전해져서 툴팁이나 글자를 같이 둬야 합니다.

2 이름부르는 말이 여러 개다

한국어사이드바, 측면 내비게이션, 좌측 메뉴
영어sidebar navigation, side nav, navigation rail
같이 쓰는 말아이콘만 남겨 좁힌 것을 레일(rail), 하위 항목이 펼쳐지는 것을 접이식(collapsible), 묶음 제목을 섹션 헤더라 합니다.
자주 잘못 부름드로어 — 늘 보이면 사이드바, 숨었다 밀려 나오면 드로어입니다. 같은 내용이 폭에 따라 둘 사이를 오갑니다.
메뉴 — 메뉴는 동작을 고르는 것이고 사이드바는 화면을 옮깁니다.
패널 — 패널은 보조 내용을 담는 칸이고, 사이드바는 길을 담습니다.

3 가르는 기준형제들과 비교하는 네 축

길 안내 부품은 모두 '누르면 어디론가 간다'는 점이 같습니다. 이 네 가지만 물어보면 갈립니다.

자리데려가는 곳지금 위치감당하는 개수
앱바 · 헤더화면 위전역 · 상위제목으로해당 없음
사이드바 내비게이션화면 옆전역강조로10~20
바텀 탭바화면 아래전역아이콘 강조3~5
탭내용 위같은 화면 안밑줄로2~6
브레드크럼내용 위상위로계층 전체3~5단계
페이지네이션목록 아래같은 목록의 다른 쪽쪽 번호로제한 없음
무한 스크롤목록 끝같은 목록 이어서안 보여 준다제한 없음

한 줄로 — 사이드바는 늘 보이는 길입니다. 자리를 내주는 대신 '지금 어디인지'와 '어디로 갈 수 있는지'를 계속 보여 줍니다.

4 상태그림 한 장으로는 못 배운다

5 해부도부분 이름이 제일 안 알려진 지식

운영
거래 내역 584
정산
  1. 사이드바 sidebar화면 높이를 다 쓴다. 보통 200~260px
  2. 섹션 헤더 section header항목이 일곱을 넘으면 묶는다. 작고 조용하게
  3. 현재 항목 current item배경과 색으로 알린다. aria-current="page"도 같이
  4. 아이콘 icon눈이 빨리 찾게 돕는다. 레일에서는 이것만 남는다
  5. 이름 label짧게. 한 줄을 넘기면 묶음을 다시 생각할 때다
  6. 숫자 count · badge개수나 처리할 것. 없으면 안 둔다
  7. 다른 항목 item과녁은 40px 이상. 글자뿐 아니라 줄 전체가 눌려야 한다

사이드바는 모든 화면에 같이 나옵니다. 그래서 항목 하나를 더하는 결정은 화면 하나를 더하는 것보다 무겁습니다 — 열 개가 넘어가면 묶음을 먼저 손봐야 합니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 갈 곳이 다섯 개를 넘을 때 — 탭바로는 못 담습니다
  • 넓은 화면에서 길을 늘 보여 주고 싶을 때
  • 계층이 두 단인 내비게이션 — 묶음과 항목

이럴 때는 안 쓴다

  • 좁은 화면에서 그대로 두기 — 내용 볼 자리가 없어집니다. 드로어로 접습니다
  • 항목을 스무 개 넘게 늘어놓기 — 묶거나 검색을 답니다
  • 동작(저장·삭제)을 섞어 넣기 — 사이드바는 길만 담습니다
  • 깊이 세 단 이상 — 접었다 폈다 하다가 길을 잃습니다

대신 이걸 — 좁은 화면이면 드로어, 폰이면 바텀 탭바, 같은 화면의 다른 면이면 탭, 동작이면 드롭다운 메뉴.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

<nav>와 aria-current 두 가지가 핵심입니다. 지금 어디인지를 색 말고도 알려야 합니다.

<nav aria-label="주 메뉴">
  <a href="/tx" aria-current="page">거래 내역</a>
  <a href="/settle">정산</a>
</nav>

/* 좁아지면 드로어로 바꾼다 — 같은 마크업, 다른 모양 */
@media (max-width: 860px) {
  .nav-side { position: fixed; transform: translateX(-100%); }
}

/* 레일에서는 이름을 숨기되 title 로 남긴다 */
.nav-side.is-rail .tx { display: none; }
키일어나야 하는 일
Tab항목마다 한 번씩 지난다. 그래서 '본문으로 건너뛰기' 링크가 꼭 필요하다
aria-current"page"로 지금 위치를 알린다. 색만으로는 안 전해진다
<nav aria-label>내비게이션이 여럿이면 이름을 붙여 가른다 — '주 메뉴', '보조 메뉴'
레일아이콘만 남으면 aria-label이나 툴팁이 반드시 있어야 한다
접이식펼침 여부를 aria-expanded로 알린다

9 서버 쪽으로 치면백엔드 감각으로 번역

사이드바 = 라우팅 표화면 구조를 그대로 비춥니다. 항목과 주소가 1대1이라, 사이드바를 고치는 일은 라우팅을 고치는 일입니다.
숫자 = 추가 질의'거래 584'를 보여 주려면 개수를 따로 세야 합니다. 모든 화면에 뜨는 값이라 캐시하거나 근사치로 둡니다 — 정확한 COUNT 는 비쌉니다.
권한 = 메뉴 필터볼 수 없는 화면은 서버가 내려 주지 않거나 플래그를 함께 줍니다. 화면에서만 숨기면 주소를 치고 들어옵니다.
현재 위치 = 라우트 매칭/tx/8812에서도 '거래 내역'이 켜져야 합니다. 정확히 같은 주소가 아니라 접두사로 맞춥니다.
