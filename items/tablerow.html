테이블 행

Table row

줄 하나에 보통 넷이 들어갑니다 — 고르기 · 주 열 · 값 · 동작. 자리를 섞으면 눈이 줄마다 헤맵니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

밀도를 바꾸면 한 화면에 들어가는 줄 수가 달라집니다 — 데모가 480px 높이에 몇 줄이 들어가는지 재서 적습니다.
행 전체를 눌리게 하면 편한 대신, 안에 있는 단추를 눌러도 행 이동이 같이 일어납니다. 데모가 그 횟수를 셉니다 — 막으려면 안쪽 단추에서 stopPropagation() 을 해야 합니다.
고르기 체크박스에는 줄마다 다른 이름이 필요합니다.

2 이름부르는 말이 여러 개다

한국어테이블 행, 표 줄, 레코드 행
영어table row, record row, data row
같이 쓰는 말그 줄이 무엇인지 말해 주는 열을 주 열(primary column), 줄 간격의 빽빽함을 밀도(density), 한 줄 건너 바탕을 바꾸는 것을 줄무늬(zebra striping)라 합니다. 마우스를 올려야 나타나는 단추는 호버 액션인데, 터치에서는 안 보입니다.
자주 잘못 부름데이터 테이블 — 데이터 테이블은 표 전체의 설계입니다.
리스트 아이템 — 리스트 아이템은 열이 없는 한 건입니다.
카드 — 카드는 덩어리로 서고 행은 줄로 섭니다.

3 가르는 기준형제들과 비교하는 네 축

표시 부품은 '보여 주기만 한다'는 점이 같습니다. 이 네 가지만 물어보면 갈립니다.

무엇을 담나전체가 눌리나어떻게 모이나내용이 길어지면
카드한 덩어리보통 눌린다그리드로높이가 늘어난다
리스트 아이템한 건보통 눌린다세로 목록으로말줄임한다
아바타사람·조직 하나안 눌린다겹쳐 쌓는다고정 — 넘치면 +N
배지숫자나 한 낱말안 눌린다혼자 안 선다 — 붙는다고정 — 넘치면 99+
칩한 낱말눌린다가로로 줄바꿈말줄임하거나 줄을 넘긴다
스탯 타일숫자 하나가끔 눌린다가로 한 줄로단위를 줄인다(1.2만)
타임라인사건들의 순서항목만세로로 꿴다아래로 길어진다
별점점수 하나읽기용은 안 눌린다줄 안에 들어간다고정 — 별 다섯
아이콘뜻 하나혼자서는 안 눌린다글자 옆에 붙는다고정 — 글자가 대신 길어진다
썸네일그림 하나보통 눌린다격자로고정 — 잘리거나 여백이 남는다
테이블 행한 건의 여러 값전체 또는 주 열만세로로 쌓인다말줄임한다
키-값 목록이름과 값의 짝안 눌린다세로로 쌓인다값이 먼저 잘린다
미디어 오브젝트그림 + 글보통 눌린다세로 목록으로글 쪽만 늘어난다
접히는 글제목과 본문제목이 눌린다세로로 포갠다접어 둔다
태그한 낱말안 눌린다가로로 줄바꿈말줄임하거나 +N

한 줄로 — 행 전체를 누르게 하려면 안쪽 단추를 먼저 막으세요. 안 막으면 둘이 같이 일어납니다.

4 상태그림 한 장으로는 못 배운다

5 해부도부분 이름이 제일 안 알려진 지식

고르기 — 줄마다 다른 이름을 준다
주 열 — 이 줄이 무엇인지 말한다
숫자 열 — 오른쪽 맞춤 · tabular-nums
동작 — 줄 끝에 둔다
행 전체를 링크로 두면 안쪽 단추가 행을 뚫는다
밀도 — 한 화면에 몇 줄이 들어가나
  1. 고르기 줄마다 이름전부 '선택'이면 구별이 안 된다
  2. 주 열 무엇인지왼쪽 첫 자리에 둔다
  3. 숫자 열 오른쪽 맞춤tabular-nums 로 자릿수 맞춤
  4. 동작 줄 끝늘 같은 자리에
  5. 행 전체 링크 부딪힘안쪽 단추를 먼저 막는다
  6. 밀도 줄 수빽빽할수록 많이 보인다

마우스를 올려야 단추가 보이게 하는 꼴이 흔한데, 터치에서는 호버가 없어 단추가 영영 안 보입니다. 늘 보이게 두거나, 적어도 좁은 화면에서는 보이게 바꿔야 합니다.
행 전체를 링크로 만들 때는 안쪽에 뭐가 있는지 먼저 세어 보세요 — 체크박스 하나와 단추 하나만 있어도 둘 다 stopPropagation() 이 필요합니다. 그게 번거로우면 주 열만 링크로 두는 쪽이 사고가 적습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 고르기 체크박스에 줄마다 다른 이름 주기
  • 숫자는 오른쪽 맞춤 + tabular-nums
  • 행 전체를 누르게 하려면 안쪽 단추를 먼저 막기

이럴 때는 안 쓴다

  • 단추를 호버에만 보이게 하기 — 터치에서는 안 보인다
  • 줄마다 동작 단추의 자리를 다르게 두기
  • 긴 이름을 줄바꿈으로 흘리기 — 줄 높이가 들쭉날쭉해진다
  • 고르기 이름을 전부 '선택'으로 두기

대신 이걸 — 표 전체 설계는 데이터 테이블, 열 없는 한 건은 리스트 아이템, 여러 줄 고르기는 일괄 선택, 덩어리로 서면 카드.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

표의 줄은 <tr> 입니다. 행 전체를 링크로 만들지 않고 주 열만 링크로 두는 쪽이 안전합니다.

<tr>
  <td><input type="checkbox" aria-label="모란상회 고르기"></td>
  <th scope="row"><a href="/s/2411">모란상회</a></th>
  <td class="num">1,284,000원</td>
  <td><button>영수증</button></td>
</tr>

.num { text-align: right; font-variant-numeric: tabular-nums; }

// 행 전체를 눌리게 했다면 안쪽은 먼저 막는다
row.querySelectorAll('button, input, a').forEach(el =>
  el.addEventListener('click', e => e.stopPropagation()));
키일어나야 하는 일
<th scope="row">주 열을 줄의 제목으로 삼는다 — 소리로 읽을 때 기준이 된다
Tab줄마다 체크박스 → 링크 → 단추 차례로 지나간다
aria-label체크박스에 그 줄의 이름을 넣는다
aria-selected고른 줄을 알린다 — 바탕색만으로는 안 들린다
행 전체 링크링크 안에 단추를 넣는 것은 잘못된 마크업이다
확인하는 법Tab 으로 한 줄을 지나며 몇 번 멈추는지 센다

9 서버 쪽으로 치면백엔드 감각으로 번역

줄의 열쇠id 가 있어야 고르기와 동작을 줄에 묶을 수 있습니다 — 순서 번호로 하면 정렬이 바뀔 때 어긋납니다.
말줄임은 화면에서서버가 미리 잘라 보내면 검색도 복사도 안 됩니다 — 온전한 값을 주고 화면이 줄입니다.
권한줄마다 할 수 있는 일이 다르면 can_edit 같은 값을 같이 줘야 단추를 그릴지 정할 수 있습니다.
