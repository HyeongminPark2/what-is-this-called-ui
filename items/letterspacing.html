1 실물 — 직접 만져 보기

막대를 양 끝으로 밀어 보세요. 음수로 가면 글자가 서로 닿고, 양수로 가면 낱글자로 흩어집니다. 아래에서 지금 값이 어느 범위인지 판정해 줍니다.
손대는 자리는 둘뿐입니다 — 아주 큰 제목은 조금 좁히고(-0.02em), 작은 대문자 라벨은 조금 벌립니다(0.05em). 그 사이의 본문은 0입니다.

2 이름부르는 말이 여러 개다

한국어자간, 글자 간격
영어letter-spacing, tracking
같이 쓰는 말전체를 고르게 벌리고 좁히는 것을 트래킹(tracking), 특정 두 글자 사이만 다듬는 것을 커닝(kerning)이라 합니다. 커닝은 글꼴 안에 표가 들어 있어 브라우저가 자동으로 적용합니다(font-kerning).
자주 잘못 부름커닝 — 커닝은 글자 쌍마다 다른 보정이고, 자간은 전체를 똑같이 벌립니다.
행간 — 글이 답답해 보이는 이유는 대개 자간이 아니라 행간입니다. 자간부터 손대면 안 낫습니다.
단어 간격 — 띄어쓰기 폭은 word-spacing으로 따로 있습니다.

한 줄로 — 자간은 기본값이 정답인 드문 속성입니다. 손대는 곳은 아주 큰 제목과 작은 대문자 라벨 둘뿐입니다.

em — 글자 크기에 딸려 가는 단위

한글은 0 — 조금만 벌려도 흩어진다
  1. 큰 제목 -0.02em아주 큰 글자는 사이가 벌어져 보인다. 조금 좁혀 덩어리로 만든다
  2. 본문 0건드리지 않는다. 글꼴 디자이너가 이미 맞춰 둔 값이다
  3. 작은 대문자 라벨 0.05~0.06em대문자는 폭이 고르게 커서 붙어 보인다. 조금 벌린다
  4. em 단위 em글자 크기에 비례한다. 크기가 바뀌어도 비율이 유지된다
  5. px 단위 px (쓰지 않는다)큰 글자에서는 티도 안 나고, 작은 글자에서는 너무 벌어진다
  6. 한글 0네모 칸에 꽉 찬 글자라 벌리면 바로 흩어진다

한글은 영문과 사정이 다릅니다. 영문은 글자마다 폭이 달라 사이를 조금 벌리면 리듬이 생기지만, 한글은 모든 글자가 같은 네모 칸에 들어 있어 벌리는 순간 칸 사이가 그대로 드러납니다. '시원하게 보이려고' 자간을 준 한국어 화면이 유독 읽기 힘든 이유입니다 — 그럴 때 필요한 것은 자간이 아니라 행간입니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 아주 큰 제목(28px 이상)을 조금 좁힐 때
  • 작은 대문자 라벨을 조금 벌릴 때 — 영문 전용
  • 로고나 표지처럼 글자 자체가 그림일 때

이럴 때는 안 쓴다

  • 본문에 자간을 주는 것 — 특히 한글은 바로 흩어집니다
  • 답답해 보인다고 자간부터 벌리는 것 — 원인은 대개 행간입니다
  • px로 적는 것 — 글자 크기가 바뀌면 비율이 깨집니다
  • 한글 라벨에 영문 관례를 그대로 쓰는 것

대신 이걸 — 글이 답답하면 행간, 줄이 너무 길면 최대 폭, 위계가 안 보이면 글자 위계.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙손대는 곳은 두 군데

기본값이 정답이므로, 적는 줄은 예외 두 줄뿐입니다.

/* 본문 — 아무것도 적지 않는다 */

/* 예외 1 — 아주 큰 제목만 살짝 좁게 */
h1 { font-size: 32px; letter-spacing: -0.02em; }

/* 예외 2 — 작은 영문 대문자 라벨만 살짝 넓게 */
.label {
  font-size: 11px;
  text-transform: uppercase;
  letter-spacing: 0.06em;
}

/* 한글 라벨에는 쓰지 않는다 */
.label:lang(ko) { letter-spacing: 0; text-transform: none; }
규칙지켜야 하는 것
본문은 0아무것도 적지 않는 것이 기본이다
em으로 적는다글자 크기에 비례해야 한다. px은 크기가 바뀌면 깨진다
큰 제목만 -0.02em눈에 띄게 좁히는 게 아니라 커지며 벌어진 것을 되돌리는 정도
작은 대문자만 +0.05em영문 전용. 한글 라벨에는 안 쓴다
답답하면 행간을 본다자간을 벌려 해결하려 하면 더 읽기 어려워진다
text-transform과 짝대문자로 바꿀 때만 자간이 필요해진다. 한국어에는 둘 다 안 쓴다

9 서버 쪽으로 치면백엔드 감각으로 번역

자간은 길이를 바꾼다자간을 주면 같은 글자 수라도 글줄이 길어집니다. 한 줄에 들어가는 글자 수가 달라져 말줄임이 더 자주 걸립니다.
다국어영문에 맞춘 자간을 한국어·일본어에 그대로 쓰면 깨집니다. 언어별로 다르게 두려면 :lang()을 씁니다.
검색과 복사자간은 보이기만 바꿀 뿐 글자 자체는 그대로입니다. 복사하면 자간 없이 붙습니다 — 당연하지만 가끔 오해가 생깁니다.
