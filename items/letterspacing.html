자간

Letter spacing · tracking

자간은 글자와 글자 사이의 거리입니다. 글꼴에 이미 알맞은 값이 들어 있어서, 본문에서는 거의 건드리지 않는 것이 맞습니다.

막대를 양 끝으로 밀어 보세요. 음수로 가면 글자가 서로 닿고, 양수로 가면 글자 사이가 벌어져 낱글자로 흩어져 보입니다. 지금 값이 어느 범위에 드는지는 아래에 알려 줍니다.
자간을 조정하는 자리는 두 군데뿐입니다. 아주 큰 제목은 조금 좁히고(-0.02em), 작은 대문자 라벨은 조금 벌립니다(0.05em). 그 밖의 본문은 0으로 둡니다.

2 이름같은 것을 부르는 여러 이름

한국어자간, 글자 간격
영어letter-spacing, tracking
같이 쓰는 말글 전체의 글자 사이를 고르게 벌리거나 좁히는 것을 트래킹(tracking), 특정 두 글자 사이만 다듬는 것을 커닝(kerning)이라고 합니다. 커닝 값은 글꼴 안에 표로 들어 있어서 브라우저가 자동으로 적용합니다(font-kerning).
자주 잘못 부르는 이름커닝 — 커닝은 글자 쌍마다 값이 다른 보정이고, 자간은 모든 글자 사이를 똑같이 벌립니다.
행간 — 글이 답답해 보이는 이유는 대개 자간이 아니라 행간이기 때문에, 자간부터 고쳐서는 나아지지 않습니다.
단어 간격 — 띄어쓰기 폭은 자간과 별개로 word-spacing으로 정합니다.

자간을 한 줄로 정리하면 — 자간은 기본값을 그대로 두는 것이 맞는 드문 속성입니다. 값을 바꾸는 곳은 아주 큰 제목과 작은 대문자 라벨, 두 군데뿐입니다.

  2. 본문 0건드리지 않습니다. 글꼴 디자이너가 이미 맞춰 둔 값입니다
  3. 작은 대문자 라벨 0.05~0.06em대문자는 폭이 고르게 커서 글자끼리 붙어 보이므로 조금 벌립니다
  4. em 단위 em글자 크기에 비례하는 단위라서 글자 크기가 바뀌어도 비율이 유지됩니다

  6. 한글 0한글은 네모 칸을 꽉 채우는 글자라서 벌리면 바로 흩어져 보입니다

한글은 영문과 사정이 다릅니다. 영문은 글자마다 폭이 달라서 사이를 조금 벌려도 글자 간격이 고르게 보이지만, 한글은 모든 글자가 같은 크기의 네모 칸에 들어 있어서 조금만 벌려도 칸 사이의 빈틈이 그대로 드러납니다. '시원하게 보이려고' 자간을 벌린 한국어 화면이 유독 읽기 힘든 것도 이 때문입니다. 글이 답답해 보일 때 고칠 것은 자간이 아니라 행간입니다.

6 쓸 때 / 안 쓸 때

자간을 쓰는 경우

  • 아주 큰 제목(28px 이상)을 조금 좁힐 때
  • 영문 작은 대문자 라벨을 조금 벌릴 때. 한글 라벨에는 쓰지 않습니다
  • 로고나 표지처럼 글자 자체가 그림일 때

자간을 쓰지 않는 경우

  • 본문에 자간을 줄 때. 특히 한글은 조금만 벌려도 글자가 흩어져 보입니다
  • 글이 답답해 보인다고 자간부터 벌릴 때. 원인은 대개 행간입니다
  • 자간을 px로 적을 때. 글자 크기가 바뀌면 글자 크기와 자간의 비율이 달라집니다
  • 대문자 라벨을 벌리는 영문 관례를 한글 라벨에 그대로 쓸 때

자간 대신 다른 것을 써야 하는 경우 — 글이 답답해 보이면 자간 대신 행간을 넓히고, 줄이 너무 길어 읽기 힘들면 최대 폭을 정합니다. 제목과 본문의 위계가 드러나지 않을 때는 글자 위계를 봅니다.

8 최소 코드와 규칙자간 값을 바꾸는 두 자리

기본값을 그대로 쓰기 때문에, 코드에 적는 것은 예외 두 줄뿐입니다.

/* 본문에는 아무것도 적지 않는다 */

/* 예외 1. 아주 큰 제목만 살짝 좁게 */
h1 { font-size: 32px; letter-spacing: -0.02em; }

/* 예외 2. 작은 영문 대문자 라벨만 살짝 넓게 */
.label {
  font-size: 11px;
  text-transform: uppercase;
  letter-spacing: 0.06em;
}

/* 한글 라벨에는 쓰지 않는다 */
.label:lang(ko) { letter-spacing: 0; text-transform: none; }
지킬 규칙지키는 방법
본문은 0으로 두기본문에는 자간을 아무것도 적지 않는 것이 기본입니다
em 단위로 적기자간은 글자 크기에 비례해야 합니다. px로 적으면 글자 크기가 바뀔 때 비율이 맞지 않습니다
큰 제목에만 -0.02em 주기눈에 띄게 좁히는 것이 아니라 글자가 커지면서 벌어져 보이는 만큼만 되돌리는 정도로 줍니다
작은 대문자에만 +0.05em 주기영문에만 쓰고, 한글 라벨에는 쓰지 않습니다
글이 답답하면 행간부터 보기글이 답답할 때 자간을 벌려 해결하려 하면 오히려 더 읽기 어려워집니다
text-transform과 함께 조정하기글자를 대문자로 바꿀 때만 자간을 함께 조정합니다. 한국어에는 둘 다 쓰지 않습니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

자간을 주면 길어지는 글줄자간을 주면 같은 글자 수라도 글줄이 길어집니다. 그러면 한 줄에 들어가는 글자 수가 줄어서 말줄임이 더 자주 걸립니다.
언어마다 다르게 두는 자간영문에 맞춘 자간을 한국어나 일본어에 그대로 쓰면 글자가 흩어져 보입니다. 자간을 언어별로 다르게 두려면 :lang()을 씁니다.
검색과 복사에는 영향이 없음자간은 화면에 보이는 모양만 바꾸고 글자 자체는 그대로 둡니다. 그래서 글을 복사하면 자간 없이 붙어 나오는데, 당연한 일이지만 가끔 오해를 삽니다.
