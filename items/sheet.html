바텀시트

Bottom sheet · Sheet

화면 아래에서 올라오는 판. 손가락이 닿는 자리에 선택지를 두려고 씁니다. 좁은 화면에서 모달이 취하는 모습이기도 합니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

핸들을 아래로 끌어 보세요. 시트에만 있는 조작입니다 — 모달에는 없습니다. Esc와 바깥 누르기도 됩니다. 폭을 넓게로 바꾸면 같은 시트가 가운데로 모입니다. 넓은 화면에서는 아래에 붙여 둘 이유가 없기 때문입니다.

2 이름부르는 말이 여러 개다

한국어바텀시트, 시트, 하단 시트
영어bottom sheet, sheet
같이 쓰는 말뒤를 막는 것을 모달 시트, 안 막고 내용 위에 걸쳐 있는 것을 스탠더드 시트라 가릅니다. 위로 조금만 올라와 있는 상태는 엿보기(peek).
자주 잘못 부름하단 팝업 — 실무에서 많이 쓰지만 표준 용어는 아닙니다.
모달 — 좁은 화면에서 모달이 시트로 바뀌는 건 맞지만, 둘은 다른 이름입니다. 시트는 어디서 뜨는가를 가리키고 모달은 뒤를 막는가를 가리킵니다.
액션 시트 — iOS 에서 선택지를 늘어놓는 시트만 가리키는 좁은 말입니다.

  2. 시트 몸통 sheet · surface위 모서리만 깎는다. 아래는 화면에 붙어 있으므로
  3. 그래브 핸들 grab handle · drag handle끌어서 크기를 바꿀 수 있다는 표시. 어포던스다

  5. 내용 content여기만 스크롤된다. 시트 전체가 스크롤되면 끌어 닫기와 부딪친다

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 손가락으로 고르는 선택지가 여럿일 때
  • 지도나 영상처럼 뒤를 계속 보여 주면서 조작해야 할 때 (안 막는 시트)
  • 좁은 화면에서 모달 대신 — 손이 닿고 키보드에 안 가립니다

이럴 때는 안 쓴다

  • 넓은 데스크톱 화면 — 아래에 붙여 둘 이유가 없습니다
  • 입력이 많은 폼 — 키보드가 올라오면 시트가 쪼그라듭니다
  • 단계가 여럿일 때 → 페이지로 보냅니다
  • 끌어 닫기와 안쪽 스크롤이 겹치게 만들기 — 둘 다 세로 제스처라 부딪칩니다

대신 이걸 — 넓은 화면이면 모달, 옆에서 나와야 하면 드로어, 알려만 주면 되면 토스트.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

<dialog>를 아래에 붙이면 됩니다. margin 한 줄이 가운데 모달과 바텀시트를 가릅니다.

<dialog class="sheet" aria-labelledby="t">
  <span class="grab"></span>
  <h2 id="t">해질녘 공원</h2>
  …
</dialog>

/* 가운데가 아니라 아래에 붙인다 — 이 한 줄이 모달과 시트를 가른다 */
dialog.sheet { margin: auto auto 0; width: 100%; }

// 끌어 내려 닫기. 일정 거리를 넘길 때만 닫는다
if (dy > 70) dlg.close();

// 홈 인디케이터에 버튼이 가리지 않게
padding-bottom: calc(16px + env(safe-area-inset-bottom));
키일어나야 하는 일
Esc닫힌다. 막는 시트든 아니든
Tab막는 시트에서는 시트 안에서만 돈다
아래로 끌기일정 거리를 넘기면 닫힌다. 안 넘기면 제자리로 돌아간다
열릴 때포커스가 시트 안으로. 파괴적 선택지가 있으면 거기에 두지 않는다
닫힐 때포커스가 열었던 버튼으로 돌아간다

9 서버 쪽으로 치면백엔드 감각으로 번역

스냅 포인트 = 상태 머신엿보기 / 반 / 전체는 세 가지 상태이고 사이를 오가는 규칙이 있습니다. 끌다가 손을 떼면 가장 가까운 상태로 수렴합니다. 상태가 늘수록 규칙이 급히 복잡해집니다.
막는 시트 = 블로킹 호출뒤를 막으면 답이 올 때까지 기다리는 셈입니다. 안 막는 시트는 비동기에 가깝습니다.
부분 로드와 궁합엿보기에서는 요약만, 끌어 올리면 상세를 더 가져옵니다. 커서 페이지네이션과 같은 모양입니다.
세이프 에어리어 = 예약 영역쓸 수 있는 폭과 실제로 그려도 되는 폭이 다릅니다. 헤더 크기를 빼고 페이로드를 계산하는 것과 같습니다.

바텀시트(Bottom sheet) · Modal(막음) / Standard(안 막음) / Expanding으로 나눠 부릅니다. 이 부품의 이름이 굳어진 곳입니다.

자주 생기는 사고 — "시트 띄워 주세요"가 iOS 에서는 화면 전환 방식을 뜻할 수 있습니다. iOS 의 시트는 모달 프레젠테이션의 한 형태라서, 웹에서 생각하는 '아래에서 올라오는 작은 판'보다 범위가 넓습니다. 역할로 말하는 편이 안전합니다.
