모션 줄이기

Reduced motion

사용자가 OS에서 모션 줄이기를 켜면 브라우저에 "움직임을 줄여 달라"는 요청이 전해집니다. 이 요청은 움직임을 전부 끄라는 뜻이 아닙니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

여섯 가지 요소가 움직이고 있습니다. 모션 줄이기를 켠 사람의 화면으로 보기를 누르면 셋은 멈추고 셋은 그대로 움직입니다.
멈추는 쪽은 큰 거리를 지나가는 이동, 확대, 끝없이 도는 것이고, 남는 쪽은 투명도, 색, 아주 짧은 미끄러짐입니다. 이런 움직임이 남아 있어야 사용자가 무엇이 바뀌었는지 알 수 있습니다.

2 이름같은 것을 부르는 여러 이름

한국어모션 줄이기, 동작 줄이기, 애니메이션 효과 감소
영어reduced motion, prefers-reduced-motion
같이 쓰는 말맥과 아이폰 설정에서는 '동작 줄이기', 윈도우에서는 '애니메이션 표시' 끄기, 안드로이드에서는 '애니메이션 삭제'라는 이름으로 있습니다. 이 설정은 브라우저에 prefers-reduced-motion: reduce로 전해집니다. 비슷한 설정으로 prefers-reduced-transparency와 prefers-reduced-data도 있습니다.
자주 잘못 부르는 이름접근성 설정 — 틀린 말은 아니지만 범위가 너무 넓습니다. 모션 줄이기는 접근성 설정 가운데 움직임 하나만 다룹니다.
저사양 모드 — 기기 성능 때문이 아니라 사용자의 몸이 불편해서 켜는 설정이라, 빠른 기기에서도 켭니다.
다크 모드처럼 보기 좋으라고 고르는 설정이 아니라, 어지럼증이나 멀미를 피하려고 켜는 설정입니다.

3 가르는 기준헷갈리는 형제 부품과 견주는 네 가지 기준

움직임은 화면에서 무엇이 바뀌었는지 사용자에게 알려 주는 역할을 합니다. 아래 네 가지를 따져 보면 움직임을 다루는 항목들을 서로 구별할 수 있습니다.

이 항목이 정하는 것사용자가 움직임에서 읽어 내는 것지나치게 쓰면 생기는 일모션 줄이기를 켰을 때
이징 곡선속도를 나눠 쓰는 방식무게와 재질끈적해 보임그대로 둠
지속 시간얼마나 걸리는지거리와 크기사용자를 기다리게 함짧게 줄이거나 0으로
진입과 퇴장들고 나는 방식어디서 왔는지닫힐 때까지 붙잡혀 기다림퇴장 시간을 거의 0으로
무엇을 움직이나어떤 속성을 바꾸는지움직임이 매끄러운지화면이 버벅임해당 없음
스프링지나쳤다 돌아오는 정도손으로 민 듯한 느낌어지러움튕김을 0으로
차례로 들어오기줄과 줄 사이의 지연순서와 묶음마지막 줄이 늦게 나타남한꺼번에 띄움
제스처손가락을 따라가는 규칙내가 조작하고 있다는 느낌실수로 닫히기 쉬움그대로 둠
모션 줄이기무엇을 끄는지배려받고 있다는 느낌다 꺼 버려 무엇이 바뀌었는지 알 수 없음이 항목이 그 기준
공유 요소 전환두 화면에 함께 있는 같은 요소어디서 왔는지자리가 어긋나면 오히려 헷갈림자리 이동 없이 전환
스크롤 연동스크롤에 맞춰 움직이는 방식지금 어디쯤 읽고 있는지멀미를 일으킴연출만 끔

모션 줄이기를 한 줄로 정리하면 — 끌지 말지는 '이 움직임이 멀미를 일으킬까'로 판단합니다. 큰 거리 이동, 확대, 시차, 끝없이 도는 것은 끄고, 자리를 거의 옮기지 않는 움직임은 남깁니다.

4 끌 움직임과 남길 움직임멀미를 일으키는지에 따라 가른 여섯 가지 움직임

5 해부도부분마다 붙은 이름

@media (prefers-reduced-motion: reduce)
큰 거리 이동·확대 축소·시차 스크롤은 끔
끝없이 도는 것·자동 재생은 줄임
투명도·색·아주 짧은 미끄러짐은 남김
기본값은 no-preference이고 켠 사람만 reduce
*{animation:none}으로 다 끄면 변화를 알 수 없음
  1. 질의 prefers-reduced-motion값은 no-preference와 reduce 두 가지뿐입니다
  2. 끄는 것 큰 이동 · 확대 · 시차가만히 있는데도 몸이 움직이는 것처럼 느끼게 하는 움직임입니다
  3. 줄이는 것 도는 것 · 자동 재생아예 없애면 작업이 진행 중이라는 것을 알 수 없습니다
  4. 남기는 것 투명도 · 색자리를 옮기지 않아서 멀미를 일으키지 않고, 변화를 알리는 데 필요합니다
  5. 기본값 no-preference설정을 켠 사람만 reduce입니다. 설정을 알 수 없으면 켜지 않은 것으로 봅니다
  6. 한 줄로 모두 끄는 코드 전부 끄기*{animation:none}으로 다 끄면 사용자가 무엇이 바뀌었는지 알 수 없습니다

인터넷에는 *{animation-duration:.01ms!important}처럼 모든 애니메이션을 한 줄로 끄는 코드가 많이 돌아다닙니다. 아무것도 하지 않는 것보다는 낫지만, 이렇게 하면 나타나고 사라지는 움직임까지 없어져서 토스트가 번쩍하고 없어지거나 메뉴가 순간이동하듯 바뀝니다. 제대로 하려면 항목마다 거리는 줄이고 투명도는 남기는 쪽으로 정해야 합니다. 거리를 CSS 변수 하나로 두고 0에 가깝게 내리는 방법이 가장 손이 덜 갑니다.

6 쓸 때 / 안 쓸 때

모션 줄이기를 챙겨야 하는 때

  • 움직이는 것을 만들 때마다 함께 챙길 때. 나중에 몰아서 하면 빠뜨립니다
  • 자동 재생 영상이나 배너가 있을 때. 처음부터 멈춰 둡니다
  • 시차 스크롤이나 스크롤에 따라 움직이는 것이 있을 때. 이런 움직임을 가장 먼저 끕니다

모션 줄이기에 대응할 때 피할 것

  • 움직임을 전부 끌 때. 무엇이 바뀌었는지 알 수 없게 됩니다
  • 줄이기를 켠 사람에게 기능을 덜 줄 때
  • 성능 설정으로 오해해서 저사양 기기에만 적용할 때
  • !important로 모두 덮어쓸 때. 꼭 필요한 전환까지 꺼집니다

모션 줄이기와 함께 볼 항목 — 길이를 줄이는 방법은 지속 시간에서 다루고, 흔들림을 없애려면 스프링의 튕김을 0으로 둡니다. 자동으로 도는 것을 바꾸는 방법은 스피너에 있습니다.

7 자주 보는 모습구조만 따라 그린 재현 그림

8 최소 코드와 규칙구현할 때 지킬 최소 규칙

거리와 길이를 변수로 두면 미디어 질의 하나로 모두 처리할 수 있습니다.

:root { --move: 8px; --dur: 220ms; }

.card { transform: translateY(var(--move)); transition: var(--dur) var(--ease-out); }

@media (prefers-reduced-motion: reduce) {
  :root { --move: 0px; --dur: 1ms; }
  .parallax { transform: none !important; }   /* 시차는 아예 끈다 */
  .spinner  { animation: pulse 1.2s ease-in-out infinite; }  /* 돌지 말고 깜빡 */
}

// 자바스크립트 애니메이션도 물어본다
const calm = matchMedia('(prefers-reduced-motion: reduce)');
if (calm.matches) el.scrollIntoView();
else el.scrollIntoView({ behavior: 'smooth' });
알아 둘 규칙자세한 내용
matchMedia로 설정 확인하기CSS 밖의 애니메이션(캔버스·자바스크립트)도 같이 줄여야 합니다
scroll-behavior: smooth부드러운 스크롤도 멀미를 일으킵니다. 모션 줄이기에서는 auto로 바꿉니다
.addEventListener('change')설정은 사용자가 화면을 쓰는 중에도 바뀔 수 있으므로, 한 번 읽고 끝내지 않습니다
켠 사람에게도 기능은 그대로 주기기능은 그대로 두고 움직임만 줄입니다
자동 재생에는 멈춤 버튼 두기WCAG는 5초 넘게 자동으로 움직이는 것에 멈출 방법을 두도록 요구합니다
설정을 바꿔 시험하는 방법개발자 도구에서 prefers-reduced-motion 값을 바꿔 가며 시험할 수 있습니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

서버가 알 수 없는 설정모션 줄이기 설정은 요청 헤더에 실려 오지 않습니다. 그래서 서버가 미리 렌더링해 보내는 화면에서는 CSS 질의로만 처리할 수 있습니다.
클라이언트 힌트Sec-CH-Prefers-Reduced-Motion 헤더가 있기는 하지만 브라우저마다 지원이 달라서 여기에 기대지 않는 편이 낫습니다.
자동 재생 영상 대신 포스터 보내기줄이기를 켠 사람에게 포스터 이미지만 보내면 데이터도 아낄 수 있습니다.

플랫폼 차이 때문에 자주 생기는 문제 — 모션 줄이기는 "접근성 챙겨 주세요"라는 요청 가운데 가장 적은 품으로 끝나는 항목입니다. 거리와 길이를 변수로 둔 프로젝트라면 미디어 질의 하나만 더하면 됩니다. 반대로 숫자를 화면마다 직접 적어 둔 프로젝트에서는 수십 군데를 찾아 고쳐야 합니다. 움직임 값을 토큰으로 두어야 하는 이유가 여기에도 있습니다.
