모션 줄이기

Reduced motion

OS 설정 하나로 "움직임을 줄여 달라"는 말이 옵니다. 전부 끄라는 뜻이 아닙니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

여섯 가지가 움직이고 있습니다. 줄이기를 켠 사람으로 보기를 눌러 보세요 — 셋은 멎고 셋은 그대로입니다.
멎는 쪽은 큰 거리를 지나가는 이동·확대·끝없이 도는 것이고, 남는 쪽은 투명도·색·아주 짧은 미끄러짐입니다. 남는 것이 있어야 무엇이 바뀌었는지를 알 수 있습니다.

2 이름부르는 말이 여러 개다

한국어모션 줄이기, 동작 줄이기, 애니메이션 효과 감소
영어reduced motion, prefers-reduced-motion
같이 쓰는 말맥·아이폰 설정에서는 '동작 줄이기', 윈도우에서는 '애니메이션 표시' 끄기, 안드로이드에서는 '애니메이션 삭제'입니다. 브라우저에는 prefers-reduced-motion: reduce로 전해집니다. 비슷한 설정으로 prefers-reduced-transparency·prefers-reduced-data도 있습니다.
자주 잘못 부름접근성 설정 — 맞지만 범위가 넓습니다. 이것은 움직임 하나에 대한 설정입니다.
저사양 모드 — 성능 문제가 아니라 몸의 문제입니다. 빠른 기기에서도 켭니다.
다크 모드처럼 디자인 선택이 아닙니다 — 어지럼증·멀미를 피하려고 켭니다.

3 가르는 기준형제들과 비교하는 네 축

움직임은 장식이 아니라 말입니다. 이 네 가지만 물어보면 갈립니다.

무엇을 정하나사람이 읽는 뜻과하면모션 줄이기에서
이징 곡선속도를 나눠 쓰는 방식무게와 재질끈적해 보인다그대로 둔다
지속 시간얼마나 걸리나거리와 크기기다리게 된다짧게 하거나 0
진입과 퇴장들고 나는 방식어디서 왔나닫는 데 붙잡힌다퇴장은 거의 0
무엇을 움직이나어떤 속성을 바꾸나매끄러움 그 자체버벅인다해당 없음
스프링지나쳤다 돌아오는 정도손으로 민 느낌어지럽다튕김을 0으로

한 줄로 — 끄는 기준은 '이게 멀미를 일으킬까'입니다. 큰 거리·확대·시차·끝없이 도는 것은 끄고, 자리를 거의 안 옮기는 것은 남깁니다.

4 끌 것과 남길 것전부 끄는 것이 아니다

5 해부도부분 이름이 제일 안 알려진 지식

@media (prefers-reduced-motion: reduce)
끈다 — 큰 거리 이동 · 확대 축소 · 시차 스크롤
줄인다 — 끝없이 도는 것 · 자동 재생
남긴다 — 투명도 · 색 · 아주 짧은 미끄러짐
기본값은 no-preference — 켠 사람만 reduce
*{animation:none} 으로 다 끄면 변화를 못 읽는다
  1. 질의 prefers-reduced-motion값은 no-preference와 reduce 둘뿐
  2. 끄는 것 큰 이동 · 확대 · 시차화면이 나를 움직이는 느낌을 주는 것들
  3. 줄이는 것 도는 것 · 자동 재생아예 없애면 진행 중임을 알 길이 없다
  4. 남기는 것 투명도 · 색자리를 안 옮긴다. 안전하고 필요하다
  5. 기본값 no-preference켠 사람만 reduce 다. 모르면 안 켠 것으로 본다
  6. 과잉 대응 전부 끄기*{animation:none}은 변화를 못 읽게 만든다

전부 끄는 한 줄이 인터넷에 많이 돌아다닙니다 — *{animation-duration:.01ms!important}. 안 하는 것보다는 낫지만, 나타남과 사라짐까지 사라져 토스트가 번쩍하고 없어지거나 메뉴가 순간이동합니다. 제대로 하려면 거리를 줄이고 투명도는 남기는 쪽으로 항목마다 정해야 합니다. CSS 변수 하나로 거리를 0 에 가깝게 만드는 방법이 품이 가장 적습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 움직이는 것을 만들 때마다 함께 — 나중에 몰아서 하면 빠뜨린다
  • 자동 재생 영상·배너 — 멈춰 둔다
  • 시차 스크롤·스크롤로 따라 움직이는 것 — 가장 먼저 끈다

이럴 때는 안 쓴다

  • 전부 끄기 — 무엇이 바뀌었는지 못 읽게 된다
  • 줄이기를 켠 사람에게 기능을 덜 주는 것
  • 성능 설정으로 오해해 저사양 기기에만 적용하기
  • !important로 덮어쓰기 — 필요한 전환까지 죽는다

대신 이걸 — 길이를 줄이는 것은 지속 시간, 흔들림을 없애는 것은 스프링의 튕김 0, 자동으로 도는 것은 스피너 쪽에서.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙이 설정의 계약서

거리와 길이를 변수로 두면 질의 하나로 전부 처리됩니다.

:root { --move: 8px; --dur: 220ms; }

.card { transform: translateY(var(--move)); transition: var(--dur) var(--ease-out); }

@media (prefers-reduced-motion: reduce) {
  :root { --move: 0px; --dur: 1ms; }
  .parallax { transform: none !important; }   /* 시차는 아예 끈다 */
  .spinner  { animation: pulse 1.2s ease-in-out infinite; }  /* 돌지 말고 깜빡 */
}

// 자바스크립트 애니메이션도 물어본다
const calm = matchMedia('(prefers-reduced-motion: reduce)');
if (calm.matches) el.scrollIntoView();
else el.scrollIntoView({ behavior: 'smooth' });
키일어나야 하는 일
matchMedia로 물어본다CSS 밖의 애니메이션(캔버스·자바스크립트)도 같이 줄여야 한다
scroll-behavior: smooth부드러운 스크롤도 멀미를 일으킨다. 줄이기에서는 auto로
.addEventListener('change')설정은 쓰는 중에도 바뀐다. 한 번 읽고 끝내지 않는다
켠 사람에게 덜 주지 않는다기능은 그대로고 움직임만 줄인다
자동 재생에는 멈춤 버튼WCAG 는 5초 넘게 자동으로 움직이는 것에 멈출 길을 요구한다
시험하는 법개발자 도구에서 prefers-reduced-motion을 흉내 낼 수 있다

9 서버 쪽으로 치면백엔드 감각으로 번역

서버는 알 수 없다이 설정은 요청 헤더로 오지 않습니다. 서버가 미리 렌더링해 보내는 화면에서는 CSS 질의로만 처리됩니다.
클라이언트 힌트Sec-CH-Prefers-Reduced-Motion 헤더가 있지만 지원이 고르지 않아 기대지 않는 편이 낫습니다.
자동 재생 영상줄이기를 켠 사람에게는 포스터 이미지만 보내면 데이터도 아낍니다.
