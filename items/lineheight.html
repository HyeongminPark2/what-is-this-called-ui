행간

Line height · leading

행간은 글줄과 글줄 사이의 거리입니다. 글이 얼마나 잘 읽히는지는 어떤 글꼴을 고르느냐보다 행간을 어떻게 잡느냐에 더 크게 좌우됩니다.

2 이름같은 것을 부르는 여러 이름

한국어행간, 줄 간격, 줄 높이
영어line-height, leading, line spacing
같이 쓰는 말인쇄에서는 레딩(leading)이라고 불렀는데, 납 활자 줄 사이에 끼우던 납 조각에서 온 말입니다. 글자 위아래로 생기는 빈 공간은 하프 레딩(half-leading), 모든 줄을 일정한 간격의 가로줄에 맞춰 놓는 방식은 베이스라인 그리드라고 부릅니다.
자주 잘못 부르는 이름자간 — 자간은 글자 사이, 행간은 줄 사이의 거리입니다. 글이 답답해 보일 때 원인은 대개 자간이 아니라 행간입니다.
문단 간격 — 문단과 문단 사이의 거리는 행간이 아니라 margin으로 정합니다.
line-height: 1.5em — 단위를 붙이면 부모에서 계산한 픽셀 값이 그대로 자식에게 물려지기 때문에, 자식 글자 크기가 달라도 줄 높이가 바뀌지 않습니다.

5 해부도부분마다 붙은 이름

행간은 글줄 사이의 거리입니다. 한글은 받침이 있어 글자가 아래로 길기 때문에 영문과 같은 값을 쓰면 답답해 보입니다.

line-height: 1.8 — 배수로 적는다
line-height: 28px — 못 박으면 글자가 커졌을 때 겹친다
줄 높이 − 글자 크기 = 실제 틈
제목 1.2~1.3 · 본문 1.6~1.8
한글은 영문 기준보다 한 단계 넓게
  1. 문단 paragraph행간을 적용하는 단위입니다. 줄 격자를 겹쳐 보면 각 줄이 어느 높이에 놓이는지 보입니다
  2. 배수로 적기 line-height: 1.8단위 없이 적습니다. 그러면 글자 크기가 바뀔 때 줄 높이도 따라 바뀝니다
  3. 못 박기 line-height: 28px글자만 커지고 줄 높이는 그대로라 줄이 겹칩니다. 그래서 쓰지 않습니다
  4. 실제 틈 line-height − font-size눈에 보이는 줄 사이 빈 공간입니다. 같은 배수라도 글자가 작으면 틈도 좁습니다
  5. 범위 1.2~1.8제목은 1.2~1.3, 본문은 1.6~1.8을 씁니다. 글자가 크면 좁게, 작으면 넓게 잡습니다
  6. 한글 보정 +0.1~0.2한글은 받침 때문에 글자가 아래로 길어서, 영문 기준보다 한 단계 더 넓힙니다

단위를 붙인 1.5em을 피하는 이유는 계산이 끝난 픽셀 값이 자식에게 그대로 내려가기 때문입니다. 예를 들어 부모 글자가 16px이면 줄 높이는 24px로 계산되고, 자식 글자가 30px이어도 줄 높이는 24px 그대로라서 줄이 겹칩니다. 반면 단위 없는 1.5는 비율이 그대로 내려가므로 자식이 자기 글자 크기로 줄 높이를 다시 계산합니다.

6 쓸 때 / 안 쓸 때

행간을 쓰는 경우

  • 모든 글에 행간을 정해 둘 때. 정하지 않으면 브라우저 기본값(약 1.2)이 쓰이는데, 한글에는 좁습니다
  • 긴 글을 읽는 화면을 만들 때. 1.7 안팎을 씁니다
  • 글자 크기가 바뀌는 자리에 쓸 때. 배수로 적어야 줄 높이가 따라 바뀝니다

행간을 쓰지 않는 경우

  • px이나 em으로 고정할 때. 글자가 더 큰 자식 요소에서 줄이 겹칩니다
  • 제목에 본문 행간을 그대로 쓸 때. 큰 글자의 줄 사이가 벌어져 흩어져 보입니다
  • 행간을 늘려 문단을 나눌 때. 문단 사이는 margin으로 띄웁니다
  • 버튼이나 한 줄짜리 라벨에 1.8을 줄 때. 글은 한 줄인데 상자만 커집니다

행간 대신 다른 것을 써야 하는 경우 — 글자 크기 단과 함께 묶으려면 타입 스케일, 줄바꿈은 한글 조판, 문단 사이는 간격 체계.

7 자주 보는 모습구조만 따라 그린 재현 그림

8 최소 코드와 규칙행간을 적는 규칙

행간은 단위 없는 숫자 하나로 적습니다. 이것만 지키면 나머지는 자리마다 알맞은 범위를 고르는 일입니다.

body { line-height: 1.7; }   /* 단위 없이 적으면 비율이 내려간다 */

h1, h2, h3 { line-height: 1.3; }   /* 큰 글자는 좁게 */
.btn, .chip { line-height: 1.2; }   /* 한 줄짜리는 더 좁게 */

/* 크기와 행간을 한 묶음으로 토큰에 둔다 */
:root {
  --text-base: 16px;  --lh-base: 1.7;
  --text-xl: 25px;    --lh-xl: 1.3;
}

/* 이렇게 쓰지 않는다. 자식에서 줄이 겹친다 */
body { line-height: 1.5em; }
규칙지켜야 하는 것
단위 없이 적는다1.7처럼 적습니다. em이나 px을 붙이면 자식에서 줄이 겹칩니다
크면 좁게, 작으면 넓게제목은 1.2~1.3, 본문은 1.6~1.8로 두고, 아주 작은 글은 더 넓게 잡습니다
한글은 한 단계 더영문이 1.5에서 편하게 읽히면 한글은 1.7을 씁니다. 받침만큼 더 넓히는 것입니다
크기와 묶어 둔다토큰에 --text-lg와 --lh-lg를 짝으로 둡니다
한 줄짜리는 1.2버튼, 칩, 배지에 씁니다. 넓히면 상자만 커집니다
문단 사이는 margin행간을 늘려 문단을 나누려 하면 문단 안의 줄 간격까지 벌어져 행간과 문단 간격이 둘 다 어긋납니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

행간은 높이를 바꾼다같은 글이라도 행간이 0.2 커지면 목록 한 줄의 높이가 달라집니다. 그래서 가상 스크롤의 줄 높이를 미리 계산해 두었다면 행간을 바꿀 때 그 값도 같이 고쳐야 합니다.
줄 수 예측'세 줄까지만 보여 주기'를 서버에서 글자 수로 자르면 줄 수가 맞지 않습니다. 줄 수는 폭·글꼴·행간이 함께 정하기 때문에, 화면에서 말줄임으로 처리합니다.
메일 HTML메일 클라이언트는 적어 둔 행간을 자기 기본값으로 덮어쓰기도 합니다. 그래서 행간을 인라인 스타일로 적고, 그래도 값이 무시될 수 있다고 보고 만듭니다.
PDF·인쇄화면용 1.7은 인쇄하면 줄 사이가 성기게 보이기 때문에, 인쇄용 스타일에서는 행간을 조금 좁혀 둡니다.
