2 이름부르는 말이 여러 개다

한국어행간, 줄 간격, 줄 높이
영어line-height, leading, line spacing
같이 쓰는 말인쇄에서는 레딩(leading)이라 불렀습니다 — 납 활자 사이에 끼우던 납 조각에서 온 말입니다. 글자 위아래로 생기는 빈 공간을 하프 레딩(half-leading), 줄들이 일정한 간격에 맞춰 앉는 것을 베이스라인 그리드라 합니다.
자주 잘못 부름자간 — 자간은 글자 사이, 행간은 줄 사이입니다. 답답해 보이는 이유는 대개 행간입니다.
문단 간격 — 문단과 문단 사이는 margin이지 행간이 아닙니다.
line-height: 1.5em — 단위를 붙이면 자식이 물려받을 때 계산이 굳어 버립니다.

5 해부도부분 이름이 제일 안 알려진 지식

행간은 글줄 사이의 거리입니다. 한글은 받침이 있어 글자가 아래로 길기 때문에 영문과 같은 값을 쓰면 답답해 보입니다.

line-height: 1.8 — 배수로 적는다
line-height: 28px — 못 박으면 글자가 커졌을 때 겹친다
줄 높이 − 글자 크기 = 실제 틈
제목 1.2~1.3 · 본문 1.6~1.8
한글은 영문 기준보다 한 단계 넓게
  1. 문단 paragraph행간이 걸리는 단위. 줄 격자를 겹쳐 보면 줄이 어디 앉는지 보인다
  2. 배수로 적기 line-height: 1.8단위 없이. 글자 크기가 바뀌면 줄 높이도 따라온다
  3. 못 박기 line-height: 28px글자만 커지면 줄이 겹친다. 쓰지 않는다
  4. 실제 틈 line-height − font-size눈에 보이는 빈 공간. 같은 배수라도 글자가 작으면 틈도 좁다
  5. 범위 1.2~1.8제목 1.2~1.3, 본문 1.6~1.8. 크면 좁게, 작으면 넓게
  6. 한글 보정 +0.1~0.2받침 때문에 글자가 아래로 길다. 영문 기준에 한 단계 더

단위를 붙인 1.5em이 위험한 이유가 있습니다. 계산된 값이 자식에게 그대로 내려가기 때문입니다 — 부모가 16px 이면 24px 이 되고, 자식 글자가 30px 이어도 줄 높이는 24px 그대로라 겹칩니다. 단위 없는 1.5는 비율이 내려가서 자식이 자기 크기로 다시 계산합니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 모든 글 — 안 정하면 브라우저 기본값(약 1.2)이 쓰여 한글에는 좁습니다
  • 긴 글을 읽히는 화면 — 1.7 안팎
  • 글자 크기가 바뀌는 자리 — 배수라야 따라옵니다

이럴 때는 안 쓴다

  • px이나 em으로 못 박는 것 — 자식에서 겹칩니다
  • 제목에 본문 행간을 그대로 쓰는 것 — 큰 글자가 흩어져 보입니다
  • 행간으로 문단을 나누는 것 — 문단 사이는 margin입니다
  • 버튼·한 줄 라벨에 1.8 — 상자만 커집니다

대신 이걸 — 글자 크기 단과 함께 묶으려면 타입 스케일, 줄바꿈은 한글 조판, 문단 사이는 간격 체계.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙이 문단의 계약서

단위 없는 숫자 하나입니다. 그 한 가지만 지키면 나머지는 범위 문제입니다.

body { line-height: 1.7; }   /* 단위 없이 — 비율이 내려간다 */

h1, h2, h3 { line-height: 1.3; }   /* 큰 글자는 좁게 */
.btn, .chip { line-height: 1.2; }   /* 한 줄짜리는 더 좁게 */

/* 크기와 행간을 한 묶음으로 토큰에 둔다 */
:root {
  --text-base: 16px;  --lh-base: 1.7;
  --text-xl: 25px;    --lh-xl: 1.3;
}

/* 이렇게 쓰지 않는다 — 자식에서 겹친다 */
body { line-height: 1.5em; }
규칙지켜야 하는 것
단위 없이 적는다1.7. em·px은 자식에서 겹친다
크면 좁게, 작으면 넓게제목 1.2~1.3, 본문 1.6~1.8, 아주 작은 글은 더 넓게
한글은 한 단계 더영문 1.5 가 편하면 한글은 1.7. 받침만큼 더
크기와 묶어 둔다토큰에 --text-lg와 --lh-lg를 짝으로
한 줄짜리는 1.2버튼·칩·배지. 넓으면 상자만 커진다
문단 사이는 margin행간을 늘려 문단을 나누려 하면 둘 다 망가진다

9 서버 쪽으로 치면백엔드 감각으로 번역

행간은 높이를 바꾼다같은 글이라도 행간이 0.2 커지면 목록 한 줄의 높이가 달라집니다. 가상 스크롤의 줄 높이를 계산해 뒀다면 같이 고쳐야 합니다.
줄 수 예측'세 줄까지만 보여 주기'를 서버에서 글자 수로 자르면 틀립니다. 줄 수는 폭·글꼴·행간이 함께 정합니다 — 화면에서 말줄임으로 처리합니다.
메일 HTML메일 클라이언트는 행간을 멋대로 덮습니다. 인라인 스타일로 적고, 값이 무시될 수 있다고 보고 만듭니다.
PDF·인쇄화면용 1.7 은 인쇄에서 성기게 보입니다. 인쇄용 스타일에서는 조금 좁혀 둡니다.
