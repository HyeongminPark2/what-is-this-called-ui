내보내기

Export

내보내기는 화면에 보이는 자료를 파일로 꺼내는 기능입니다. 설계할 때는 내보낼 범위를 어떻게 물을지와 파일을 만드는 데 오래 걸릴 때 어떻게 할지를 특히 따져야 합니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

건수를 올려 보세요. 건수가 적으면 그 자리에서 파일을 받지만, 많으면 파일을 만드는 데 시간이 걸려서 메일로 보내거나 나중에 받게 해야 합니다.
범위를 '이 쪽'과 '조건에 맞는 전부'로 나눠 묻는 이유는 일괄 선택과 같습니다. 사용자가 내보내기를 누를 때는 거의 언제나 조건에 맞는 전부를 원합니다.

2 이름같은 것을 부르는 여러 이름

한국어내보내기, 다운로드, 추출, 엑셀 받기
영어export, download, data export, report
같이 쓰는 말파일을 만드는 데 시간이 걸려 나중에 건네주는 방식은 비동기 내보내기·작업 큐라고 합니다. 파일 맨 앞에 붙여 인코딩을 알려 주는 표식은 BOM이라고 하는데, 엑셀이 UTF-8 CSV를 제대로 열게 하려고 붙입니다. 내보낼 열을 사용자가 고르게 하는 기능은 필드 선택이라고 부릅니다.
자주 잘못 부르는 이름백업 — 백업은 나중에 되돌리려고 만드는 사본이고, 내보내기는 자료를 다른 곳에서 쓰려고 꺼내는 것입니다.
인쇄 — 인쇄물은 눈으로 보기 위한 것이고, 내보낸 파일은 다시 계산할 수 있는 자료입니다.
API — API는 다른 프로그램이 자료를 가져가는 통로라서, 사람이 버튼을 눌러 파일을 받는 내보내기와는 다릅니다.

내보내기를 한 줄로 정리하면 — 내보낼 범위가 '이 쪽'인지 '조건에 맞는 전부'인지 묻고, 파일을 만드는 데 오래 걸리면 사용자를 그 자리에서 기다리게 하지 마세요.

5 해부도부분마다 붙은 이름

범위는 이 쪽 / 조건에 맞는 전부 / 전체
파일 꼴은 CSV · XLSX · PDF
건수를 128건처럼 미리 보여 줌
오래 걸리면 파일을 다 만든 뒤에 알림
CSV에 BOM을 붙여 엑셀에서 한글이 안 깨지게
파일 이름에 조건과 날짜를 적음
  1. 범위 이 쪽 / 조건 / 전체범위를 나눠서 묻습니다. 묻지 않으면 사용자가 원하지 않은 범위의 파일을 받게 됩니다
  2. 꼴 CSV · XLSX · PDF받은 자료를 다시 계산할 수 있는지에 따라 고릅니다
  3. 건수 미리 보여 주기버튼을 누르기 전에 몇 건이 나올지 알려 줍니다
  4. 오래 걸리면 다 만든 뒤 알리기사용자를 기다리게 하지 않고, 창을 닫아도 파일 만들기는 계속됩니다
  5. BOM CSV에서 놓치기 쉬운 점BOM을 붙이지 않으면 엑셀에서 한글이 깨집니다
  6. 파일 이름 조건 + 날짜받은 뒤에도 무슨 자료인지 알 수 있도록 조건과 날짜를 넣습니다

CSV는 만들기 쉬워 보이지만 놓치기 쉬운 문제가 많습니다. 엑셀은 UTF-8 CSV를 열 때 BOM이 없으면 한글을 깨뜨리고, 010-1234 같은 값을 날짜나 수식으로 바꿔 버립니다. =·+로 시작하는 값은 아예 수식으로 실행될 수 있어서 보안 문제(CSV 인젝션)가 되기도 합니다. 값 안에 쉼표나 줄바꿈이 있으면 따옴표로 감싸야 하는데, 이런 규칙을 직접 짜면 빠뜨리는 경우가 많으므로 검증된 라이브러리를 쓰는 편이 낫습니다.

6 쓸 때 / 안 쓸 때

내보내기가 필요한 경우와 지킬 것

  • 표가 있는 화면이라면 거의 언제나 필요합니다. 관리 도구에서 가장 많이 요청받는 기능입니다
  • 내보낼 범위를 나눠서 묻기
  • 건수가 많으면 파일을 다 만든 뒤 알리기

내보내기를 만들 때 피할 것

  • 범위를 묻지 않고 지금 보이는 쪽만 내보낼 때
  • 오래 걸리는 작업인데 사용자가 창을 떠나지 못하게 할 때
  • CSV에 BOM을 붙이지 않을 때. 엑셀에서 한글이 깨집니다
  • export.csv 같은 이름을 붙일 때. 받고 나면 무슨 자료인지 알 수 없습니다

내보내기와 함께 보면 좋은 항목 — 화면에서 자료를 살펴보는 방법은 데이터 테이블에서 다루고, 내보낼 범위를 고르는 방법은 일괄 선택에서, 기간을 고르는 방법은 날짜 범위에서 다룹니다.

role="status"건수가 바뀐 것을 알립니다. 화면의 숫자만 바뀌면 화면을 보지 않는 사람은 알 수 없습니다
오래 걸릴 때버튼을 잠그고 무슨 일이 일어나고 있는지 알립니다. 아무 반응이 없으면 사용자가 버튼을 또 누릅니다
download 속성<a download="settlements.csv">처럼 쓰면 받을 파일 이름을 정할 수 있습니다
창이 닫힌 뒤의 포커스내보내기 창이 닫히면 포커스를 창을 연 버튼으로 되돌립니다
파일을 받으려고 새 창 열지 않기파일을 받으려고 새 탭이 열렸다 닫히면 포커스가 사라집니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

오래 걸리면 작업으로 돌리기큰 파일을 요청 하나로 만들어 돌려주려 하면 타임아웃이 납니다. 작업 번호를 먼저 돌려주고, 파일이 다 되면 알립니다.
범위는 조건으로 받기20만 건의 ID를 모두 담아 보낼 수는 없으므로 필터 조건을 그대로 보냅니다. 일괄 선택과 같은 방식입니다.
메모리에 다 올리지 않고 스트리밍하기모든 행을 메모리에 올리면 서버 메모리가 모자라 작업이 실패합니다. 스트리밍으로 한 줄씩 읽어 파일에 씁니다.
내보낼 때도 권한 확인하기사용자가 화면에서 볼 수 없는 줄이 파일에 섞이면 정보 유출이 됩니다. 내보낼 때도 화면과 같은 권한 조건을 겁니다.
CSV 인젝션=·+·-·@로 시작하는 값은 앞에 작은따옴표를 붙여서 엑셀이 수식으로 실행하지 않게 합니다.
내려받기 링크의 만료내려받기 링크를 계속 열어 두면 링크를 얻은 다른 사람도 파일을 받을 수 있습니다. 링크는 짧은 시간 뒤에 만료시키고, 받을 때 로그인을 확인합니다.

플랫폼 차이 때문에 자주 생기는 문제 — "엑셀로 받게 해 주세요"는 가장 자주 받는 요청이면서, 일정이 가장 자주 작게 잡히는 요청입니다. 범위 묻기, 큰 건수 처리, 권한 확인, 한글 깨짐, 두 번 눌림 대응까지 함께 만들어야 하기 때문에, 버튼 하나 다는 일로 보고 일정을 잡으면 거의 언제나 시간이 모자랍니다.
