이징 곡선

Easing

이징 곡선은 움직이는 동안 속도를 어떻게 나눠 쓸지 정하는 곡선입니다. 거리와 시간이 같아도 곡선이 다르면 움직임의 느낌이 달라집니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

네 공이 같은 거리를 같은 시간 동안 달립니다. 속도를 나눠 쓰는 방식만 다른데도 움직임의 느낌은 완전히 다릅니다.
줄 이름을 누르면 오른쪽에 그 줄의 곡선이 그려지는데, 그래프의 가로가 시간, 세로가 간 거리입니다. 대각선이 linear이고, 곡선이 대각선에서 멀어질수록 빨라지고 느려지는 차이가 커집니다.

2 이름같은 것을 부르는 여러 이름

한국어이징, 가속 곡선, 완급
영어easing, timing function, easing curve
같이 쓰는 말CSS에서는 transition-timing-function과 animation-timing-function 속성으로 정합니다. 곡선을 네 숫자로 적는 방식을 큐빅 베지에(cubic-bezier), 연속으로 움직이지 않고 몇 단계로 끊어 가는 방식을 스텝(steps)이라고 부릅니다. 디자인 도구에서는 이즈 인/아웃이라고 부르고 그래프로 보여 줍니다.
자주 잘못 부르는 이름지속 시간 — 지속 시간은 움직임이 '얼마나' 걸리는지, 이징은 '어떻게' 움직이는지를 정합니다. 두 값은 따로 정합니다.
딜레이 — 딜레이는 움직임의 시작을 늦추는 값으로, 차례로 들어오기에서 씁니다.
스프링 — 스프링은 곡선이 아니라 물리 계산으로 움직임을 만들기 때문에 끝나는 시점이 미리 정해져 있지 않습니다.

3 가르는 기준헷갈리는 형제 부품과 견주는 네 가지 기준

움직임은 화면에서 무엇이 바뀌었는지 사용자에게 알려 주는 역할을 합니다. 아래 네 가지를 따져 보면 움직임을 다루는 항목들을 서로 구별할 수 있습니다.

무엇을 정하나사람이 읽는 뜻과하면모션 줄이기에서
이징 곡선속도를 나눠 쓰는 방식무게와 재질끈적해 보인다그대로 둔다
지속 시간얼마나 걸리나거리와 크기기다리게 된다짧게 하거나 0
진입과 퇴장들고 나는 방식어디서 왔나닫는 데 붙잡힌다퇴장은 거의 0
무엇을 움직이나어떤 속성을 바꾸나매끄러움 그 자체버벅인다해당 없음
스프링지나쳤다 돌아오는 정도손으로 민 느낌어지럽다튕김을 0으로
차례로 들어오기줄 사이 지연순서와 묶음마지막이 늦는다한꺼번에 띄운다
제스처손가락을 따라가는 규칙내가 조작한다실수로 닫힌다그대로 둔다

공유 요소 전환두 화면의 같은 것어디서 왔나자리가 어긋나면 더 헷갈린다자리 이동 없이
스크롤 연동굴림에 맞춰 움직이기내가 어디쯤인가멀미를 부른다연출만 끈다

이징 곡선을 한 줄로 정리하면 — 들어오는 것에는 ease-out, 나가는 것에는 ease-in을 씁니다. 이 규칙만 지켜도 대부분의 화면에서 움직임이 자연스러워집니다.

4 곡선 여섯대각선에서 얼마나 벗어났나

5 해부도부분마다 붙은 이름

가로 = 시간 0 → 1
세로 = 간 거리 0 → 1
가파른 곳 = 빠른 구간
cubic-bezier(.22, .9, .3, 1)
대각선 = linear — 기계가 미는 움직임
  1. 곡선 timing function가로가 시간, 세로가 간 거리입니다. 이것만 알면 그래프를 읽을 수 있습니다
  2. 가로축 0 → 1움직임이 시작해서 끝날 때까지를 0에서 1로 나타냅니다. 실제 시간 길이와는 상관없습니다
  3. 세로축 0 → 1출발점에서 도착점까지를 0에서 1로 나타냅니다. 값이 1을 넘으면 목표를 지나쳤다가 돌아온다는 뜻입니다
  4. 가파른 구간 빠른 구간곡선이 가파른 곳일수록 빠르게 움직입니다
  5. 네 숫자 cubic-bezier곡선 모양을 정하는 손잡이 두 개의 좌표입니다. 앞의 두 숫자가 출발 쪽, 뒤의 두 숫자가 도착 쪽을 정합니다
  6. 대각선 linear속도가 변하지 않습니다. 실제 물체는 이렇게 움직이지 않아서 기계적으로 보입니다

현실의 물체는 갑자기 멈추지 않고 서서히 속도를 줄입니다. 그래서 끝에서 속도가 뚝 끊기는 linear 움직임은 물체보다는 기계의 움직임으로 보여 어색합니다. 반대로 계속 도는 것(스피너)과 진행 막대에는 linear가 맞습니다. 이런 요소는 속도가 바뀌면 작업이 꾸준히 진행되는 것이 아니라 중간에 막혔다가 풀린 것처럼 보이기 때문입니다.

6 쓸 때 / 안 쓸 때

이징 곡선을 쓰는 경우

  • 자리·크기·투명도가 바뀌는 모든 것에 쓸 기본 곡선을 정해 둘 때
  • 들어오는 것에 ease-out, 나가는 것에 ease-in을 줄 때
  • 제자리로 돌아오는 것에 ease-in-out을 줄 때

이징 곡선을 쓰지 않는 경우

  • linear를 기본 곡선으로 둘 때. linear는 도는 것과 진행 막대에만 씁니다
  • 항목마다 곡선을 따로 정할 때. 토큰으로 두세 개만 정해 두고 돌려 씁니다
  • 본문이나 목록에 튀는 곡선을 쓸 때. 글을 읽으려는 사이에 또 움직여서 읽기 어렵습니다
  • 들어오는 것에 ease-in을 쓸 때. 출발이 느려서 굼떠 보이는데, 이런 실수가 가장 흔합니다

이징 곡선 대신 다른 것을 써야 하는 경우 — 끝나는 시점을 정하지 않고 손으로 민 듯한 움직임을 내려면 스프링, 얼마나 걸릴지는 지속 시간, 들어오고 나가는 움직임의 짝은 진입과 퇴장.

7 자주 보는 모습구조만 따라 그린 재현 그림

8 최소 코드와 규칙구현할 때 지킬 최소 규칙

곡선을 이름 붙인 토큰으로 정의해 두고, 들어올 때와 나갈 때에 짝지어 씁니다.

:root {
  --ease-out: cubic-bezier(.22, .9, .3, 1);   /* 들어올 때 */
  --ease-in:  cubic-bezier(.7, 0, .84, 0);    /* 나갈 때 */
  --ease-both: cubic-bezier(.4, 0, .2, 1);    /* 제자리로 */
}

.sheet            { transition: transform 180ms var(--ease-in); }
.sheet[data-open] { transition: transform 260ms var(--ease-out); }

/* 도는 것만 linear */
.spinner { animation: spin 1s linear infinite; }
키와 동작그때 일어나야 하는 일
기본값은 easetransition: transform 200ms처럼 곡선을 적지 않으면 ease가 적용됩니다
cubic-bezier의 네 숫자x1 y1 x2 y2 순서입니다. x는 0~1을 벗어날 수 없지만 y는 벗어나도 되고, y가 1을 넘으면 목표를 지나쳤다가 돌아옵니다
steps(n)연속으로 움직이지 않고 n단계로 끊어서 갑니다. 스프라이트 애니메이션이나 숫자 카운터에 씁니다
곡선은 속성마다 따로transition: transform 260ms var(--ease-out), opacity 180ms linear처럼 속성마다 다른 곡선을 줄 수 있습니다
linear는 도는 것에만스피너와 진행 막대에 씁니다. 그 밖의 자리에서는 대부분 맞지 않습니다
모션 줄이기에서곡선은 그대로 둬도 됩니다. 줄여야 하는 것은 움직이는 거리와 지속 시간입니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

서버는 곡선을 모른다이징은 모두 화면 쪽에서 처리합니다. 다만 움직임이 끝나기를 기다렸다가 요청을 보내면 응답도 그만큼 늦게 오기 때문에, 요청은 움직임을 시작할 때 먼저 보냅니다.
응답이 먼저 와도데이터가 50ms 만에 와도 애니메이션이 400ms 걸리면 사용자는 400ms를 기다립니다. 화면이 느리게 느껴질 때 원인이 서버가 아닐 수도 있습니다.
측정에 섞인다화면이 뜨기까지 걸린 시간을 재는 지표(LCP 등)에는 애니메이션 시간도 들어갑니다. 그래서 요소가 늦게 나타나는 연출은 점수를 깎습니다.

웹cubic-bezier
곡선을 네 숫자로 직접 적습니다. 이름이 붙은 곡선은 ease·ease-in·ease-out·ease-in-out 네 가지뿐입니다.
iOSUIView · SwiftUI
.easeOut이 있지만 요즘은 스프링을 기본으로 씁니다. 시스템 애니메이션도 대부분 스프링입니다.

플랫폼 차이 때문에 자주 생기는 문제 — "애니메이션 좀 자연스럽게 해 주세요"라는 요청의 절반은 이징 문제이고 나머지 절반은 길이 문제입니다. 곡선 토큰을 세 개 정해 두고 그것만 쓰게 하면 화면마다 다르게 움직이는 문제가 거의 사라집니다. 처음에 토큰을 정하는 데는 한 시간 정도면 되지만, 화면이 늘어난 뒤에 하나하나 맞추려면 한 주가 걸리기도 합니다.
