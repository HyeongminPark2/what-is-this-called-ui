컨텍스트 메뉴

Context menu

누른 자리에 뜹니다. 그 방법으로만 열리기 때문에 있는 줄 모르는 기능이 되기 쉽습니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

줄에 마우스 오른쪽을 눌러 보세요(폰에서는 길게 누르기). 데모가 같은 일에 이르는 길이 몇 개인지 세서 적습니다.
⋯ 단추를 같이 두면 길이 둘이 되고, 끄면 하나뿐입니다 — 숨은 길만 두지 않는 것이 규칙입니다.
브라우저 기본 메뉴를 막는 것은 빼앗는 일입니다. 복사·새 탭으로 열기를 못 쓰게 되니, 정말 필요할 때만 막고 그 안에 그 기능들을 다시 넣어 줘야 합니다.

2 이름부르는 말이 여러 개다

한국어컨텍스트 메뉴, 오른쪽 메뉴, 마우스 우클릭 메뉴
영어context menu, right-click menu, long-press menu
같이 쓰는 말폰에서는 길게 누르기(long press)로 같은 것을 엽니다. iOS 에서는 미리보기까지 같이 띄우는 콘텍스트 메뉴가 정식 부품이고, 안드로이드에는 여러 개를 고르는 컨텍스추얼 액션 바가 따로 있습니다.
자주 잘못 부름드롭다운 메뉴 — 드롭다운 메뉴는 단추에 붙어 열립니다.
액션 시트 — 액션 시트는 아래에서 올라옵니다.
팝오버 — 팝오버는 아무 내용이나 담습니다.

4 상태그림 한 장으로는 못 배운다

5 해부도부분 이름이 제일 안 알려진 지식

오른쪽 누르기 · 길게 누르기로만 열린다
그래서 있는 줄 모르는 기능이 된다
⋯ 단추를 같이 두어 보이는 길을 만든다
누른 자리에 뜬다 — 가장자리에서 비켜난다
브라우저 기본 메뉴를 막는 것은 빼앗는 일
키보드에도 길이 있어야 한다 — Shift+F10
  1. 여는 법 오른쪽 · 길게그 방법으로만
  2. 숨은 길 모르면 없음가장 큰 약점
  3. ⋯ 단추 보이는 길같이 둔다
  4. 자리 누른 곳가장자리에서 비켜난다
  5. 기본 메뉴 막으면 빼앗음복사·새 탭이 사라진다
  6. 키보드 Shift + F10길이 하나 더

브라우저 기본 메뉴를 막을지는 신중하게 정해야 합니다. 거기에는 복사·붙여넣기·새 탭으로 열기·이미지 저장처럼 사용자가 당연히 기대하는 것들이 들어 있고, 막는 순간 그것들이 전부 사라집니다. 꼭 막아야 한다면 우리 메뉴 안에 그 기능들을 다시 넣어 줘야 합니다.
키보드에는 Shift + F10(또는 메뉴 키)이라는 길이 있습니다 — 대부분 안 붙이지만, 붙이면 마우스 없이도 같은 일을 할 수 있습니다. 물론 그보다 쉬운 답은 ⋯ 단추를 두는 것입니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • ⋯ 단추를 같이 두어 보이는 길 만들기
  • 가장자리에서 안쪽으로 비키기
  • 기본 메뉴를 막는다면 그 기능들을 다시 넣기

이럴 때는 안 쓴다

  • 컨텍스트 메뉴에만 있는 기능 두기 — 모르면 없는 기능
  • 아무 데서나 기본 메뉴 막기
  • 폰에서 길게 누르기를 드래그와 겹치게 두기
  • 메뉴를 화면 밖으로 넘기기

대신 이걸 — 단추에 붙으면 드롭다운 메뉴, 아래에서 올라오면 액션 시트, 아무 내용이나 담으면 팝오버, 여러 줄을 고르면 일괄 선택.

8 최소 마크업과 키보드이 부품의 계약서

contextmenu 이벤트를 받되, 막을지는 신중하게 정합니다.

<li>
  영수증_2411_01.jpg
  <button aria-haspopup="menu"
          aria-label="영수증_2411_01.jpg 메뉴 열기">⋯</button>
</li>

row.addEventListener('contextmenu', e => {
  e.preventDefault();          // 기본 메뉴를 빼앗는다 — 꼭 필요할 때만
  openMenu(e.clientX, e.clientY);
});

// 키보드에도 길을 둔다
row.addEventListener('keydown', e => {
  if (e.key === 'ContextMenu' || (e.shiftKey && e.key === 'F10')) {
    e.preventDefault();
    const r = row.getBoundingClientRect();
    openMenu(r.left, r.bottom);
  }
});

Shift + F10 · 메뉴 키키보드로 여는 표준 방법
↑ ↓항목 사이를 옮긴다
Esc닫고 초점을 그 줄로
aria-haspopup⋯ 단추에 붙인다
길게 누르기폰에서는 드래그와 안 겹치게 시간을 둔다
확인하는 법마우스를 안 쓰고 같은 일을 할 수 있는지 본다

9 서버 쪽으로 치면백엔드 감각으로 번역

할 수 있는 일줄마다 권한이 다르면 항목을 지웁니다 — 드롭다운 메뉴와 같습니다.
여러 줄여러 줄을 고른 상태에서 열면 묶음 동작이 떠야 합니다 — 일괄 선택과 이어집니다.

길게 누르면 미리보기와 메뉴가 같이 뜹니다 — 정식 부품입니다.
안드로이드길게 누르기 + 액션 바
길게 누르면 선택 모드로 들어가 앱바가 동작 모음으로 바뀝니다.

자주 생기는 사고 — 안드로이드가 길게 누르기를 선택 모드로 쓰는 것은 다른 두 플랫폼과 크게 다릅니다 — 한 줄을 고르면 앱바가 '지우기·공유' 같은 동작 모음으로 바뀌고, 더 고를 수도 있습니다. 웹에서 폰 폭을 만들 때 길게 누르기를 메뉴로 쓸지 선택으로 쓸지를 정해 두지 않으면 둘이 부딪힙니다. 대부분은 ⋯ 단추 + 액션 시트 쪽이 덜 헷갈립니다.
