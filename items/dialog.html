다이얼로그

Dialog (modeless · modal)

사용자와 주고받으려고 띄우는 대화 상자. 뒤를 막으면 모달, 안 막으면 비모달입니다 — 모달은 다이얼로그의 한 종류입니다.

2 이름부르는 말이 여러 개다

한국어다이얼로그, 대화 상자
영어dialog
같이 쓰는 말뒤를 막는 것이 모달 다이얼로그, 안 막는 것이 비모달(modeless·non-modal). 답을 하나 받으려고 띄우는 작은 모달은 얼럿 다이얼로그.
자주 잘못 부름모달 — 모달은 다이얼로그의 한 종류입니다. 모든 다이얼로그가 모달은 아닙니다.
팝업 — 브라우저의 새 창과 섞입니다.
창 — 운영체제의 윈도와 헷갈립니다. 다이얼로그는 페이지 안에 있습니다.

  1. 뒤쪽 내용 background content어둡지 않다. 스크림이 없다는 것이 비모달의 전부라 해도 된다
  2. 다이얼로그 dialog surface모달보다 작고 그림자도 약하다. 화면 구석에 붙여 두는 일이 많다
  3. 제목 줄 title bar무엇을 하는 창인지. 끌어서 옮기는 손잡이를 겸한다
  4. 닫기 close비모달은 사용자가 닫을 때까지 떠 있으니 닫기가 더 중요하다
  5. 내용 content뒤쪽을 보면서 하는 일이라 작고 단순해야 한다
  6. 액션 영역 actions'다음 찾기'처럼 여러 번 누르는 버튼이 온다. 모달은 한 번 누르면 끝이다

모달의 해부도(모달 ⑤칸)와 비교해 보면 스크림이 없다는 것 하나가 다릅니다. 그 하나가 포커스·스크롤·겹침 순서까지 전부 바꿉니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 찾기·바꾸기처럼 뒤쪽을 보면서 하는 일
  • 도구 창·속성 패널 — 열어 둔 채 여러 번 쓰는 것
  • 길게 띄워 두고 참고하는 보조 정보

이럴 때는 안 쓴다

  • 꼭 답을 받아야 할 때 → 모달. 비모달은 무시하고 지나갈 수 있습니다
  • 되돌릴 수 없는 일의 확인 → 모달
  • 좁은 화면 — 뒤쪽을 볼 자리가 없어 비모달의 이점이 사라집니다
  • 비모달을 여러 개 띄워 두고 겹침 순서를 안 정하기

대신 이걸 — 답을 꼭 받아야 하면 모달, 누른 것 옆에 붙어야 하면 팝오버, 옆에 길게 두고 쓰면 드로어, 알려만 주면 토스트.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

같은 요소를 어떻게 여느냐만 다릅니다. 이 두 줄이 이 항목의 전부입니다.

<dialog id="dlg" aria-labelledby="t">…</dialog>

// 비모달 — 뒤를 막지 않는다. 포커스도 안 가둔다
dlg.show();

// 모달 — 뒤가 inert 가 되고 포커스가 갇힌다
dlg.showModal();

// 지금 어느 쪽으로 열려 있는지 물어볼 수 있다
dlg.matches(':modal');   // showModal() 로 열었으면 true

// 비모달은 자리를 직접 잡아 줘야 한다 (모달처럼 가운데로 안 온다)
dialog.dlg { position: fixed; top: 72px; right: 20px; margin: 0; }
키일어나야 하는 일
Esc양쪽 다 닫힌다. <dialog>가 해 준다
Tab모달만 갇힌다. 비모달은 뒤쪽 화면으로 이어진다
배경 스크롤모달만 잠근다. 비모달은 그대로 둔다 — 그게 쓰는 이유다
열릴 때포커스를 첫 입력칸으로. 비모달은 뒤에서 하던 일이 있으니 더 조심한다
닫힐 때포커스가 열었던 곳으로 돌아간다. 양쪽 다 직접 해 줘야 한다

9 서버 쪽으로 치면백엔드 감각으로 번역

show() = 비동기 · showModal() = 동기비모달은 띄워 놓고 다른 일을 계속합니다. 모달은 답이 올 때까지 멈춥니다. await 를 붙이느냐 안 붙이느냐와 같은 선택입니다.
비모달 여럿 = 동시 세션여러 개가 동시에 떠 있을 수 있어 겹침 순서와 포커스 관리가 필요합니다. 모달은 한 번에 하나라 그 고민이 없습니다.
상태가 뒤쪽과 묶여 있다찾기 다이얼로그는 뒤쪽 문서를 계속 읽습니다. 다이얼로그를 띄우면서 뒤쪽을 얼려 버리면 쓸 수가 없습니다.
무시 가능 = 보장 없음비모달은 사용자가 그냥 지나칠 수 있습니다. 반드시 처리돼야 하는 일은 담지 않습니다.
