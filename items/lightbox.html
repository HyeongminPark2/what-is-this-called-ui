라이트박스

Lightbox

라이트박스는 그림 하나를 크게 보는 동안 뒤 화면을 덮는 부품입니다. 모달과 같은 규칙을 따르고, 여기에 그림을 앞뒤로 넘기는 기능이 더해집니다.

① 실물② 이름③ 상태④ 해부도⑤ 쓸 때⑥ 사례⑦ 마크업⑧ 백엔드 메모⑨ 플랫폼

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

그림을 눌러 크게 열어 보세요. ← →로 그림을 옮기고 Esc로 닫습니다.
라이트박스를 닫으면 초점이 눌렀던 칸으로 돌아가야 합니다. 그렇지 않으면 키보드 사용자의 초점이 목록 맨 처음으로 가 버리기 때문입니다. 데모는 닫은 뒤 초점이 어디에 있는지를 재서 보여 줍니다.
열린 그림을 주소에 남겨 두면 그 그림을 링크로 보낼 수 있고 뒤로가기로도 닫을 수 있습니다. 데모는 지금 주소도 함께 보여 줍니다.

2 이름같은 것을 부르는 여러 이름

한국어라이트박스, 사진 크게 보기, 이미지 뷰어
영어lightbox, image viewer, photo viewer, gallery overlay
같이 쓰는 말2005년 무렵에 나온 자바스크립트 라이브러리 이름에서 온 말입니다. 여러 장을 넘겨 보는 형태는 갤러리(gallery), 아래에 작은 그림을 늘어놓은 띠는 필름스트립(filmstrip)이라고 부릅니다. 작은 그림이 이어서 큰 그림으로 커지는 움직임은 공유 요소 전환이라고 합니다.
자주 잘못 부르는 이름모달 — 모달은 더 넓은 말이고, 라이트박스는 그중 그림을 보는 데만 쓰는 모달입니다.
캐러셀 — 캐러셀도 그림을 넘기지만, 화면 위에 겹쳐 뜨지 않고 화면 안의 제자리에서 넘깁니다.
썸네일 — 썸네일은 라이트박스를 열기 전 목록에 보이는 작은 그림을 가리킵니다.

4 해부도부분마다 붙은 이름

어두운 가림막으로 그림을 돋보이게 함
닫기(✕) · ← → · 몇 번째인지
닫으면 눌렀던 칸으로 초점이 돌아감
주소에 남겨 링크로 보낼 수 있음
Esc · 가림막 · ✕ 세 가지로 닫음
작은 그림을 억지로 늘리지 않음
  1. 가림막 어둡게 덮음뒤 화면을 어둡게 덮어 그림에 눈이 가게 합니다
  2. 조작 ✕ · ← → · 몇/몇마우스나 손가락으로도, 키보드로도 모두 다룰 수 있어야 합니다
  3. 초점 닫을 때 돌려주기닫으면 눌렀던 칸으로 초점을 돌려줍니다
  4. 주소 주소에 남기기주소에 남겨 두면 링크로 보낼 수 있습니다
  5. 닫는 방법 세 가지Esc, 가림막, ✕ 세 가지로 닫을 수 있습니다
  6. 크기 원본까지만작은 그림을 원본보다 억지로 늘리지 않습니다

라이트박스는 모달인데도 모달처럼 다루지 않는 경우가 많은 부품입니다. 그림을 보여 줄 뿐이라는 생각에 초점 가둠과 Esc 닫기, 초점 돌려주기를 빠뜨리기 쉽습니다. 그런데 여덟 장짜리 목록에서 세 번째 그림을 열었다 닫았을 때 초점이 맨 앞으로 가 버리면, 키보드 사용자는 원래 자리로 돌아가려고 Tab을 다시 세 번 눌러야 합니다.
반면 주소에 남기기는 들이는 품에 비해 얻는 것이 많습니다. 그림을 링크로 보낼 수 있고, 폰에서는 시스템 백으로 닫히며, 새로 고침해도 같은 그림이 열려 있습니다.

5 쓸 때 / 안 쓸 때

라이트박스를 만들 때 지킬 것

  • 닫으면 눌렀던 칸으로 초점 돌려주기
  • 주소에 남겨 링크 공유와 뒤로가기 닫기가 되게 하기
  • 원본보다 크게 늘리지 않기

라이트박스를 만들 때 피할 것

  • 초점을 가두지 않기. Tab을 누르면 초점이 뒤 화면의 링크로 나갑니다
  • Esc로 닫히지 않게 두기
  • 한 장뿐인데 화살표 두기
  • 그림 설명(alt)을 빠뜨리기

라이트박스 대신 다른 것을 써야 하는 경우 — 그림이 아닌 내용을 겹쳐 띄우려면 모달을 쓰고, 목록에 작게 보여 주는 그림은 썸네일에서 다룹니다. 작은 그림이 커지며 이어지는 움직임은 공유 요소 전환을 보고, 화면 전체를 덮어야 하면 전체 화면 레이어를 씁니다.

7 최소 마크업과 키보드구현할 때 지킬 최소 규칙

<dialog>를 쓰면 초점 가둠과 Esc 닫기를 따로 만들지 않아도 됩니다.

<dialog id="lb" aria-label="영수증 3">
  <img src="/r/3.jpg" alt="2026-11-12 모란상회 영수증">
  <button id="prev" aria-label="이전 그림">‹</button>
  <button id="next" aria-label="다음 그림">›</button>
  <button id="close" aria-label="닫기">✕</button>
  <p>3 / 8</p>
</dialog>

// 주소에 남기면 링크 공유와 뒤로가기 닫기가 따라온다
function open(i, fromBtn) {
  last = fromBtn;
  history.pushState({ photo: i }, '', `?photo=${i + 1}`);
  lb.showModal();                    // 초점 가둠 · Esc 가 따라온다
}
lb.addEventListener('close', () => last && last.focus());   // 초점 돌려주기
키와 마크업그때 일어나야 하는 일
Esc라이트박스를 닫습니다. <dialog>를 쓰면 저절로 됩니다
← →앞뒤 그림으로 넘깁니다. 이 키는 직접 붙여야 합니다
Tab초점이 라이트박스 안에 갇혀 밖으로 나가지 않습니다
열고 닫을 때의 초점열면 닫기 버튼으로, 닫으면 눌렀던 칸으로 옮깁니다
alt크게 보는 그림에도 설명이 필요합니다
확인하는 방법세 번째 그림을 Tab으로 찾아 열었다 닫은 뒤 초점이 어디에 있는지 봅니다

8 서버 쪽으로 치면백엔드 개념과 짝지어 보기

큰 그림은 따로 내려 주기목록에는 작은 그림을, 라이트박스에는 큰 그림을 따로 내려 줍니다.
앞뒤 그림 미리 받아 두기지금 보는 그림의 앞뒤 한 장씩을 미리 받아 두면 넘길 때 기다리지 않습니다.
원본 크기 함께 내려 주기그림의 원본 width·height를 함께 내려 주면 원본보다 억지로 늘리는 것을 막을 수 있습니다.

라이트박스는 어느 플랫폼에서나 생김새가 같고, 폰에서는 손짓 조작이 더해집니다.

사용자는 시스템 백으로 닫히기를 기본으로 기대합니다. 그래서 라이트박스를 열 때 방문 기록에 넣어 둡니다.

플랫폼 차이 때문에 자주 생기는 문제 — 폰에서는 아래로 쓸어 닫기가 거의 표준이 되었습니다. 웹에도 붙여 둘 만하지만, 그 손짓만 두면 PC에서 마우스나 키보드로는 닫을 수 없습니다. 안드로이드에서는 시스템 백으로 닫히는 것을 꼭 맞춰야 하는데, 열린 그림을 주소나 방문 기록에 넣어 두면 이 문제도 함께 해결됩니다.
