그림 하나를 보는 동안 뒤를 덮습니다. 모달과 같은 규칙을 따르고, 여기에 앞뒤로 넘기기가 붙습니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

그림을 눌러 크게 열어 보세요. ← → 로 옮기고 Esc 로 닫습니다.
닫았을 때 초점이 눌렀던 칸으로 돌아가야 합니다 — 안 그러면 키보드 사용자는 목록 맨 처음으로 튕겨 갑니다. 데모가 닫은 뒤 초점이 어디인지를 재서 적습니다.
주소에 남기면 그 그림을 링크로 보낼 수 있고 뒤로가기로 닫힙니다 — 데모가 지금 주소를 같이 보여 줍니다.

2 이름부르는 말이 여러 개다

한국어라이트박스, 사진 크게 보기, 이미지 뷰어
영어lightbox, image viewer, photo viewer, gallery overlay
같이 쓰는 말2005년 무렵의 자바스크립트 라이브러리 이름에서 온 말입니다. 여러 장을 넘겨 보는 꼴은 갤러리(gallery), 아래에 작은 그림을 늘어놓은 띠는 필름스트립(filmstrip)이라 합니다. 작은 그림에서 큰 그림으로 이어 붙는 움직임은 공유 요소 전환입니다.
자주 잘못 부름모달 — 모달은 더 넓은 말입니다. 라이트박스는 그림 전용입니다.
캐러셀 — 캐러셀은 안 겹치고 화면 안에서 넘깁니다.
썸네일 — 썸네일은 작은 그림 쪽입니다.

  2. 조작 ✕ · ← → · 몇/몇손과 키보드 둘 다
  3. 초점 돌려주기눌렀던 칸으로
  4. 주소 남기기링크로 보낼 수 있다
  5. 닫는 길 셋Esc · 가림막 · ✕
  6. 크기 원본까지만작은 그림을 억지로 늘리지 않는다

라이트박스는 모달이면서 모달처럼 안 다뤄지는 대표적인 자리입니다 — 그림이니까 괜찮겠지 싶어 초점 가둠도, Esc 도, 초점 돌려주기도 빠뜨리기 쉽습니다. 그런데 여덟 장짜리 목록에서 세 번째를 열었다 닫았을 때 초점이 맨 앞으로 가면 다시 세 번 Tab 을 눌러야 합니다.
주소에 남기는 것은 공짜로 얻는 이득이 큽니다 — 링크로 보낼 수 있고, 폰에서는 시스템 백으로 닫히며, 새로 고쳐도 그 그림이 열립니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 닫으면 눌렀던 칸으로 초점 돌려주기
  • 주소에 남겨 링크·뒤로가기가 되게 하기
  • 원본보다 크게 늘리지 않기

이럴 때는 안 쓴다

  • 초점을 안 가두기 — 뒤의 링크로 Tab 이 나간다
  • Esc 로 안 닫히게 두기
  • 한 장뿐인데 화살표 두기
  • 그림 설명(alt)을 빠뜨리기

대신 이걸 — 더 넓은 겹침은 모달, 작은 그림은 썸네일, 이어 붙는 움직임은 공유 요소 전환, 전체 화면이면 전체 화면 레이어.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

<dialog> 를 쓰면 초점 가둠과 Esc 가 공짜로 따라옵니다.

<dialog id="lb" aria-label="영수증 3">
  <img src="/r/3.jpg" alt="2026-11-12 모란상회 영수증">
  <button id="prev" aria-label="이전 그림">‹</button>
  <button id="next" aria-label="다음 그림">›</button>
  <button id="close" aria-label="닫기">✕</button>
  <p>3 / 8</p>
</dialog>

// 주소에 남긴다 — 링크·뒤로가기가 공짜로 된다
function open(i, fromBtn) {
  last = fromBtn;
  history.pushState({ photo: i }, '', `?photo=${i + 1}`);
  lb.showModal();                    // 초점 가둠 · Esc 가 따라온다
}
lb.addEventListener('close', () => last && last.focus());   // 초점 돌려주기
키일어나야 하는 일
Esc닫는다. <dialog> 면 저절로 된다
← →앞뒤 그림으로 — 직접 붙인다
Tab라이트박스 안에 갇힌다
초점열면 닫기, 닫으면 눌렀던 칸
alt큰 그림에도 설명이 필요하다
확인하는 법세 번째 그림을 Tab 으로 열었다 닫고 초점이 어디인지 본다

9 서버 쪽으로 치면백엔드 감각으로 번역

큰 그림은 따로목록에는 작은 그림, 라이트박스에는 큰 그림을 따로 내려 줍니다.
이웃 그림지금 그림의 앞뒤 하나씩을 미리 받아 두면 넘길 때 안 기다립니다.
원본 크기width·height 가 있으면 억지로 늘리는 것을 막을 수 있습니다.
