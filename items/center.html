가운데 맞추기

Centering

요소를 가운데에 놓는 방법은 다섯 가지나 되지만, 방법마다 가운데로 맞춰지는 범위가 다릅니다. 그래서 다른 레이아웃보다 유독 자주 틀립니다.

① 실물② 이름③ 상태④ 해부도⑤ 쓸 때⑥ 사례⑦ 마크업⑧ 백엔드 메모⑨ 플랫폼

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

다섯 칸 아래에는 가로·세로가 실제로 맞았는지 재서 표시해 두었습니다. 처음에는 다섯 칸 모두 맞아 보이지만, 글을 두 줄로 늘려 보면 margin: auto와 text-align은 세로 가운데가 어긋납니다. 두 방법은 상자를 위에서 일정한 거리만큼 떨어뜨려 놓았을 뿐이라서, 상자 높이가 바뀌면 세로 위치가 따라오지 않기 때문입니다.

2 이름같은 것을 부르는 여러 이름

한국어가운데 맞추기, 가운데 정렬, 센터링
영어centering, center alignment
같이 쓰는 말가로 가운데는 수평 정렬, 세로 가운데는 수직 정렬(vertical centering)이라고 부릅니다. place-items는 align-items와 justify-items를 한 번에 적는 단축 속성이고, place-content는 내용 덩어리 전체의 위치를 옮깁니다.
자주 잘못 부르는 이름vertical-align — 이름 때문에 세로 가운데에 쓸 것 같지만, 글줄 안에서 글자끼리 높이를 맞추는 속성이라서 블록을 가운데로 옮기지는 못합니다.
text-align: center — 글만 가운데로 옮기고, 상자 자체는 움직이지 않습니다.
align-content — items와 content는 옮기는 대상이 다릅니다. items는 자식 하나하나를, content는 줄 덩어리 전체를 옮깁니다.

3 가운데에 놓는 방법방법마다 맞출 수 있는 범위

4 해부도부분마다 붙은 이름

가운데
display: grid; place-items: center
display: flex; align-items + justify-content
margin-inline: auto 가로만 맞춤
position: absolute + translate(-50%, -50%)
text-align: center 글만 옮기고 세로는 못 맞춤
  1. 가운데에 놓인 것 centered item자식 하나일 수도, 여럿일 수도 있습니다. 가운데 위치는 자식이 아니라 부모가 정합니다
  2. 그리드 방법 place-items: center한 줄로 가로·세로를 함께 맞춥니다. 외울 것은 이것 하나면 됩니다
  3. 플렉스 방법 align-items + justify-content두 줄을 적어야 하고, 주축·교차축 개념을 알아야 해서 한 번 더 생각하게 됩니다
  4. 마진 방법 margin-inline: auto블록의 가로 가운데만 맞춥니다. 세로도 맞출 수 있다고 생각하는 것이 가장 흔한 착각입니다
  5. 절대 위치 방법 absolute + translate부모 크기에 영향을 주지 못하기 때문에 겹쳐 놓을 때만 씁니다
  6. 글 정렬 방법 text-align: center글줄만 가운데로 옮기고, 상자 자체는 제자리에 있습니다

'세로 가운데가 안 맞는다'는 문제는 대부분 margin: auto와 text-align을 세로에도 쓸 수 있다고 생각해서 생기지만, 두 속성은 가로에만 작동합니다. 세로 가운데는 자식 혼자서는 정할 수 없기 때문에, 세로를 맞추려면 부모를 플렉스나 그리드로 만들어야 합니다.

5 쓸 때 / 안 쓸 때

가운데 맞추기를 쓰는 경우

  • 빈 상태, 로딩 스피너, 아이콘 버튼처럼 부모 안에 하나만 놓을 때
  • 자식이 여럿이라도 다 가운데로 모아야 할 때
  • 세로 가운데가 필요할 때. 세로를 맞추는 방법은 그리드와 플렉스 두 가지뿐입니다

가운데 맞추기를 쓰지 않는 경우

  • 읽어야 하는 긴 글을 가운데 정렬할 때. 줄 시작 위치가 들쭉날쭉해서 읽기 힘듭니다
  • position: absolute로 가운데에 놓으면서 부모가 자식 높이만큼 커지길 기대할 때. 자식이 흐름에서 빠지므로 부모 높이가 0이 됩니다
  • vertical-align으로 블록을 옮기려 할 때. 이 속성으로는 블록이 움직이지 않습니다

가운데 맞추기 대신 다른 것을 써야 하는 경우 — 여러 요소를 한 줄로 세우면서 가운데에 모으려면 플렉스를, 판 전체를 칸으로 나눠야 하면 그리드를 씁니다. 화면 한가운데에 창을 띄우는 일이라면 모달을 봅니다.

6 자주 보는 모습구조만 따라 그린 재현 그림

7 최소 코드와 규칙외워 둘 한 줄과 지킬 규칙

다섯 가지를 다 외울 필요는 없습니다. 한 줄만 외우고 나머지는 이런 방법도 있다는 정도로 알아 두면 됩니다.

/* 대부분 이것 하나로 된다. 가로·세로를 함께 맞춘다 */
.center { display: grid; place-items: center; }

/* 많이 쓰는 플렉스 방식(두 줄) */
.center { display: flex; align-items: center; justify-content: center; }

/* 블록 하나를 가로로만 가운데에 놓는다 */
.container { max-width: 65ch; margin-inline: auto; }

/* 흐름에서 빠지므로 겹쳐 놓을 때만 쓴다 */
.overlay { position: absolute; left: 50%; top: 50%;
            transform: translate(-50%, -50%); }
지킬 규칙지키는 방법
가운데 위치는 부모에서 정하기가운데 놓기는 자식이 아니라 부모에 설정합니다. 자식만 고쳐서는 세로 가운데를 맞출 수 없습니다
place-items: center 한 줄 외워 두기한 줄로 가로·세로를 맞추며, 자식이 몇 개든 상관없습니다
margin: auto는 가로만 맞춘다는 점 기억하기세로 가운데에는 쓸 수 없는데, 쓸 수 있다고 생각하는 것이 가장 흔한 착각입니다
text-align은 글만 옮긴다는 점 기억하기글만 옮기고 상자 자체는 움직이지 않습니다
읽는 글은 가운데 정렬하지 않기줄 시작 위치가 들쭉날쭉해져서 다음 줄의 시작을 찾기 어렵습니다
absolute는 다른 방법이 안 될 때만 쓰기부모 높이에 영향을 주지 못해서 부모 높이가 0이 되는 일이 생깁니다

8 서버 쪽으로 치면백엔드 개념과 짝지어 보기

가운데 위치를 부모가 맡는 구조자식에게는 아무 값도 주지 않아도 됩니다. 부모 설정 하나로 모든 자식이 가운데로 모이기 때문에, 공통 레이아웃 컴포넌트로 빼 두기 좋습니다.
빈 상태와 로딩에 같은 래퍼 쓰기빈 상태와 스피너는 거의 항상 가운데에 놓입니다. 같은 래퍼 컴포넌트를 돌려쓰면 화면마다 위치가 다르게 보이는 일이 없어집니다.
부모 높이를 먼저 정해 두기부모 높이가 내용 높이와 같으면 가운데에 놓아도 제자리와 구별되지 않습니다. 그래서 부모에 min-height를 먼저 줘야 합니다.
