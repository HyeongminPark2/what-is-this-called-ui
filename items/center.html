가운데 맞추기

Centering

'가운데에 놓기'는 방법이 다섯 가지나 되는데 되는 범위가 다 다릅니다. 그래서 유독 자주 틀립니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

다섯 칸 아래에 가로·세로가 실제로 맞았는지 재서 표시해 뒀습니다. 처음엔 다섯 다 맞아 보이는데, 글을 두 줄로 늘려 보세요 — margin: auto와 text-align은 세로가 따라오지 않습니다. 위에서 일정한 거리만큼 떨어뜨려 놓은 것뿐이라 그렇습니다.

2 이름부르는 말이 여러 개다

한국어가운데 맞추기, 가운데 정렬, 센터링
영어centering, center alignment
같이 쓰는 말가로 가운데는 수평 정렬, 세로 가운데는 수직 정렬(vertical centering)이라 합니다. place-items는 align-items와 justify-items를 한 번에 적은 것이고, place-content는 내용 덩어리 전체를 옮깁니다.
자주 잘못 부름vertical-align — 이름 때문에 세로 가운데에 쓸 것 같지만, 글줄 안에서 글자끼리 맞추는 속성입니다. 블록을 가운데로 못 옮깁니다.
text-align: center — 글만 가운데로 갑니다. 상자 자체는 안 움직입니다.
align-content — items 와 content 는 다릅니다. content 는 줄 덩어리 전체를 옮깁니다.

3 가르는 기준형제들과 비교하는 네 축

뼈대를 다루는 것들은 '눈에 안 보이는데 자리를 정한다'는 점이 같습니다. 이 네 가지만 물어보면 갈립니다.

무엇을 정하나방향넘치면누가 값을 정하나
박스 모델상자 한 개의 크기해당 없음밖으로 삐져나온다내가
플렉스한 줄에 늘어놓기한 방향줄을 넘기거나 삐져나온다나 + 내용
그리드판을 칸으로 나누기두 방향칸끼리 자리를 빼앗는다나 + 내용
가운데 맞추기자식의 자리두 방향해당 없음나
넘침넘친 것을 어떻게 할지해당 없음이게 그 답이다나

한 줄로 — 외울 것은 하나입니다 — 부모에 display: grid; place-items: center. 가로·세로가 한 줄로 끝납니다.

4 방법되는 범위가 다 다르다

5 해부도부분 이름이 제일 안 알려진 지식

가운데
display: grid; place-items: center
display: flex; align-items + justify-content
margin-inline: auto — 가로만
position: absolute + translate(-50%, -50%)
text-align: center — 글에만. 세로는 못 맞춘다
  1. 가운데에 놓인 것 centered item자식 하나 또는 여럿. 자식이 아니라 부모가 정한다
  2. 그리드 방법 place-items: center한 줄로 가로·세로. 외울 것은 이것 하나면 된다
  3. 플렉스 방법 align-items + justify-content두 줄. 주축·교차축 개념이 필요해 한 번 더 생각하게 된다
  4. 가로만 margin-inline: auto블록의 가로 가운데. 세로는 못 맞춘다 — 가장 흔한 착각
  5. 흐름에서 빼기 absolute + translate부모 크기에 영향을 못 준다. 겹쳐 놓을 때만 쓴다
  6. 글만 text-align: center글줄만 가운데로. 상자 자체는 제자리에 있다

'세로 가운데가 안 된다'는 고민의 거의 전부가 margin: auto와 text-align을 세로에도 쓸 수 있다고 생각해서 생깁니다. 둘 다 가로 전용입니다. 세로를 맞추려면 부모가 플렉스나 그리드여야 합니다 — 세로 가운데는 자식 혼자서는 정할 수 없는 일입니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 부모 안에 하나만 놓을 때 — 빈 상태, 로딩 스피너, 아이콘 버튼
  • 자식이 여럿이라도 다 가운데로 모아야 할 때
  • 세로 가운데가 필요할 때 — 방법이 둘뿐입니다(그리드·플렉스)

이럴 때는 안 쓴다

  • 읽는 긴 글을 가운데 정렬하는 것 — 줄 시작이 들쭉날쭉해 읽기 힘듭니다
  • position: absolute로 가운데 놓고 부모 높이를 기대하는 것 — 흐름에서 빠져 부모가 0이 됩니다
  • vertical-align으로 블록을 옮기려는 것 — 안 됩니다

대신 이걸 — 여럿을 줄 세우며 가운데면 플렉스, 판을 짜면 그리드, 화면 가운데 띄우면 모달.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙외울 것은 한 줄

다섯 가지를 다 외울 필요는 없습니다. 한 줄만 외우고 나머지는 '그런 것도 있다'로 둡니다.

/* 이것 하나면 거의 끝난다 — 가로·세로 동시에 */
.center { display: grid; place-items: center; }

/* 많이 쓰이는 플렉스 방식 — 두 줄 */
.center { display: flex; align-items: center; justify-content: center; }

/* 가로만 — 블록 하나를 가운데로 */
.container { max-width: 65ch; margin-inline: auto; }

/* 겹쳐 놓을 때만 — 흐름에서 빠진다 */
.overlay { position: absolute; left: 50%; top: 50%;
            transform: translate(-50%, -50%); }
규칙지켜야 하는 것
부모가 정한다가운데 놓기는 자식이 아니라 부모의 일이다. 자식만 고치면 세로는 안 된다
place-items: center한 줄로 끝난다. 자식이 몇 개든 상관없다
margin: auto는 가로만세로 가운데에는 쓸 수 없다. 가장 흔한 착각
text-align은 글만상자 자체는 안 움직인다
읽는 글은 가운데 정렬하지 않는다줄 시작이 들쭉날쭉해져 눈이 다음 줄을 못 찾는다
absolute는 마지막 수단부모 높이에 영향을 못 줘서 부모가 0이 되는 일이 생긴다

9 서버 쪽으로 치면백엔드 감각으로 번역

가운데 놓기 = 부모의 책임자식에게 아무 값도 안 줘도 됩니다. 부모 설정 하나로 모든 자식이 따라오는 구조라, 공통 레이아웃 컴포넌트로 빼기 좋습니다.
빈 상태와 로딩빈 상태와 스피너는 거의 늘 가운데입니다. 같은 래퍼를 돌려쓰면 화면마다 다르게 보이는 일이 없어집니다.
높이가 없으면 가운데도 없다부모 높이가 내용과 똑같으면 '가운데'가 제자리입니다. min-height를 주는 것이 먼저입니다.

자주 생기는 사고 — 세 쪽 다 짧게 끝나는 일이라 소통 문제가 거의 없습니다. 다만 '가운데'가 무엇의 가운데인지는 확인하세요 — 화면 가운데인지, 카드 안 가운데인지, 글줄 가운데인지에 따라 전혀 다른 코드가 됩니다.
