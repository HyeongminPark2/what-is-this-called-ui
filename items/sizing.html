크기 정하기

Sizing

크기를 정하는 값은 여럿인데, 갈리는 지점은 하나입니다 — 칸이 좁아질 때 같이 줄어드는가.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

칸 폭을 좁히며 어떤 값이 넘치는지 보세요 — 넘친 줄은 빨갛게 표시됩니다.
width: 300px은 안 줄어 넘치고, max-width: 300px은 같이 줄어듭니다. 안 끊기는 긴 낱말로 바꾸면 더 많은 값이 무너집니다.

2 이름부르는 말이 여러 개다

한국어크기, 폭, 최소·최대 크기, 내용 기준 크기
영어sizing, intrinsic sizing, min-content / max-content / fit-content, clamp()
같이 쓰는 말내용이 크기를 정하는 방식을 내용 기준 크기(intrinsic sizing)라 하고, min-content·max-content·fit-content가 그 값들입니다. 최소·기본·최대를 한 줄로 적는 함수가 clamp()이고, 테두리·패딩을 크기에 넣을지는 box-sizing이 정합니다.
자주 잘못 부름반응형 — 폭에 따라 배치를 바꾸는 것은 브레이크포인트입니다. 크기 값은 안 끊고도 반응합니다.
종횡비 — 종횡비는 폭에 따른 높이입니다.
컨테이너 — 컨테이너와 최대 폭은 이 값들을 쓰는 한 패턴입니다.

뼈대는 눈에 안 보이지만 모든 화면이 그 위에 섭니다. 이 네 가지만 물어보면 갈립니다.

한 줄로 — 거의 늘 width가 아니라 max-width입니다. 그 한 글자 차이가 반응형의 절반입니다.

4 값별로좁아지면 어떻게 되나

5 해부도부분 이름이 제일 안 알려진 지식

width — 안 줄어든다. 칸이 좁아지면 넘친다
max-width — 좁아지면 같이 줄어든다
min-content — 가장 긴 낱말만큼
max-content — 안 끊고 한 줄로
fit-content — 둘 사이, 칸이 허락하는 만큼
clamp(최소, 기본, 최대) — 한 줄로
  1. width 안 줄어든다칸이 좁아지면 넘친다
  2. max-width 같이 줄어든다반응형의 기본값
  3. min-content 가장 긴 낱말더는 못 줄이는 폭
  4. max-content 한 줄로넘기기 쉽다. 표 칸 정도에만
  5. fit-content 둘 사이내용만큼 쓰되 칸을 안 넘는다
  6. clamp() 최소·기본·최대한 줄로 셋을 적는다

플렉스·그리드 자식에는 숨은 최소 크기가 있습니다. 기본값이 min-width: auto라서 내용보다 작아지지 않으려 버티고, 그래서 긴 글이나 긴 낱말이 들어가면 칸이 줄지 않고 통째로 넘칩니다. min-width: 0 한 줄이 그걸 풉니다 — 플렉스·그리드에서 되풀이해 나오는 바로 그 한 줄이고, 말줄임이 안 먹는 이유이기도 합니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 거의 늘 max-width로 적기
  • 버튼·칩처럼 내용만 한 것에 fit-content
  • 글줄 길이는 clamp()나 ch 단위로

이럴 때는 안 쓴다

  • width로 박기 — 좁은 화면에서 넘친다
  • max-content를 본문에 — 한 줄로 늘어난다
  • 플렉스 자식에 min-width: 0을 잊기
  • 높이를 박기 — 글자를 키우면 잘린다

대신 이걸 — 폭에 따른 높이는 종횡비, 글줄 길이는 컨테이너, 넘칠 때 처리는 넘침.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙이 크기의 계약서

max-width를 기본으로 두고, 플렉스 자식에는 min-width: 0을 잊지 않습니다.

/* 거의 늘 이쪽 */
.panel { max-width: 480px; width: 100%; }

/* 글줄 길이는 글자 수로 */
.prose { max-width: 68ch; }

/* 내용만큼만 — 버튼 · 칩 */
.chip { width: fit-content; }

/* 최소 · 기본 · 최대를 한 줄로 */
.gap { padding-inline: clamp(16px, 4vw, 40px); }

/* 플렉스 · 그리드 자식의 숨은 최소 크기를 푼다 */
.row > * { min-width: 0; }
키일어나야 하는 일
box-sizing: border-box테두리·패딩을 크기에 넣는다. 안 넣으면 계산이 어긋난다
min-width: 0플렉스·그리드 자식의 숨은 최소 크기를 푼다
ch 단위글자 폭 기준이라 글줄 길이에 맞는다
clamp()의 가운데vw만 쓰면 글자를 키워도 안 커진다. rem을 섞는다
높이는 min-height박으면 글이 커질 때 잘린다
max-content와 스크린 리더한 줄로 늘어나 가로 스크롤이 생기면 확대한 사람이 못 읽는다

9 서버 쪽으로 치면백엔드 감각으로 번역

글 길이가 크기를 정한다시안은 짧은 글로 그려집니다. 가장 긴 실제 값으로 한 번 채워 보면 어디가 무너지는지 보입니다.
번역같은 뜻이라도 말마다 길이가 다릅니다. width로 박아 두면 다른 말에서 깨집니다.

10 플랫폼마다 다른 이름같은 부품, 다른 말

내용이 크기를 정하게 한다는 생각은 같습니다.

웹max-width · clamp
max-width
정산
min-content·fit-content 같은 내용 기준 값이 표준에 있습니다.
iOSframe · layoutPriority
.frame(maxWidth:)가 max-width 자리입니다. 우선순위로 누가 줄어들지 정합니다.
안드로이드weight · wrapContent
wrapContent가 fit-content, weight가 flex: 1 자리입니다.

자주 생기는 사고 — "좁은 화면에서 삐져나와요"의 거의 전부가 width 한 글자입니다. 시안에 '폭 300'이라고 적혀 오면 그대로 width: 300px로 옮기기 쉬운데, 뜻은 대개 '최대 300'입니다. 핸드오프에서 어느 쪽인지 한 번 묻는 것으로 이 왕복이 사라집니다.
