체크박스

Checkbox

여러 개를 각각 켜고 끄는 네모 칸. 서로 독립이고, 보통 저장을 눌러야 적용됩니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

전체 선택을 보세요. 일부만 켜져 있을 때는 체크도 빈칸도 아닌 세 번째 모습이 됩니다 — 중간 상태(indeterminate)라 부르고, 체크박스에만 있습니다.
글자 아무 데나 눌러도 켜집니다. 라벨과 칸이 이어져 있기 때문이고, 손가락으로 쓸 때 큰 차이가 납니다.

2 이름부르는 말이 여러 개다

한국어체크박스, 확인란, 체크 상자
영어checkbox
같이 쓰는 말일부만 켜진 상태를 중간 상태(indeterminate·partial), 묶음 제목을 그룹 레이블(fieldset·legend)이라 합니다. 테두리를 두른 꼴은 박스형 체크.
자주 잘못 부름스위치 — 스위치는 누르는 즉시 적용되고 저장 버튼이 없습니다. 가장 잦은 혼동입니다.
라디오 — 라디오는 하나만 고릅니다. 하나만 고르게 할 거면 체크박스를 쓰면 안 됩니다.
토글 — '토글'은 켜고 끄는 모든 것을 뭉뚱그린 말이라 가려지지 않습니다.

4 상태그림 한 장으로는 못 배운다

5 해부도부분 이름이 제일 안 알려진 지식

정산 알림
– 전체 선택
✓ 정산 확정 · 매주 월요일
✓ 보안 경고
  1. 그룹 제목 legend · group label<fieldset>+<legend>. 스크린 리더가 무엇에 대한 묶음인지 먼저 읽어 준다
  2. 부모 체크 parent checkbox아래를 한 번에 켜고 끈다. 일부만 켜지면 중간 상태가 된다
  3. 라벨 label칸과 이어 둔다. 글자를 눌러도 켜져서 과녁이 몇 배 커진다
  4. 체크 칸 box최소 18px. 손가락 과녁은 라벨까지 합쳐 44px 이상
  5. 항목 이름 item label켰을 때 무엇이 일어나는지를 적는다
  6. 보조 설명 description조건이나 빈도. 라벨에 다 넣으려 하지 않는다
  7. 비활성 항목 disabled못 끄는 것. 흐리게만 두지 말고 이유를 적는다

중간 상태는 CSS 로는 못 만듭니다. el.indeterminate = true 로 자바스크립트에서만 켤 수 있고, 값으로는 '켜짐'이 아닙니다 — 보내질 때는 꺼진 것으로 갑니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 여러 개를 각각 켜고 끌 때
  • 약관 동의처럼 하나만 있어도 켜고 끄는 것일 때
  • 목록에서 여러 줄을 골라 한꺼번에 처리할 때

이럴 때는 안 쓴다

  • 하나만 골라야 할 때 → 라디오
  • 누르는 즉시 적용될 때 → 스위치. 저장 버튼이 없으면 체크박스가 아닙니다
  • 선택지가 열 개 넘게 늘어설 때 → 콤보박스나 접어 두기
  • 라벨 없이 칸만 두기 — 무엇을 켜는지 알 수 없습니다

대신 이걸 — 하나만 고르면 라디오, 즉시 적용이면 스위치, 둘셋 중 하나면 세그먼티드, 많으면 콤보박스.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

네이티브 <input type="checkbox">를 쓰면 키보드와 스크린 리더가 공짜입니다. accent-color 한 줄로 색만 바꿉니다.

<fieldset>
  <legend>정산 알림</legend>
  <label>
    <input type="checkbox" name="notify" value="settled">
    정산 확정
  </label>
</fieldset>

// 중간 상태는 속성이 아니라 프로퍼티다. HTML 로는 못 쓴다
all.indeterminate = on > 0 && on < kids.length;

/* 색만 바꾼다. 직접 그리면 키보드 조작을 다시 만들어야 한다 */
input[type=checkbox] { accent-color: var(--accent); }
키일어나야 하는 일
Space켜고 끈다. Enter는 안 먹는다(폼을 보낸다)
Tab칸마다 한 번씩 지난다. 라디오 그룹이 한 번인 것과 다르다
라벨 누름<label>로 감싸 두면 글자를 눌러도 켜진다
그룹<fieldset>+<legend>로 묶으면 묶음 제목이 먼저 읽힌다
중간 상태스크린 리더가 '부분 선택'으로 읽는다. 눈으로만 알리면 안 된다

9 서버 쪽으로 치면백엔드 감각으로 번역

체크박스 = 비트 집합서로 독립인 불리언 여럿입니다. 폼으로 보내면 켜진 것만 옵니다 — 꺼진 것은 키 자체가 안 와서, 서버는 '없음 = 꺼짐'으로 읽어야 합니다.
중간 상태는 값이 아니다보낼 때는 꺼진 것으로 갑니다. 화면에서만 쓰는 표시라 서버에 '부분'을 보내려면 따로 설계해야 합니다.
전체 선택 = 범위 연산보이는 것만 켜는지, 조건에 맞는 전부를 켜는지는 전혀 다른 요청입니다. 10,000건을 '전부 선택'했을 때 ID 를 다 보낼지 조건을 보낼지 정해야 합니다.
약관 동의 = 감사 기록언제 어떤 판본에 동의했는지를 남겨야 합니다. 체크 하나가 불리언이 아니라 이력이 됩니다.
