수량 스테퍼

Quantity stepper · number stepper

수량 스테퍼는 −와 ＋ 단추로 수를 하나씩 고치는 부품이라서 한두 번 고칠 때만 빠릅니다. 1에서 24까지 올리려면 ＋를 스물세 번 눌러야 합니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

'목표까지 ＋만 눌러 보기'를 눌러 보세요. 데모가 몇 번 눌러야 하는지를 세어 적어 주는데, 같은 수를 가운데 칸에 쳐서 넣으면 한 번에 끝납니다.
그래서 가운데 칸은 읽기 전용으로 두지 않습니다. 체크를 끄면 칸이 잠겨서 큰 수를 넣을 방법이 없어집니다.
단추는 44px은 되어야 손가락으로 정확히 누를 수 있습니다. 또 1에서 −, 최대에서 ＋는 꺼 두어야 합니다.

2 이름같은 것을 부르는 여러 이름

한국어수량 스테퍼, 수량 조절기, 숫자 스테퍼
영어quantity stepper, number stepper, spinner
같이 쓰는 말iOS에서는 Stepper, 안드로이드와 웹에서는 수량 선택기라고 부르기도 합니다. <input type="number">에 브라우저가 붙여 주는 작은 화살표는 스피너라고 합니다. 7부의 스테퍼와는 이름만 같고 전혀 다른 부품입니다.
자주 잘못 부르는 이름스테퍼(단계) — 7부의 스테퍼는 수를 고치는 부품이 아니라 흐름의 단계를 보여 주는 부품입니다.
슬라이더 — 슬라이더는 손잡이를 끌어 범위 안에서 값을 고릅니다.
숫자 입력 — 숫자 입력은 −·＋ 단추 없이 칸만 있는 부품입니다.

  1. − · ＋ 한두 번 고칠 때한두 번 고칠 때 씁니다. 그보다 많이 바꿀 때는 쳐서 넣는 편이 빠릅니다
  2. 가운데 칸 쳐서 넣는 자리큰 수를 넣을 수 있도록 잠그지 않습니다
  3. 끝값 단추 끄기1에서는 −를, 최대에서는 ＋를 끕니다
  4. 크기 44px 이상손가락으로 정확히 누를 수 있도록 44px 이상으로 둡니다
  5. 소리 바뀐 값 알리기aria-live나 role="status"로 바뀐 값을 읽어 줍니다
  6. 0 빼기인지 정하기0으로 내렸을 때 어떻게 할지 미리 정합니다

0으로 내렸을 때 어떻게 할지 정해 두지 않으면 사용자가 원하지 않은 결과가 생깁니다. 장바구니에서는 수량 0이 대개 상품을 '빼기'라는 뜻인데, 아무 안내 없이 상품이 사라지면 사용자는 자기가 무엇을 했는지 알 수 없습니다. 그래서 수량이 1일 때 − 자리를 휴지통 단추로 바꾸는 꼴을 흔히 쓰고, 이렇게 하면 사용자가 누르기 전에 무슨 일이 일어날지 알 수 있습니다.
꺼진 단추를 disabled로 두면 초점도 받지 않고 스크린 리더도 읽지 않기 때문에, 사용자는 단추가 왜 안 눌리는지 알 방법이 없습니다. aria-disabled로 두고 이유를 알려 주는 편이 낫습니다.

5 쓸 때 / 안 쓸 때

수량 스테퍼를 쓰는 경우

  • 가운데 칸에 쳐서 넣을 수 있게 하기
  • 단추를 44px 이상으로 두기
  • 값이 바뀌면 스크린 리더로 소리로도 알리기

수량 스테퍼를 쓰지 않는 경우

  • 가운데 칸을 잠그기. 큰 수를 넣으려면 단추를 수십 번 눌러야 합니다
  • 최소값과 최대값에서도 단추를 눌리게 두기
  • 0이 되었을 때 안내 없이 상품을 빼기
  • 단추를 작게 만들기. 손가락으로 정확히 누르기 어렵습니다

수량 스테퍼 대신 다른 것을 써야 하는 경우 — −·＋ 단추 없이 칸만 두려면 숫자 입력을 쓰고, 정해진 범위 안에서 값을 고르게 하려면 슬라이더를 씁니다. 수가 아니라 흐름의 단계를 보여 주려는 것이라면 스테퍼가 맞습니다. 단추 크기를 얼마로 잡을지는 터치 타깃에서 다룹니다.

7 최소 마크업과 키보드구현할 때 지킬 최소 규칙

입력 칸 하나와 단추 두 개로 만듭니다. 끝값에서는 단추를 aria-disabled로 두고 왜 안 눌리는지 알려 줍니다.

<div class="qty">
  <button type="button" aria-label="하나 줄이기"
          aria-disabled="true">−</button>
  <input id="qty" inputmode="numeric" value="1"
         aria-label="수량">
  <button type="button" aria-label="하나 늘리기">＋</button>
</div>
<p role="status" class="sr-only">수량 1</p>

.qty button { min-width: 44px; min-height: 44px; }

8 서버 쪽으로 치면백엔드 개념과 짝지어 보기

최대 수량을 서버가 알려 주기재고나 구매 한도가 있으면 서버가 최대 수량을 내려 줘야 화면이 끝값에서 ＋를 끌 수 있습니다.
수량 0의 뜻을 API에서 정하기수량 0이 '빼기'인지 '0개 주문'인지 API에서 정해 두어야 화면도 그 뜻에 맞춰 동작할 수 있습니다.
＋를 빠르게 연달아 누를 때＋를 연달아 누를 때마다 요청을 보내면 서버로 요청이 몰립니다. 그래서 디바운스를 두거나 마지막 값만 보냅니다.
