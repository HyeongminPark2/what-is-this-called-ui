태그

Tag

생김새가 거의 같아 가장 많이 섞여 쓰입니다. 가르는 질문은 셋입니다 — 눌리나 · 지울 수 있나 · 혼자 서나.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

무엇을 만들지 골라 보세요 — 데모가 그 셋에 어떻게 답하는지 표로 적습니다.
태그는 분류를 보여 주기만 합니다. 칩은 눌러서 거르고, 입력 태그는 지울 수 있습니다. 배지는 혼자 서지 못하고 무언가에 붙어 숫자를 알립니다 — 눌리는 것은 배지가 붙은 쪽입니다.

2 이름부르는 말이 여러 개다

한국어태그, 라벨, 꼬리표, 분류
영어tag, label, pill, token
같이 쓰는 말입력칸 안에서 값 하나하나가 알약이 되는 것을 토큰(token)이나 태그 인풋이라 합니다. 깃허브·지라에서 쓰는 색 있는 꼬리표는 라벨(label)이라 부르는데, HTML 의 <label> 과는 전혀 다른 말입니다.
자주 잘못 부름칩 — 칩은 눌러서 거릅니다. 태그는 안 눌립니다.
배지 — 배지는 혼자 서지 못합니다.
버튼 — 알약처럼 생겼다고 버튼은 아닙니다. 동작이 있어야 버튼입니다.

3 가르는 기준형제들과 비교하는 네 축

표시 부품은 '보여 주기만 한다'는 점이 같습니다. 이 네 가지만 물어보면 갈립니다.

무엇을 담나전체가 눌리나어떻게 모이나내용이 길어지면
카드한 덩어리보통 눌린다그리드로높이가 늘어난다
리스트 아이템한 건보통 눌린다세로 목록으로말줄임한다
아바타사람·조직 하나안 눌린다겹쳐 쌓는다고정 — 넘치면 +N
배지숫자나 한 낱말안 눌린다혼자 안 선다 — 붙는다고정 — 넘치면 99+
칩한 낱말눌린다가로로 줄바꿈말줄임하거나 줄을 넘긴다
스탯 타일숫자 하나가끔 눌린다가로 한 줄로단위를 줄인다(1.2만)
타임라인사건들의 순서항목만세로로 꿴다아래로 길어진다
별점점수 하나읽기용은 안 눌린다줄 안에 들어간다고정 — 별 다섯
아이콘뜻 하나혼자서는 안 눌린다글자 옆에 붙는다고정 — 글자가 대신 길어진다
썸네일그림 하나보통 눌린다격자로고정 — 잘리거나 여백이 남는다
테이블 행한 건의 여러 값전체 또는 주 열만세로로 쌓인다말줄임한다
키-값 목록이름과 값의 짝안 눌린다세로로 쌓인다값이 먼저 잘린다
미디어 오브젝트그림 + 글보통 눌린다세로 목록으로글 쪽만 늘어난다
접히는 글제목과 본문제목이 눌린다세로로 포갠다접어 둔다
태그한 낱말안 눌린다가로로 줄바꿈말줄임하거나 +N

한 줄로 — 눌리나 · 지울 수 있나 · 혼자 서나. 이 셋만 물으면 배지·칩·태그가 갈립니다.

4 상태그림 한 장으로는 못 배운다

5 해부도부분 이름이 제일 안 알려진 지식

태그 — 분류를 보여 준다 · 안 눌린다
칩 — 눌러서 걸러낸다 · aria-pressed
입력 태그 — 지울 수 있다 · ✕ 에 이름을 준다
배지 — 혼자 서지 못한다 · 무언가에 붙는다
줄이 넘치면 +N 으로 접는다
색으로만 뜻을 싣지 않는다
  1. 태그 안 눌림분류를 보여 주기만
  2. 칩 눌림aria-pressed 로 상태
  3. 입력 태그 지움✕ 에 이름을 준다
  4. 배지 혼자 못 섬붙는 쪽이 눌린다
  5. 많을 때 +N줄이 세 줄 넘기 전에 접는다
  6. 색 혼자 쓰지 않기글자가 뜻을 진다

셋을 섞어 쓰면 누를 수 있는지를 눈으로 가릴 수 없게 됩니다 — 같은 알약인데 어떤 것은 눌리고 어떤 것은 안 눌리면 사용자는 전부 눌러 보게 됩니다. 한 화면 안에서는 한 가지만 쓰거나, 쓰더라도 눌리는 것과 안 눌리는 것의 생김새를 다르게 둬야 합니다.
색으로 분류를 알리는 것도 흔한데, 색만으로는 상태 색에서 본 문제가 그대로 생깁니다 — 글자가 뜻을 지고 색은 거드는 역할이어야 합니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 한 화면에서는 한 가지만 쓰기
  • 눌리는 것은 <button>, 아닌 것은 <span>
  • 지우기 ✕ 에 '○○ 지우기' 이름 붙이기

이럴 때는 안 쓴다

  • 안 눌리는 태그를 버튼으로 만들기 — 누를 줄 알게 된다
  • 눌리는 칩을 <span> 으로 두기 — 키보드로 못 쓴다
  • 색으로만 분류 알리기
  • 줄이 다섯 줄 되도록 다 늘어놓기 — +N 으로 접는다

대신 이걸 — 눌러서 거르면 칩, 숫자를 붙이면 배지, 값을 고르는 칸이면 콤보박스, 거르기 화면 전체는 필터와 패싯.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

눌리느냐가 태그를 가릅니다 — 눌리면 버튼, 아니면 span 입니다.

<!-- 태그 — 보여 주기만 한다 -->
<ul class="tags">
  <li>정산</li><li>카드</li>
</ul>

<!-- 칩 — 눌러서 켜고 끈다 -->
<button class="chip" aria-pressed="true">카드</button>

<!-- 입력 태그 — 값 하나하나를 지울 수 있다 -->
<span class="token">정산
  <button aria-label="정산 지우기">✕</button>
</span>
키일어나야 하는 일
aria-pressed칩이 켜졌는지. 색만으로는 안 들린다
Backspace입력 태그에서 마지막 값을 지우는 관습이 있다
aria-label✕ 에는 무엇을 지우는지까지 적는다
<ul>태그 묶음은 목록이다 — 몇 개인지가 소리로 전해진다
Tab안 눌리는 태그는 멈추지 않는다
확인하는 법Tab 으로 지나며 눌리는 것만 멈추는지 본다

9 서버 쪽으로 치면백엔드 감각으로 번역

태그는 이름과 열쇠를 같이{id: "card", name: "카드"} 처럼 주면 걸러낼 때 이름이 아니라 열쇠를 씁니다.
개수 제한입력 태그에 몇 개까지 넣을 수 있는지는 서버가 정합니다 — 화면에 미리 적어 둡니다.
자주 쓰는 태그많이 쓰인 순서를 주면 고르기 목록의 차례를 정할 수 있습니다.

10 플랫폼마다 다른 이름같은 부품, 다른 말

이름이 가장 어지러운 부품입니다.

웹직접 만듦
정산카드
정해진 부품이 없어 이름도 제각각입니다 — 팀 안에서 먼저 정해 두는 편이 낫습니다.
iOS없다 — Capsule
정식 부품이 없습니다. Capsule 모양으로 직접 만들고, 거르기에는 세그먼티드를 더 씁니다.
안드로이드Chip
Material 에 Chip 이 네 종류로 정리돼 있습니다 — assist · filter · input · suggestion.

자주 생기는 사고 — Material 이 칩을 네 종류로 나눠 이름을 붙여 둔 것이 가장 쓸모 있는 정리입니다 — 거르는 칩(filter), 값을 넣는 칩(input), 권하는 칩(suggestion), 동작하는 칩(assist). 우리말로 '태그'라 부르는 것은 대개 필터 칩이거나 그냥 분류 표시입니다. 이름을 정할 때 이 네 갈래에 대 보면 무엇을 만들고 있는지가 분명해집니다.
