2 이름부르는 말이 여러 개다

한국어스프링, 용수철, 물리 기반 애니메이션
영어spring animation, physics-based animation
같이 쓰는 말세게 당기는 정도가 뻣뻣함(stiffness·tension), 흔들림이 잦아드는 정도가 감쇠(damping·friction), 움직이는 것의 무게가 질량(mass)입니다. 목표를 지나치는 것을 오버슈트(overshoot), 잦아드는 흔들림을 세틀링이라 합니다. 지나치지 않게 딱 맞춘 상태가 임계 감쇠(critically damped)입니다.
자주 잘못 부름바운스 — 튕기는 느낌을 내는 이징 곡선도 있지만, 그건 길이가 정해진 곡선입니다.
이징 — 스프링은 곡선표가 아니라 매 프레임 계산입니다. cubic-bezier로 흉내만 냅니다.
관성 스크롤 — 손을 떼도 미끄러지는 것은 제스처 쪽입니다.

움직임은 장식이 아니라 말입니다. 이 네 가지만 물어보면 갈립니다.

한 줄로 — 끌어서 다루는 것에는 스프링, 순서대로 이어지는 것에는 곡선. 끝나는 때를 알아야 하면 스프링은 맞지 않습니다.

4 튕김별로목표를 얼마나 지나치나

5 해부도부분 이름이 제일 안 알려진 지식

점선 = 목표 — 한 번 지나친다
뻣뻣함(stiffness) — 얼마나 세게 당기나
감쇠(damping) — 얼마나 빨리 잦아드나
끌던 속도를 그대로 이어받는다
끝나는 때가 정해져 있지 않다
  1. 곡선 감쇠 진동목표를 지나쳤다 돌아온다. 이게 용수철의 모양이다
  2. 목표선 1.0점선. 여기서 멈추는 게 아니라 여기를 중심으로 흔들린다
  3. 뻣뻣함 stiffness클수록 빨리 당겨진다. 작으면 흐느적거린다
  4. 감쇠 damping클수록 빨리 잦아든다. 작으면 오래 흔들린다
  5. 이어받는 속도 initial velocity끌던 손가락 속도를 그대로 받는다 — 스프링의 진짜 값어치
  6. 끝 정해져 있지 않다충분히 가까워지면 끊는다. 몇 ms 인지 미리 알 수 없다

스프링의 값어치는 '예뻐서'가 아니라 끌던 속도를 이어받기 때문입니다. 손가락으로 시트를 빠르게 튕기면 그 속도 그대로 날아가고, 천천히 밀면 천천히 자리 잡습니다 — 곡선으로는 흉내 낼 수 없는 연결입니다. 반대로 끝나는 때를 알아야 하는 곳에는 맞지 않습니다. '애니메이션이 끝나면 다음 것' 같은 이어 붙이기는 길이가 정해진 곡선 쪽이 쉽습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 끌어서 다루는 것 — 시트, 카드 넘기기, 당겨서 새로고침
  • 손을 뗀 뒤 이어지는 움직임
  • 작고 자주 보는 누르는 느낌 — 살짝 눌렸다 돌아오기

이럴 때는 안 쓴다

  • 읽을 글이 실린 것 — 또 움직여서 읽기를 방해한다
  • 순서대로 이어 붙이는 연출 — 끝나는 때를 모른다
  • 흔들림을 세 번 이상 — 거의 늘 과하다
  • 모션 줄이기를 켠 사람에게 — 흔들림이 가장 어지럽다

대신 이걸 — 길이를 알아야 하면 이징 곡선, 손가락을 따라가는 규칙은 제스처, 줄이 차례로면 차례로 들어오기.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙이 스프링의 계약서

웹에는 표준 스프링이 없어 매 프레임 계산하거나 라이브러리를 씁니다.

// 감쇠 진동: 목표를 지나쳤다 돌아온다
function spring(el, to, v0) {
  const k = 180, c = 22, m = 1;     // 뻣뻣함 · 감쇠 · 질량
  let x = 0, v = v0 || 0, last = performance.now();

  (function step(now) {
    const dt = Math.min((now - last) / 1000, 0.032); last = now;
    const a = (-k * (x - to) - c * v) / m;
    v += a * dt; x += v * dt;
    el.style.transform = `translateY(${x.toFixed(2)}px)`;
    // 충분히 가까워지고 느려지면 끊는다
    if (Math.abs(x - to) > 0.4 || Math.abs(v) > 0.4) requestAnimationFrame(step);
    else el.style.transform = `translateY(${to}px)`;
  })(last);
}
키일어나야 하는 일
표준이 없다CSS 에는 스프링이 없다. linear()로 곡선을 베껴 넣는 방법이 생겼다
끝을 끊는 조건거리와 속도가 둘 다 작아졌을 때. 하나만 보면 안 멈춘다
dt에 상한을 둔다탭을 다시 열면 dt가 몇 초가 되어 튕겨 나간다
이어받는 속도pointerup 직전 몇 프레임의 평균을 쓴다. 마지막 한 프레임만 쓰면 튄다
prefers-reduced-motion지나침을 0 으로 내리거나 그냥 끝 값으로 보낸다
초점·읽기스프링이 끝나기를 기다렸다 초점을 옮기지 않는다 — 끝나는 때를 모른다

9 서버 쪽으로 치면백엔드 감각으로 번역

서버와는 상관없다전부 화면 쪽 계산입니다. 다만 매 프레임 도는 코드라 느린 기기에서 다른 일을 밀어냅니다.
끝을 기다려 요청하지 않는다끝나는 때가 정해져 있지 않으니, 움직임이 멎기를 기다렸다 저장하면 얼마나 걸릴지 모릅니다.
탭이 쉬면 멈춘다requestAnimationFrame은 배경 탭에서 멎습니다. 돌아오면 끝 값으로 바로 보냅니다.
