아이콘 글꼴

Icon font

글자 자리에 그림을 넣은 글꼴. 색과 크기가 공짜였지만, 지금은 SVG 가 거의 모든 면에서 낫습니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

색을 바꿔 보세요 — 아이콘 글꼴은 color, SVG 는 stroke 로 따라옵니다. 둘 다 되는 것이 옛 장점이었습니다.
글꼴을 못 받았을 때를 켜면 그 자리에 엉뚱한 글자나 네모가 남습니다. 아래 표에서 나머지 차이도 함께 볼 수 있습니다.

2 이름부르는 말이 여러 개다

한국어아이콘 글꼴, 아이콘 폰트, 글립 아이콘
영어icon font, glyph icon, webfont icon
같이 쓰는 말글꼴 안의 글자 하나가 글립(glyph)이고, 아이콘을 넣어 두는 자리가 사용자 영역(Private Use Area)입니다. 여러 SVG 를 한 파일에 모아 <use>로 꺼내 쓰는 것이 SVG 스프라이트, HTML 안에 직접 적는 것이 인라인 SVG입니다.
자주 잘못 부름웹폰트 — 웹폰트는 글자를 그리는 글꼴입니다. 받는 방식만 같습니다.
이모지 — 이모지는 OS 가 가진 그림이라 우리가 모양을 못 정합니다.
아이콘 — 아이콘은 그림 자체, 이쪽은 그것을 넘기는 방식입니다 — 에셋 내보내기.

4 두 방식무엇이 다른가

5 해부도부분 이름이 제일 안 알려진 지식

글자 자리에 그림을 넣은 글꼴
color · font-size 가 그대로 먹는다 — 옛 장점
못 받으면 네모나 엉뚱한 글자가 남는다
스크린 리더가 그 글자를 읽어 버린다
안 쓰는 아이콘까지 통째로 받는다
SVG — currentColor 로 색이 따라오고 안 깨진다
  1. 글립 글자 자리의 그림글자라서 글꼴 규칙을 그대로 따른다
  2. 색 · 크기 color · font-size옛 장점. 지금은 SVG 도 된다
  3. 못 받으면 네모가 남는다글꼴이 늦거나 막히면 그 자리만 깨진다
  4. 읽히는 방식 글자를 읽는다aria-hidden이 없으면 엉뚱하게 읽힌다
  5. 받는 양 통째로320개 중 12개만 써도 전부 받는다
  6. SVG currentColor색이 따라오고 깨질 것이 없다

아이콘 글꼴이 널리 쓰인 것은 그때는 그게 가장 쉬웠기 때문입니다 — 색과 크기를 CSS 로 바꾸는 것이 SVG 로는 번거롭던 시절이 있었습니다. 지금은 fill="currentColor" 한 줄이면 같은 일이 되고, 깨짐·읽힘·용량 쪽은 여전히 글꼴이 불리합니다. 그래서 새로 만들면 SVG이고, 이미 글꼴로 되어 있는 곳은 aria-hidden만 제대로 붙여 두면 굳이 급히 걷어낼 이유는 없습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 이미 글꼴로 되어 있고 바꿀 일정이 없을 때
  • 아이콘이 아주 많고 전부 한 색일 때
  • 쓸 때는 aria-hidden을 반드시

이럴 때는 안 쓴다

  • 새로 시작하면서 아이콘 글꼴 고르기
  • aria-hidden 없이 쓰기 — 엉뚱하게 읽힌다
  • 열두 개 쓰려고 320개짜리 글꼴 받기
  • 두 색이 필요한 아이콘을 글꼴로

대신 이걸 — 거의 모든 경우 SVG, 글자용 글꼴은 웹폰트, 배율 이야기는 화면 밀도.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 아이콘의 계약서

어느 방식이든 읽히는 방식을 정해야 합니다.

<!-- 글자 옆이면 아이콘은 장식이다 -->
<button>
  <svg aria-hidden="true" fill="currentColor">…</svg>
  삭제
</button>

<!-- 아이콘만 있으면 이름을 준다 -->
<button aria-label="모란상회 삭제">
  <svg aria-hidden="true">…</svg>
</button>

<!-- 아이콘 글꼴을 쓴다면 — 글자가 읽히지 않게 -->
<i class="icon icon-trash" aria-hidden="true"></i>
키일어나야 하는 일
aria-hidden="true"글꼴이든 SVG 든 장식이면 숨긴다
아이콘만이면 이름aria-label이 없으면 이름 없는 버튼이 된다
<i> 태그원래 뜻은 기울임이다. 아이콘 자리로 쓰는 것은 관례일 뿐 의미가 없다
currentColor글자색을 따라간다. 다크 모드가 공짜로 해결된다
대비비아이콘도 3:1은 넘어야 한다 — 흐린 회색 아이콘이 흔한 사고
눌리는 넓이아이콘이 24px 이어도 44px은 눌려야 한다

9 서버 쪽으로 치면백엔드 감각으로 번역

글꼴은 캐시가 잘 먹는다한 파일이라 한 번 받으면 계속 씁니다. 그게 옛 장점이었습니다.
SVG 스프라이트여러 아이콘을 한 파일에 모아 <use>로 꺼내면 요청은 하나입니다.
쓰는 것만 추리기빌드에서 쓰인 아이콘만 모으면 글꼴이든 스프라이트든 크기가 확 줄어듭니다.
받은 SVG 를 훑는다남이 만든 SVG 에 id·style이 섞여 와 다른 그림과 부딪힙니다.
