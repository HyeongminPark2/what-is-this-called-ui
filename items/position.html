2 이름부르는 말이 여러 개다

한국어포지션, 위치 지정, 절대 위치, 고정
영어position, static / relative / absolute / fixed / sticky
같이 쓰는 말static이 아닌 값이 걸린 요소를 positioned 라 하고, absolute는 가장 가까운 positioned 조상을 포함 블록(containing block)으로 삼습니다. top·right·bottom·left를 묶어 오프셋이라 하고, 요즘은 inset 한 줄로 적습니다.
자주 잘못 부름z-index — z-index는 앞뒤이고 포지션은 자리입니다. 다만 z-index 는 positioned 에서만 먹습니다.
float — 옛 배치 방법입니다. 지금은 플렉스·그리드를 씁니다.
스티키 — 스티키는 포지션의 한 값이지만 다루는 바가 달라 따로 뒀습니다.

4 다섯 값자리를 차지하나

5 해부도부분 이름이 제일 안 알려진 지식

static — 기본. top · left 가 안 먹는다
relative — 자리는 그대로, 보이기만 옮긴다
absolute — 흐름에서 빠진다. 기준은 가까운 positioned 조상
fixed — 화면을 기준으로. 굴려도 안 움직인다
sticky — relative 와 fixed 사이
transform 이 걸린 조상은 fixed 의 기준이 되어 버린다
  1. static 기본흐름대로. 오프셋이 안 먹는다
  2. relative 자리는 그대로보이기만 옮긴다. 기준점 노릇도 한다
  3. absolute 흐름에서 빠짐기준은 가까운 positioned 조상
  4. fixed 화면 기준굴려도 안 움직인다
  5. sticky 둘 사이자리는 차지하면서 붙는다
  6. 가로채는 것 transform걸린 조상이 fixed 의 기준이 되어 버린다

fixed가 화면에 안 붙는다는 사고는 거의 늘 조상 어딘가에 transform·filter·will-change가 걸려 있어서입니다. 그 속성들은 새 기준점을 만들기 때문에, fixed가 화면이 아니라 그 상자를 따릅니다. 애니메이션을 넣으려고 transform을 건 부모가 그 안의 떠 있는 메뉴를 가둬 버리는 식이라, 원인과 결과가 멀리 떨어져 찾기 어렵습니다 — 무엇을 움직이나와 같은 뿌리입니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 겹쳐 올리는 것 — 배지·닫기 버튼·떠 있는 메뉴
  • 기준을 만들 때 부모에 relative
  • 화면에 붙여 둘 것 — 단, transform 조상을 확인하고

이럴 때는 안 쓴다

  • 배치를 absolute로 — 플렉스·그리드가 먼저다
  • relative를 아무 데나 — 기준이 엉뚱한 데 생긴다
  • fixed로 폰 바닥에 붙이기 — 키보드가 덮는다
  • 오프셋만 주고 position을 안 주기 — 아무 일도 안 난다

대신 이걸 — 한 방향 배치는 플렉스, 두 방향은 그리드, 붙었다 떨어지는 것은 스티키.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙이 자리의 계약서

기준을 만들 부모에 relative를 걸고, 자식에 오프셋을 줍니다.

.card {
  position: relative;        /* 기준점을 만든다 */
}
.card .badge {
  position: absolute;
  top: -6px; right: -6px;   /* 또는 inset 한 줄로 */
}

/* 바닥 막대 — 폰 키보드와 세이프 에어리어를 함께 */
.cta-bar {
  position: fixed;
  inset: auto 0 0 0;
  padding-bottom: env(safe-area-inset-bottom);
}

/* ✕ 조상에 transform 이 있으면 fixed 가 화면이 아니라 그 상자를 따른다 */
.animated-parent { transform: translateY(0); }
키일어나야 하는 일
오프셋만으로는 안 된다position이 static이면 top·left가 통째로 무시된다
inset네 방향을 한 줄로. inset: 0이 꽉 채우기다
z-indexpositioned 에서만 먹는다. static에는 안 통한다
초점 순서는 안 바뀐다absolute로 옮겨도 Tab 은 마크업 순서다 — 보이는 순서와 읽는 순서
fixed와 transform조상에 걸려 있으면 기준이 가로채진다
폰 바닥fixed는 키보드를 모른다. visualViewport로 올려 준다

9 서버 쪽으로 치면백엔드 감각으로 번역

서버와는 상관없다전부 화면 쪽 배치입니다. 다만 떠 있는 요소가 많으면 그리기가 무거워집니다 — 무엇을 움직이나.
인쇄fixed는 인쇄에서 매 쪽에 찍히거나 사라집니다. 인쇄용 스타일을 따로 둡니다.
