숫자와 단위 쓰기

Writing numbers & units

같은 값도 어디에 적느냐에 따라 다르게 씁니다. 그리고 단위 없는 숫자는 아무것도 알려 주지 않습니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

값과 자리를 바꿔 보세요 — 표 안에서는 자릿수를 맞춰 세로로 견주게, 요약 타일에서는 크게 줄여 읽히게 적습니다.
한국어는 만·억으로 끊어 읽으므로 ‘1.2M’보다 ‘128만 원’이 훨씬 빨리 읽힙니다. 아래에는 건수·비율에서 자주 틀리는 것을 모아 두었습니다.

2 이름부르는 말이 여러 개다

한국어자릿수 구분, 천 단위 쉼표, 단위 표기, 반올림
영어number formatting, thousands separator, abbreviation, rounding
같이 쓰는 말세 자리마다 찍는 쉼표가 천 단위 구분이고, 큰 수를 줄이는 것이 약어 표기(abbreviation)입니다. 브라우저가 말에 맞춰 적어 주는 장치가 Intl.NumberFormat이고, 화폐·퍼센트·단위까지 다룹니다.
자주 잘못 부름숫자 꼴 — 숫자 꼴은 글자의 생김새(등폭 숫자)입니다. 이쪽은 무엇을 적을지입니다.
포맷팅 — 넓은 말이라 날짜·시간까지 섞입니다. 날짜와 시간은 따로입니다.
단위 — 길이·무게의 단위계와는 다릅니다. 화면에서는 원·건·%가 대부분입니다.

3 가르는 기준형제들과 비교하는 네 축

화면의 말은 꾸미는 것이 아니라 일하는 것입니다. 이 네 가지만 물어보면 갈립니다.

무엇을 알려야 하나흔한 실수고치는 기준한국어에서 더 조심할 것
버튼 문구누르면 무슨 일이 나나‘확인’ · ‘제출’동사 + 두세 어절조사 없이 끝낸다
오류 문구무엇이 · 왜 · 어떻게코드만 보여 주기다음 수가 있나사과보다 다음 수
빈 상태 문구왜 비었고 뭘 하면 되나‘데이터가 없습니다’네 경우를 가른다명사로 끝내지 않는다
자리글과 헬퍼 텍스트형식의 보기레이블을 자리글로셋을 따로 둔다보기를 진짜처럼
한국어 UI같은 말을 한국어로번역투소리 내어 읽어 본다조사 · 주어 생략
날짜와 시간 쓰기언제인지기계 꼴 그대로얼마나 지났나로 가른다오전 · 오후와 요일
숫자와 단위 쓰기얼마인지단위 없는 숫자자리에 따라 끊는다만 · 억으로 읽는다
말투와 높임우리가 누구인지화면마다 다른 말투하나로 정한다해요체인가 합쇼체인가

한 줄로 — 단위를 꼭 붙이고, 자리에 맞게 끊으세요. 그리고 한국어에서는 K·M 이 아니라 만·억입니다.

4 자리별로같은 값, 다른 적기

5 해부도부분 이름이 제일 안 알려진 지식

표 안 — 1,284,000원. 자릿수를 맞춘다
요약 타일 — 128만 원. 크게 줄여 읽힌다
단위를 꼭 붙인다 — 원인가 건인가
0건 · 1건 — 그대로 적는다. 복수형이 없다
소수점은 한 자리까지 — 33.3%
1.28M — 한국어는 만 단위로 끊어 읽는다
  1. 표 안 1,284,000원자릿수를 맞춰 세로로 견주게
  2. 요약 타일 128만 원크게 줄여 한눈에
  3. 단위 원 · 건 · %반드시 붙인다. 없으면 뜻이 없다
  4. 건수 0건 · 1건한국어에는 복수형이 없다
  5. 소수점 한 자리까지33.3%. 더 적으면 틀린 인상을 준다
  6. K · M 쓰지 않는다한국어는 만·억으로 끊는다

반올림은 합계를 깨뜨립니다. 33.33% · 33.33% · 33.33% 를 각각 한 자리로 반올림하면 33.3 × 3 = 99.9 가 되어 100%가 안 됩니다. 비율을 여럿 늘어놓는 화면(차트 범례, 구성비 표)에서는 가장 큰 항목에 나머지를 몰아주거나, '합이 100%가 안 될 수 있습니다'를 작게 적어 둡니다. 작은 값을 0으로 만들지 않는 것도 같은 줄기입니다 — 0.4%를 0%로 적으면 '없다'는 말이 되어 버립니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 단위를 꼭 붙이기 — 원 · 건 · %
  • 표에서는 자릿수를 맞추고 오른쪽 정렬
  • 요약에서는 만·억으로 줄이기

이럴 때는 안 쓴다

  • 단위 없는 숫자 — 무엇의 숫자인지 모른다
  • K · M 쓰기 — 한국어 독자는 한 번 더 계산한다
  • 0 을 ‘-’ 나 빈칸으로 — 0건이라고 적는다
  • 작은 값을 0 으로 반올림 — 없는 것처럼 보인다

대신 이걸 — 글자의 생김새는 숫자 꼴, 요약 한 칸은 스탯, 비율 그림은 차트 고르기.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 코드와 규칙이 숫자의 계약서

Intl.NumberFormat이 말과 화폐를 함께 다룹니다.

// 표 안 — 자릿수를 끊고 단위를 붙인다
new Intl.NumberFormat('ko-KR', { style: 'currency', currency: 'KRW' })
  .format(1284000);          // '₩1,284,000'

// 요약 — 만 · 억으로 줄인다 (Intl 은 한국어 단위를 자동으로 주지 않는다)
function short(n) {
  if (n >= 1e8) return (n / 1e8).toFixed(1).replace(/\.0$/, '') + '억';
  if (n >= 1e4) return (n / 1e4).toFixed(0) + '만';
  return n.toLocaleString('ko-KR');
}

/* 표에서는 오른쪽 정렬 + 등폭 숫자 */
td.num { text-align: right; font-variant-numeric: tabular-nums; }
키일어나야 하는 일
Intl.NumberFormat쉼표·화폐·퍼센트를 말에 맞춰 적어 준다. 직접 쉼표를 찍지 않는다
notation: 'compact'영어는 1.2M, 한국어는 128만. 다만 단위 선택이 아쉬울 때가 있어 직접 쓰기도 한다
tabular-nums표에서 자릿수를 맞춘다 — 숫자 꼴
스크린 리더1,284,000은 '백이십팔만 사천'으로 읽힌다. 단위가 없으면 무엇인지 모른다
<bdi>말이 섞인 줄에서 숫자 방향이 뒤집히는 것을 막는다
입력칸에는 쉼표를 넣지 않는다type="text" + inputmode="numeric"으로 받고 보낼 때 숫자로 바꾼다

9 서버 쪽으로 치면백엔드 감각으로 번역

돈은 정수로원 단위는 소수점 없는 정수로 다룹니다. 부동소수점으로 두면 0.1 + 0.2 가 안 맞습니다.
반올림을 한곳에서화면과 서버가 따로 반올림하면 합계가 어긋납니다. 어디서 할지 정해 둡니다.
단위를 함께 보낸다{"amount":1284000,"currency":"KRW"}. 숫자만 오면 화면이 짐작해야 합니다.
집계값의 자릿수평균·비율은 몇 자리까지인지 정해 보냅니다. 안 정하면 화면마다 다르게 보입니다.
큰 수자바스크립트는 아주 큰 정수를 정확히 못 다룹니다. ID 는 문자열로 보냅니다.

10 플랫폼마다 다른 이름같은 부품, 다른 말

만·억으로 끊는 것은 한국어 화면에서만 할 일입니다.

웹Intl.NumberFormat
1,284,000원
말과 화폐를 함께 다룹니다. 만·억 줄임은 손을 좀 봐야 합니다.
iOSNumberFormatter
1,284,000원
지역 설정을 따라갑니다. 표에서는 등폭 숫자를 켜야 자릿수가 맞습니다.
안드로이드NumberFormat
1,284,000원
같은 방식입니다. CompactDecimalFormat이 '128만'을 만들어 줍니다.

자주 생기는 사고 — 시안에 ‘1.2M’이라고 적혀 있으면 영어 템플릿을 그대로 쓴 것입니다. 한국어 독자는 머릿속에서 한 번 더 바꿔야 해서 읽는 속도가 느려지고, 금액이 클수록 더합니다. ‘만·억으로 적습니다’를 한 줄 정해 두면 이 왕복이 사라집니다.
