글자 굵기

Font weight

글자의 두께. 크기보다 조용한 강조 수단이고, 줄 높이를 안 바꿔서 레이아웃이 흔들리지 않습니다.

2 이름부르는 말이 여러 개다

한국어글자 굵기, 굵기, 웨이트
영어font weight, weight, bold, regular
같이 쓰는 말100~900의 숫자를 웨이트라 하고, 이름으로는 Thin · Light · Regular · Medium · SemiBold · Bold · Black 순입니다. 파일이 없어 브라우저가 만들어 내는 굵기를 가짜 굵게(synthetic bold · faux bold), 한 파일로 모든 굵기를 내는 것을 가변 글꼴(variable font)이라 합니다.
자주 잘못 부름<b>와 <strong> — 굵기는 생김새이고 strong은 중요하다는 뜻입니다. 스크린 리더가 다르게 읽습니다.
볼드 — 보통 700을 가리키지만 글꼴에 따라 600이 '볼드'인 경우도 있습니다.
굵기와 크기 — 둘 다 강조 수단이지만 굵기는 줄 높이를 안 바꿉니다.

@font-face { font-weight: 400 } — 굵기마다 파일 한 벌
가짜 굵게(synthetic bold) — 파일이 없으면 흉내 낸다
가변 글꼴(variable) — 한 파일로 100~900
  1. 400 Regular font-weight: 400본문. 기본값이고 글의 대부분을 차지한다
  2. 500 Medium font-weight: 500살짝 강조. 줄 제목·라벨에 쓴다
  3. 700 Bold font-weight: 700제목·버튼. <b>와 <strong>의 기본값
  4. 파일 한 벌 @font-face굵기 하나가 파일 하나다. 늘리면 그만큼 더 받아야 한다
  5. 가짜 굵게 synthetic bold파일이 없으면 브라우저가 획을 부풀려 만든다 — 뭉개져 보인다
  6. 가변 글꼴 variable font한 파일로 100~900 전부. 요즘 한글 글꼴도 가변으로 나온다

한글은 가짜 굵게가 특히 나쁩니다. 획이 많아서 브라우저가 부풀리면 자음 안쪽의 빈 공간이 메워져 글자가 덩어리로 뭉개집니다. 영문은 어느 정도 봐줄 만하지만 한글은 바로 티가 나서, 쓸 굵기의 파일은 반드시 받아 와야 합니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 크기를 안 바꾸고 강조할 때 — 줄 높이가 안 흔들립니다
  • 표의 머리글, 줄 제목, 버튼 글자
  • 같은 크기 안에서 층을 하나 더 만들고 싶을 때

이럴 때는 안 쓴다

  • 굵기를 다섯 단 넘게 두는 것 — 파일만 늘고 구별은 안 됩니다
  • 본문 전체를 300(Light)으로 — 작은 글자에서 흐려 읽기 힘듭니다
  • <b>를 뜻 없이 쓰는 것 — 중요하면 <strong>입니다
  • 파일 없는 굵기를 시안에 적는 것 — 화면에서는 가짜 굵게가 됩니다

대신 이걸 — 크기로 층을 만들려면 타입 스케일, 셋을 함께 쓰려면 글자 위계, 파일 문제는 웹폰트.

8 최소 코드와 규칙이 글꼴의 계약서

굵기는 숫자로 적습니다. bold는 700의 다른 이름일 뿐이고, 중간 단을 못 가리킵니다.

/* 받아 올 굵기만 적는다 — 하나가 파일 하나다 */
@font-face {
  font-family: "Pretendard";
  font-weight: 400;
  src: url("pretendard-400.woff2") format("woff2");
}
@font-face { font-weight: 700; src: url("pretendard-700.woff2"); … }

/* 가변 글꼴이면 한 벌로 끝난다 */
@font-face {
  font-weight: 100 900;          /* 범위로 적는다 */
  src: url("pretendard-var.woff2") format("woff2-variations");
}

/* 흉내 내지 말라고 막을 수도 있다 */
body { font-synthesis: none; }

숫자로 적는다700이라고 쓴다. bold는 중간 단을 못 가리킨다
쓸 굵기만 받는다굵기 하나가 파일 하나. 한글은 한 벌이 수백 KB 다
가변 글꼴을 본다한 파일로 전부 되면 굵기를 늘려도 공짜가 된다
<strong>은 뜻굵게 보이려면 CSS 로. 중요하다는 뜻일 때만 strong
가짜 굵게를 확인한다파일 없는 굵기를 쓰면 한글이 뭉개진다. 눈으로 한 번 본다

9 서버 쪽으로 치면백엔드 감각으로 번역

굵기 = 파일 수굵기를 하나 늘리면 내려받을 파일이 한 벌 늘어납니다. 한글 한 벌이 수백 KB라 첫 화면 속도에 바로 영향이 옵니다.
가변 글꼴의 손익한 파일로 모든 굵기를 내지만 파일 자체는 더 큽니다. 굵기를 셋 이상 쓸 때부터 이득입니다.
시안과 현실디자인 도구에는 모든 굵기가 보입니다. 실제로 받아 오는 굵기 목록을 디자이너와 먼저 합의해 두면 '세미볼드가 안 나와요'가 없어집니다.
메일·PDF웹폰트를 못 쓰는 곳에서는 굵기 두 단(400·700)만 믿을 수 있습니다.
