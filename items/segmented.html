세그먼티드 컨트롤

Segmented control

세그먼티드 컨트롤은 선택지 두세 개를 가로로 붙여 놓고 그중 하나를 고르게 하는 띠입니다. 라디오 그룹을 다른 모양으로 그린 것이고, 보통 누르는 즉시 반영됩니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

같은 화면에 탭도 함께 두었습니다. 세그먼티드 컨트롤을 누르면 아래 목록이 걸러질 뿐 화면은 그대로입니다. 반면 탭을 누르면 내용 묶음 자체가 바뀝니다. 이 예에서 거래와 정산은 아예 다른 화면입니다. 두 부품은 생김새가 닮아서 특히 자주 섞어 씁니다.

2 이름같은 것을 부르는 여러 이름

한국어세그먼티드 컨트롤, 분할 컨트롤, 토글 그룹
영어segmented control, segmented button, toggle group
같이 쓰는 말칸 하나는 세그먼트, 바깥의 알약 모양은 트랙이라고 부릅니다. 안드로이드에서는 이 부품을 세그먼티드 버튼이라고 부릅니다.
자주 잘못 부르는 이름탭 — 특히 자주 혼동합니다. 탭은 화면을 바꾸고, 세그먼티드 컨트롤은 값을 고릅니다.
버튼 그룹 — 버튼 그룹은 칸마다 동작을 실행하기 때문에 고른 상태가 남지 않습니다.
필터 — 필터는 이 부품을 쓰는 목적을 가리키는 말이고, 부품 이름은 아닙니다.

역할로 보면 세그먼티드 컨트롤은 라디오 그룹입니다(role="radiogroup"). 생김새만 가로로 붙어 있을 뿐이어서 키보드 규칙도 라디오와 같습니다. Tab 한 번으로 묶음에 들어가고 화살표로 칸을 옮깁니다.

6 쓸 때 / 안 쓸 때

세그먼티드 컨트롤을 쓰는 경우

  • 선택지가 2~4개이고 늘 다 보여야 할 때
  • 전체 / 카드 / 계좌처럼 같은 목록을 거르는 조건일 때
  • 목록 / 격자처럼 누르는 즉시 반영되는 보기 전환일 때

세그먼티드 컨트롤을 쓰지 않는 경우

  • 선택지가 다섯 개를 넘을 때. 글자가 잘리므로 셀렉트로 바꿉니다
  • 화면 자체가 바뀔 때. 이때는 탭을 씁니다
  • 칸마다 동작을 실행할 때. 이때는 버튼 그룹을 씁니다
  • 선택지 글자가 길 때. 가로로 붙이면 글자가 모두 잘립니다

세그먼티드 컨트롤 대신 다른 것을 써야 하는 경우 — 화면이 바뀌면 탭(7부), 선택지가 많으면 셀렉트, 설명이 길면 라디오, 켜고 끄기면 스위치.

8 최소 마크업과 키보드구현할 때 지킬 최소 규칙

세그먼티드 컨트롤의 역할은 라디오 그룹입니다. 그래서 role="radiogroup"과 aria-checked를 붙이고, 화살표 조작도 라디오와 같은 규칙으로 맞춥니다.

<div role="radiogroup" aria-label="결제 수단">
  <button role="radio" aria-checked="true">전체</button>
  <button role="radio" aria-checked="false">카드</button>
</div>

// 화살표로 옮긴다. 라디오 그룹과 같은 규칙
if (e.key === 'ArrowRight') next().click();

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

세그먼티드 = 질의 조건고른 값은 보통 목록을 불러오는 질의의 필터로 쓰입니다. 이 값을 주소(URL)에 담아 두면 뒤로가기와 링크 공유가 따로 만들지 않아도 동작합니다.
탭과 다른 점탭은 보통 서로 다른 리소스를 불러오고, 세그먼티드 컨트롤은 같은 리소스에 조건만 바꿔 불러옵니다. 그래서 캐시 전략도 달라집니다.
0건인 칸칸마다 결과 개수를 미리 받아 적어 주면(전체 12 · 카드 9 · 계좌 3), 사용자가 결과가 없는 칸을 눌러 보는 일이 줄어듭니다. 개수를 받는 질의가 하나 더 필요하지만 쓰기에는 훨씬 편해집니다.
기본값세그먼티드 컨트롤은 늘 하나가 골라져 있습니다. 이 기본값이 첫 화면에서 보내는 질의를 정하므로, 가장 많이 쓰는 값을 기본값으로 둡니다.

플랫폼 차이 때문에 자주 생기는 문제 — 안드로이드의 세그먼티드 버튼은 여럿 고르기(multi-select)도 표준으로 지원합니다. 여럿을 고르게 하면 역할이 라디오가 아니라 체크박스가 되고 키보드 규칙도 달라집니다. 그래서 "세그먼티드로 해 주세요"라는 요청을 받으면 하나만 고르는지, 여럿을 고르는지부터 물어야 합니다.
