세그먼티드 컨트롤

Segmented control

선택지 둘셋을 가로로 붙여 놓고 하나를 고르는 띠. 라디오 그룹의 다른 모양이고, 보통 누르는 즉시 반영됩니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

같은 화면에 탭도 같이 뒀습니다. 세그먼티드를 누르면 아래 목록이 걸러질 뿐 화면은 그대로입니다. 탭을 누르면 내용 묶음 자체가 바뀝니다 — 거래와 정산은 아예 다른 화면입니다. 생김새가 닮아서 가장 자주 섞이는 둘입니다.

2 이름부르는 말이 여러 개다

한국어세그먼티드 컨트롤, 분할 컨트롤, 토글 그룹
영어segmented control, segmented button, toggle group
같이 쓰는 말칸 하나를 세그먼트, 바깥 알약을 트랙이라 합니다. 안드로이드는 세그먼티드 버튼이라 부릅니다.
자주 잘못 부름탭 — 가장 잦습니다. 탭은 화면을 바꾸고 세그먼티드는 값을 고릅니다.
버튼 그룹 — 버튼 그룹은 각 칸이 동작이라 고른 상태가 남지 않습니다.
필터 — 쓰임이지 부품 이름이 아닙니다.

3 가르는 기준형제들과 비교하는 네 축

조작 부품은 모두 '값을 받는다'는 점이 같습니다. 이 네 가지만 물어보면 갈립니다.

고르는 개수선택지가 보이나바로 적용되나타이핑
텍스트 필드자유 입력해당 없음저장 눌러야된다
셀렉트하나펼쳐야 보인다저장 눌러야안 된다
콤보박스하나펼치고 걸러진다저장 눌러야된다
체크박스여럿다 보인다저장 눌러야안 된다
라디오 그룹하나다 보인다저장 눌러야안 된다
스위치켬 · 끔해당 없음바로안 된다
세그먼티드 컨트롤하나다 보인다보통 바로안 된다
슬라이더범위에서 하나범위가 보인다보통 바로안 된다

한 줄로 — 세그먼티드는 값을 고르는 것이고 탭은 화면을 바꾸는 것입니다. 누른 뒤 같은 화면에 머물면 세그먼티드입니다.

4 상태그림 한 장으로는 못 배운다

5 해부도부분 이름이 제일 안 알려진 지식

전체 카드 계좌
아래 목록이 걸러집니다 — 화면은 그대로
  1. 트랙 track바깥 알약. 칸들이 하나의 묶음이라는 표시다
  2. 고른 칸 selected segment떠 보이게 한다. 색만으로는 약해서 그림자나 배경을 같이 쓴다
  3. 안 고른 칸 segment읽히되 눌러도 된다는 느낌이 있어야 한다
  4. 칸 글자 label짧게. 길면 잘리고, 잘리면 고를 수가 없다
  5. 영향받는 영역 controlled region같은 화면 안이다. 화면이 바뀌면 그건 탭이다

역할로는 라디오 그룹입니다(role="radiogroup"). 생김새만 가로로 붙어 있을 뿐이라, 키보드 규칙도 라디오와 같습니다 — Tab 한 번으로 들어가고 화살표로 옮깁니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 선택지가 2~4개이고 늘 다 보여야 할 때
  • 같은 목록을 거르는 조건일 때 — 전체 / 카드 / 계좌
  • 누르는 즉시 반영되는 보기 전환 — 목록 / 격자

이럴 때는 안 쓴다

  • 다섯 개를 넘을 때 — 글자가 잘립니다. 셀렉트로 바꿉니다
  • 화면 자체가 바뀔 때 → 탭입니다
  • 각 칸이 동작일 때 → 버튼 그룹입니다
  • 글자가 긴 선택지 — 가로로 붙이면 다 잘립니다

대신 이걸 — 화면이 바뀌면 탭(7부), 선택지가 많으면 셀렉트, 설명이 길면 라디오, 켜고 끄기면 스위치.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

역할은 라디오 그룹입니다. role="radiogroup"과 aria-checked를 붙이면 화살표 조작까지 라디오와 같은 규칙으로 맞출 수 있습니다.

<div role="radiogroup" aria-label="결제 수단">
  <button role="radio" aria-checked="true">전체</button>
  <button role="radio" aria-checked="false">카드</button>
</div>

// 화살표로 옮긴다 — 라디오 그룹과 같은 규칙
if (e.key === 'ArrowRight') next().click();

// 탭이라면 role 이 전혀 다르다. 섞어 쓰지 않는다
// role="tablist" / role="tab" / role="tabpanel"
키일어나야 하는 일
Tab묶음 전체를 한 번에 지난다
←→칸을 옮기고 옮기는 즉시 반영된다
Space짚은 칸을 고른다
스크린 리더radiogroup이면 '3개 중 1번째'로 읽힌다. 탭이면 전혀 다르게 읽히니 역할을 섞지 않는다
손가락칸 하나가 44px 이상이어야 한다. 셋을 넘기면 좁은 화면에서 먼저 무너진다

9 서버 쪽으로 치면백엔드 감각으로 번역

세그먼티드 = 질의 조건고른 값은 보통 목록 질의의 필터입니다. 주소(URL)에 담아 두면 뒤로가기와 공유가 공짜로 됩니다.
탭과 다른 점탭은 보통 다른 리소스를 부릅니다. 세그먼티드는 같은 리소스에 조건만 바뀝니다 — 캐시 전략이 달라집니다.
0건인 칸미리 개수를 받아 칸에 적어 주면(전체 12 · 카드 9 · 계좌 3) 헛걸음이 줄어듭니다. 질의가 하나 더 필요한 대신 체감이 크게 좋아집니다.
기본값늘 하나는 골라져 있습니다. 그 기본값이 첫 화면의 질의를 정하므로 가장 흔한 것을 둡니다.
