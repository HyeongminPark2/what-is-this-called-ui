그리드

CSS Grid · grid layout

그리드는 판을 먼저 칸으로 나누고 그 칸에 자식을 넣는 방법입니다. 플렉스가 자식을 한 줄로 늘어놓는 방법이라면, 그리드는 가로와 세로로 칸을 나누는 방법입니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

짜는 법을 칸이 알아서 접히기로 두고 위의 폭 토글로 화면 폭을 바꿔 보세요. auto-fit과 minmax를 함께 쓰면 미디어 쿼리 없이도 폭에 맞춰 열 수가 줄어들기 때문에, 요즘 카드 그리드는 대부분 이 방식으로 만듭니다.
긴 글 넣기를 켜면 너비가 고르던 칸들이 어긋납니다. 1fr은 사실 minmax(auto, 1fr)이라서 긴 글이 든 칸이 글보다 좁아지지 못하기 때문입니다. minmax(0, 1fr)로 고쳐야 그 칸도 다른 칸과 같은 너비로 줄어듭니다.

2 이름같은 것을 부르는 여러 이름

한국어그리드, 격자, 레이아웃 그리드
영어CSS Grid, grid layout, track, gutter
같이 쓰는 말열과 행 하나하나는 트랙(track), 칸 사이의 빈 줄은 거터(gutter · gap)라고 부릅니다. fr은 남은 자리의 몫(fraction)을 나타내는 단위이고, auto-fit/auto-fill은 열 수를 브라우저가 정하게 하는 키워드입니다. 칸마다 이름을 붙여 짠 배치는 그리드 템플릿 영역이라고 합니다.
자주 잘못 부르는 이름간격 그리드 — 여백 단위로 쓰는 8px 격자와는 다른 것입니다. CSS 그리드는 열을 나누는 배치 방법입니다.
테이블 — 표는 데이터를 담는 것이고 그리드는 배치를 정하는 것입니다. 배치에 표를 쓰면 스크린 리더가 그 영역을 '표'라고 읽습니다.
플렉스 — 플렉스는 한 방향, 그리드는 두 방향으로 배치합니다. 위아래 줄의 칸이 서로 맞아야 하면 그리드를 씁니다.

그리드를 한 줄로 정리하면 — 그리드는 판을 먼저 정해 두는 방법입니다. 자식이 몇 개가 들어와도 판은 그대로이기 때문에 줄과 열이 서로 맞습니다.

4 짜는 법같은 자식, 다른 판

5 해부도부분마다 붙은 이름

1 2 3
grid-template-columns: 1fr 1fr 1fr
gap: 8px (거터)
repeat(auto-fit, minmax(150px, 1fr))
minmax(0, 1fr) — 1fr 의 함정을 푸는 값
grid-column: span 2 (한 칸이 두 칸을 먹기)
  1. 그리드 컨테이너 grid containerdisplay: grid를 준 부모입니다. 자식은 마크업 순서대로 칸에 들어갑니다
  2. 트랙 track · template열(과 행)의 크기를 정의합니다. 1fr은 남은 자리를 한 몫 나눠 받습니다
  3. 거터 gap · gutter칸 사이의 빈 줄입니다. column-gap·row-gap으로 따로 줄 수 있습니다
  4. 알아서 접기 auto-fit + minmax칸이 최소 150px보다 좁아지면 열 수를 줄이라는 뜻입니다. 미디어 쿼리 없이 화면 폭에 맞춰집니다
  5. minmax(0, 1fr) minmax1fr에 숨은 최소값(auto)을 0으로 바꿔서 칸이 글보다 좁아질 수 있게 합니다
  6. 칸 합치기 grid-column: span자식 하나가 여러 칸을 차지합니다. 플렉스로는 할 수 없는 일입니다

1fr은 남은 자리를 한 몫 나눠 받는다는 뜻이지만, 실제로는 minmax(auto, 1fr)로 계산되고 auto는 '내용만큼'을 뜻합니다. 그래서 긴 글이 든 칸은 내용보다 좁아지지 않고 옆 칸의 자리를 빼앗습니다. 글이 더 길면 판 전체가 부모보다 넓어져 가로 스크롤이 생깁니다. minmax(0, 1fr)로 적으면 숨은 최소값이 0으로 바뀌어 이 문제가 사라집니다.

6 쓸 때 / 안 쓸 때

그리드를 쓰는 경우

  • 카드 그리드나 표 같은 배치처럼 줄과 열이 서로 맞아야 할 때
  • 사이드바, 본문, 꼬리말로 화면 전체를 짤 때
  • 미디어 쿼리 없이 열 수가 줄어들게 하고 싶을 때. auto-fit minmax를 씁니다
  • 자식 하나가 여러 칸을 차지해야 할 때

그리드를 쓰지 않는 경우

  • 한 줄에 늘어놓기만 하면 될 때. 플렉스로 적는 편이 짧습니다
  • 데이터 표를 만들 때. 그리드로 만들면 스크린 리더가 행과 열을 읽지 못하니 <table>을 씁니다
  • 자식 개수가 매번 달라서 열 수를 못 박은 판이 무너질 때. auto-fit으로 바꿉니다

그리드 대신 다른 것을 써야 하는 경우 — 한 방향이면 플렉스, 데이터면 데이터 테이블(10부), 가운데만 놓으면 가운데 맞추기.

7 자주 보는 모습구조만 따라 그린 재현 그림

8 최소 코드와 규칙그리드를 쓸 때 지킬 것

외워 둘 것은 카드 그리드 한 줄과 화면 짜임 한 줄, 이렇게 두 줄입니다.

/* 카드 그리드. 미디어 쿼리 없이 열 수가 줄어든다 */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}

/* 사이드바와 본문으로 짠 화면 */
.app {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
}                       /* ↑ 0이어야 긴 글이 들어와도 본문이 넘치지 않는다 */

/* 자식 하나가 두 칸을 차지하게 하기 */
.cards > .featured { grid-column: span 2; }
규칙지켜야 하는 것
minmax(0, 1fr)본문처럼 긴 글이 들어올 칸에는 거의 항상 필요합니다
auto-fit vs auto-fillauto-fit은 빈 트랙을 접고 auto-fill은 빈 칸을 남깁니다. 보통은 auto-fit을 씁니다
gap만 쓴다자식에 마진을 줘서 간격을 만들면 판의 가장자리에도 여백이 생깁니다
auto 트랙auto 1fr auto는 앞뒤 칸을 내용만큼, 가운데 칸만 유동 폭으로 둡니다. 리스트 한 줄을 짤 때 흔히 씁니다
배치에 <table>을 쓰지 않는다배치에 표를 쓰면 스크린 리더가 '표, 3열 5행'이라고 읽습니다
자식 순서 = 읽는 순서grid-area로 눈에 보이는 자리를 바꿔도 키보드 순서는 바뀌지 않습니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

그리드 = 판이 먼저자식이 몇 개 오든 판은 그대로이기 때문에, 응답 개수가 들쭉날쭉해도 레이아웃이 무너지지 않습니다. 이 점이 플렉스와 가장 크게 다릅니다.
빈 칸 처리마지막 줄이 덜 찼을 때 어떻게 보일지 정해 둬야 합니다. auto-fit이면 남은 칸이 늘어나고, auto-fill이면 빈 자리가 남습니다.
페이지 크기한 번에 12개를 주면 3열·4열·6열 어디서도 줄이 딱 맞습니다. 12의 약수로 페이지 크기를 잡는 관례가 여기서 나왔습니다.
이미지 비율칸 너비가 바뀌어도 카드 높이가 들쭉날쭉하지 않게 하려면 이미지에 aspect-ratio를 정해 둬야 합니다. 서버가 원본 비율을 함께 내려 주면 더 정확하게 맞출 수 있습니다.
