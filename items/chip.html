칩

Chip · tag · pill

한 낱말짜리 작은 덩어리. 생김새는 하나인데 셋이 서로 다른 일을 해서 가장 많이 헷갈립니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

위는 필터 칩(눌러서 거른다), 가운데는 입력 칩(내가 넣은 값이라 뗄 수 있다), 아래는 표시 칩(그냥 라벨이라 안 눌린다)입니다.
칩을 ×로 지워 보세요. 포커스가 사라지지 않고 다음 칩으로 넘어갑니다 — 지운 자리에 포커스를 두면 키보드 사용자는 화면 맨 위로 튕깁니다. 삭제 칩의 1번 사고입니다.

2 이름부르는 말이 여러 개다

한국어칩, 태그, 필터 칩, 알약
영어chip, tag, pill, token, filter chip
같이 쓰는 말Material 은 네 갈래로 나눕니다 — 어시스트(assist) · 필터(filter) · 인풋(input) · 서제스천(suggestion). 입력칸 안에 들어간 칩은 토큰(token)이라고도 하고, 떼는 ×는 딜리트 아이콘입니다.
자주 잘못 부름배지 — 가장 잦은 혼동입니다. 배지는 붙어서 알리기만 하고 칩은 눌리거나 떼어집니다.
버튼 — 칩도 눌리지만 값을 켜고 끄는 것이지 동작을 일으키지 않습니다.
세그먼티드 컨트롤 — 세그먼티드는 하나만 고르고 칸이 붙어 있습니다. 필터 칩은 여럿 고를 수 있습니다.

3 가르는 기준형제들과 비교하는 네 축

표시 부품은 '보여 주기만 한다'는 점이 같습니다. 이 네 가지만 물어보면 갈립니다.

무엇을 담나전체가 눌리나어떻게 모이나내용이 길어지면
카드한 덩어리보통 눌린다그리드로높이가 늘어난다
리스트 아이템한 건보통 눌린다세로 목록으로말줄임한다
아바타사람·조직 하나안 눌린다겹쳐 쌓는다고정 — 넘치면 +N
배지숫자나 한 낱말안 눌린다혼자 안 선다 — 붙는다고정 — 넘치면 99+
칩한 낱말눌린다가로로 줄바꿈말줄임하거나 줄을 넘긴다
스탯 타일숫자 하나가끔 눌린다가로 한 줄로단위를 줄인다(1.2만)
타임라인사건들의 순서항목만세로로 꿴다아래로 길어진다
별점점수 하나읽기용은 안 눌린다줄 안에 들어간다고정 — 별 다섯

한 줄로 — 칩은 눌리거나 떼어집니다. 둘 다 아니면 그건 배지이거나 그냥 글자입니다.

4 갈래같은 모양이 세 가지 일을 한다

5 해부도부분 이름이 제일 안 알려진 지식

검토 중 ×
켜진 칩은 바탕과 테두리가 함께 바뀐다 — 색만 바꾸면 못 알아본다
전체검토 중승인됨거절됨
  1. 칩 chip알약 모양 한 덩어리. 높이가 32px 안팎이라 버튼보다 작다
  2. 라벨 label한 낱말. 길어지면 칩이 늘어나니 글자 수 상한을 정해 둔다
  3. 지우기 delete icon입력 칩에만 붙는다. 칩 본체와 다른 누를 것이라 따로 이름이 필요하다
  4. 켜짐 표시 selected바탕·테두리·글자색이 함께 바뀐다. 체크 아이콘을 넣기도 한다
  5. 무리 chip group칩들이 모인 줄. role="group"으로 묶고 이름을 붙인다

입력 칩은 누를 것이 둘입니다 — 칩 본체와 ×. 그래서 키보드로는 칩마다 두 번 멈추고, 스크린 리더에는 '홍길동', '홍길동 빼기'로 두 번 읽힙니다. ×의 이름을 그냥 '삭제'로 두면 칩이 열 개일 때 '삭제'가 열 번 읽혀 무엇을 지우는지 알 수 없습니다.

6 쓸 때 / 안 쓸 때

이럴 때 쓴다

  • 목록을 빠르게 거를 때 — 상태·기간·분류
  • 내가 넣은 값을 여러 개 쌓아 보여 줄 때 — 받는 사람, 태그
  • 고를 것이 미리 정해져 있고 개수가 적을 때

이럴 때는 안 쓴다

  • 동작을 일으킬 때 → 버튼입니다. 칩은 값을 다룹니다
  • 선택지가 열 개를 넘을 때 → 콤보박스나 필터 패널
  • 하나만 골라야 하고 선택지가 2~4개일 때 → 세그먼티드 컨트롤
  • 누를 수 없는 칩에 테두리와 호버를 주는 것 — 눌러 보게 됩니다

대신 이걸 — 붙어서 알리기만 하면 배지, 하나만 고르면 세그먼티드, 많으면 콤보박스.

7 자주 보는 모습구조만 흉내 낸 재현 그림

8 최소 마크업과 키보드이 부품의 계약서

필터 칩은 켜고 끄는 버튼이라 aria-pressed를 씁니다. 입력 칩의 ×는 무엇을 지우는지까지 이름에 적습니다.

<!-- 필터 칩: 켜고 끄는 버튼 -->
<div role="group" aria-label="상태로 거르기">
  <button class="chip" aria-pressed="true">검토 중</button>
  <button class="chip" aria-pressed="false">승인됨</button>
</div>

<!-- 입력 칩: 본체와 × 가 각각 누를 것 -->
<span class="chip">홍길동
  <button aria-label="홍길동 빼기">×</button>
</span>

// 지운 뒤 포커스를 옮긴다 — 안 옮기면 화면 맨 위로 튕긴다
chips.splice(i, 1); render();
(next ?? input).focus();
키일어나야 하는 일
Tab칩마다 한 번. 입력 칩은 두 번(본체 + ×)
Enter · Space필터 칩을 켜고 끈다
Backspace입력칸이 비어 있을 때 누르면 마지막 칩을 뺀다 — 메일 앱의 관례
지운 뒤 포커스다음 칩, 없으면 입력칸으로. 지운 자리에 두면 포커스가 사라진다
× 의 이름aria-label="홍길동 빼기" — 그냥 '삭제'면 열 개가 다 같은 말이 된다
무리에 이름role="group" + aria-label로 '무엇으로 거르는 칩인지' 알린다

9 서버 쪽으로 치면백엔드 감각으로 번역

필터 칩 = 질의 조건켜진 칩이 곧 WHERE 조건입니다. 여럿 켜질 수 있으니 AND 인지 OR 인지를 먼저 정해야 합니다 — 같은 갈래끼리는 보통 OR, 갈래가 다르면 AND 입니다.
주소에 담기?status=wait,ok&period=week처럼 담아 두면 공유와 뒤로가기가 됩니다. 안 담으면 새로고침 때 필터가 날아갑니다.
개수 보여 주기칩에 '검토 중 7' 처럼 수를 붙이려면 거르기 전 전체에서 세야 합니다. 거른 결과에서 세면 늘 자기 수만 나옵니다.
입력 칩의 값화면에 보이는 것은 이름이지만 서버로 가는 것은 ID 입니다. 칩마다 ID 를 함께 들고 있어야 동명이인이 섞이지 않습니다.
