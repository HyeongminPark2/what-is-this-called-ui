아바타

Avatar · profile picture

아바타는 사람이나 조직 하나를 가리키는 작은 그림입니다. 화면을 꾸미려고 두는 것이 아니라, 이 내용이 누구의 것인지 알려 주려고 둡니다.

1 실물 — 직접 만져 보기

새 탭에서 열기 ↗

사진이 깨진 상태로 보기를 켜 보세요. 사진이 사라지면 깨진 그림 아이콘 대신 밑에 깔아 둔 이니셜이 드러납니다. 아바타의 기본값은 사진이 아니라 이니셜이고, 사진은 그 위에 덮어 두는 것이기 때문입니다.
사람 수를 늘려 보면 그림은 셋까지만 늘어나고 나머지는 +N으로 표시됩니다. 이때 화면 아래의 '읽히는 말'도 함께 바뀌는 것을 확인해 보세요.

2 이름같은 것을 부르는 여러 이름

한국어아바타, 프로필 사진, 프사
영어avatar, profile picture, user image, gravatar
같이 쓰는 말사진이 없을 때 보이는 글자는 이니셜(initials · monogram), 이니셜을 그린 바닥은 폴백(fallback)이라고 부릅니다. 여러 아바타를 겹쳐 놓은 것은 아바타 그룹(avatar group · stack · facepile), 모서리에 붙는 작은 점은 프레즌스(presence · status dot)라고 합니다.
자주 잘못 부르는 이름아이콘 — 아이콘은 기능을 가리키고 아바타는 사람을 가리킵니다. 둘은 생김새가 아니라 가리키는 대상으로 갈립니다.
썸네일 — 썸네일은 사진이나 영상 같은 내용을 줄여 보여 주는 그림이고, 아바타는 그 내용을 만든 사람처럼 주체를 가리킵니다.
배지 — 아바타 모서리에 붙는 작은 점은 배지가 아니라 상태 점이라고 따로 부릅니다.

3 가르는 기준헷갈리는 형제 부품과 견주는 네 가지 기준

표시 부품은 모두 무언가를 보여 주기만 한다는 점이 같아서, 아래 네 가지를 물어봐야 서로 구별됩니다.

무엇을 담는가부품 전체를 누를 수 있는가여러 개가 어떻게 모이는가내용이 길어지면 어떻게 하는가
카드한 덩어리보통 눌린다그리드로 늘어선다높이가 늘어난다
리스트 아이템한 건보통 눌린다세로 목록으로 쌓인다말줄임한다
아바타사람·조직 하나눌리지 않는다겹쳐 쌓는다크기는 고정하고 넘치면 +N으로 줄인다
배지숫자나 한 낱말눌리지 않는다혼자 놓이지 않고 다른 요소에 붙는다크기는 고정하고 넘치면 99+로 줄인다
칩한 낱말눌린다가로로 늘어서다 줄을 바꾼다말줄임하거나 줄을 넘긴다
스탯 타일숫자 하나가끔 눌린다가로 한 줄로 늘어선다단위를 줄인다(1.2만)
타임라인사건들의 순서항목만 눌린다세로 선으로 잇는다아래로 길어진다
별점점수 하나읽기용은 눌리지 않는다줄 안에 들어간다별 다섯 개로 고정된다
아이콘뜻 하나혼자서는 눌리지 않는다글자 옆에 붙는다아이콘은 그대로 두고 옆 글자가 길어진다
썸네일그림 하나보통 눌린다격자로 늘어선다칸은 고정하고 사진을 자르거나 여백을 남긴다
테이블 행한 건의 여러 값행 전체나 주 열만 눌린다세로로 쌓인다말줄임한다
키-값 목록이름과 값의 짝눌리지 않는다세로로 쌓인다값이 먼저 잘린다
미디어 오브젝트그림과 글보통 눌린다세로 목록으로 쌓인다글 쪽만 늘어난다
접히는 글제목과 본문제목이 눌린다세로로 쌓는다접어 둔다
태그한 낱말눌리지 않는다가로로 늘어서다 줄을 바꾼다말줄임하거나 +N으로 접는다

아바타를 한 줄로 정리하면 — 아바타는 누구인지를 작은 그림 하나로 보여 주는 것입니다. 사진이 없어도 누구인지 알려 줄 수 있어야 하기 때문에, 아바타의 기본값은 사진이 아니라 이니셜입니다.

철수 모서리에 붙는 상태 점
길동 철수 +6 겹쳐 쌓고 나머지는 +N으로 줄임
  1. 이니셜 바닥 fallback · initials아바타의 기본값입니다. 사진을 불러오지 못하면 이니셜 바닥이 그대로 보입니다
  2. 사진 image이니셜 바닥 위에 덮습니다. 사진이 깨지면 onerror로 사진을 숨겨 바닥을 드러냅니다
  3. 모양 shape원은 사람, 둥근 모서리 사각형은 조직이나 상품에 씁니다. 섞어 쓰면 모양으로 종류를 구별할 수 없게 됩니다
  4. 상태 점 presence dot아바타 모서리에 붙습니다. 바탕색 테두리를 둘러야 점이 아바타 그림과 섞여 보이지 않습니다
  5. 겹침과 +N avatar group셋쯤까지만 보여 주고 나머지는 숫자로 줄입니다. 위에 겹치는 쪽이 앞 순서가 되게 쌓습니다

이니셜을 만드는 규칙은 생각보다 까다롭습니다. 한국 이름 '홍길동'은 성을 뺀 두 글자를 쓰는 것이 자연스럽고, 영문 'Hong Gildong'은 머리글자 두 개(HG)를 씁니다. 그런데 이름이 한 글자이거나 이모지이거나 비어 있을 수도 있으므로, 이름이 비어 있을 때 무엇을 보여 줄지를 반드시 정해 두어야 합니다. 정해 두지 않으면 운영 중에 아무것도 없는 빈 동그라미가 나옵니다.

6 쓸 때 / 안 쓸 때

아바타를 쓰는 경우

  • 댓글, 대화, 활동 기록처럼 누가 했는지가 중요할 때
  • 같은 이름이 여럿일 수 있을 때. 얼굴 사진이 있으면 이름보다 빨리 구별됩니다
  • 여럿이 함께 있는 것을 보여 줄 때(겹쳐 쌓기)

아바타를 쓰지 않는 경우

  • 이름이 바로 옆에 있는데 아바타까지 크게 둘 때. 같은 정보를 두 번 보여 주느라 자리만 차지합니다
  • 사진을 꾸밈용으로 넣을 때. 아바타는 주체를 가리키는 표시입니다
  • 목록의 모든 줄에 큰 아바타를 넣을 때. 사진을 많이 받느라 목록이 느려지고 글이 옆으로 밀립니다
  • 접속 상태를 색 점 하나로만 알릴 때

아바타 대신 다른 것을 써야 하는 경우 — 사람이 아니라 기능을 가리킨다면 아이콘(5부)을 쓰고, 사진이나 영상 같은 내용을 줄여 보여 주려면 썸네일을 씁니다. 숫자를 알리는 것이 목적이라면 배지가 맞습니다.

8 최소 마크업과 규칙구현할 때 지킬 최소 규칙

이니셜을 먼저 깔고 사진을 그 위에 덮는 순서가 중요합니다. 순서를 반대로 하면 사진이 깨졌을 때 아무것도 남지 않습니다.

<span class="av" aria-hidden="true">길동
  <img src="/u/12.jpg" alt=""
       onerror="this.remove()">   <!-- 사진이 깨지면 이니셜이 드러난다 -->
</span>
<span>홍길동</span>

/* 사진은 이니셜 바닥 위에 덮는다 */
.av     { position: relative; overflow: hidden; border-radius: 50%; }
.av img { position: absolute; inset: 0; width: 100%; height: 100%;
           object-fit: cover; }

<!-- 겹친 아바타 무리는 한 번에 읽힌다 -->
<span role="img" aria-label="참여자 9명: 홍길동, 김철수, …">…</span>
지킬 규칙지키는 방법
이니셜을 먼저 깔기사진은 이니셜 위에 덮어 둡니다. 순서를 바꾸면 사진이 깨졌을 때 빈 동그라미만 남습니다
object-fit: cover세로 사진이든 가로 사진이든 동그라미를 꽉 채웁니다. 쓰지 않으면 사진이 찌그러집니다
이름이 옆에 있으면 아바타를 숨기기aria-hidden="true"을 붙입니다. 그러지 않으면 스크린 리더가 같은 이름을 두 번 읽습니다
겹친 무리를 한 번에 읽히기role="img" + aria-label로 묶어 무리 전체가 한 번만 읽히게 합니다
상태 점을 말로도 알리기초록 점에 title을 달거나 화면에 보이지 않는 글로 '접속 중'이라고 적습니다
누를 수 있으면 <button>으로 만들기프로필로 이동하는 아바타는 실제 버튼이나 링크로 만들어야 키보드로 누를 수 있습니다

9 서버 쪽으로 치면백엔드 개념과 짝지어 보기

사진이 없는 경우를 기본으로 보기가입할 때 사진이 필수가 아니면 대부분의 사용자에게 사진이 없습니다. 그래서 이니셜 바닥을 기본 화면으로 보고, 사진은 있으면 더 좋은 것으로 다룹니다.
이니셜과 색은 화면 쪽에서 정하기이름에서 이니셜을 따는 규칙과 바탕색은 화면 쪽에서 정합니다. 다만 같은 사람에게는 늘 같은 색이 나오도록 이름을 해시한 값으로 색을 고릅니다.
사진을 크기별로 줄여 두기목록의 28px 자리에 2,000px짜리 원본을 보내면 받는 데 오래 걸려 화면이 느려집니다. 그래서 업로드할 때 몇 가지 크기로 미리 줄여 두고, 화면에서 자리에 맞는 크기를 골라 씁니다.
사진을 바꿨는데 예전 사진이 보일 때사진을 바꿔도 주소가 같으면 캐시된 예전 사진이 보입니다. 그래서 파일 이름에 버전이나 해시를 넣어 사진이 바뀔 때 주소도 바뀌게 합니다.
탈퇴한 사용자의 아바타탈퇴한 사람의 아바타는 익명 바닥으로 바꿔야 합니다. 이니셜이나 이름이 그대로 남아 있으면 그 사람의 정보를 다 지운 것이 아니기 때문입니다.

플랫폼 차이 때문에 자주 생기는 문제 — 웹, iOS, 안드로이드 개발자가 이니셜 규칙을 각자 정하는 일이 많습니다. 그러면 웹은 '길동', 안드로이드는 'ㅎ', iOS는 'HG'처럼 제품마다 달라져서, 같은 사람이 플랫폼마다 다르게 보이게 됩니다. 이니셜을 만드는 규칙 한 줄을 미리 합의해 두면 이런 차이가 생기지 않습니다.
