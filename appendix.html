ㄱ

  • 가상 스크롤Virtual scrolling 10부 데이터 다루는 화면 수만 줄짜리 목록에서 보이는 줄만 그리는 가상 스크롤을 받침대 높이, 창 계산, 고정 줄 높이라는 제약과 대안까지 다루는 항목입니다.
  • 가운데 맞추기Centering 1부 뼈대 가운데에 놓는 다섯 가지 방법과 방법마다 맞출 수 있는 범위의 차이를 실물과 해부도로 보여 주는 항목입니다.
  • 간격 체계Spacing scale · spacing system 2부 꾸미는 규칙 여백을 4px이나 8px의 배수로 정해 두는 간격 체계와, 가까운 것끼리 한 묶음으로 보이는 근접성 규칙을 보여 주는 항목입니다.
  • 검색Search 10부 데이터 다루는 화면 검색 입력칸과 결과 화면을 디바운스, 늦게 온 응답 버리기, 일치 글자 강조, 빈 결과 문구까지 다루는 항목입니다.
  • 검색 결과 화면Search results page 13부 화면 단위 패턴 찾은 것 가운데 하나를 고르는 화면입니다. 질의를 다시 보여 주는 법, 상태를 주소에 담는 법, 돌아왔을 때 되살리는 법을 다룹니다.
  • 결제 흐름Checkout 13부 화면 단위 패턴 돈을 내기까지 거치는 여러 단계입니다. 비용을 처음부터 보여 주는 법, 이전 단계로 돌아가도 값을 남기는 법, 결제 버튼이 두 번 눌리는 일을 막는 법을 다룹니다.
  • 고도Elevation · shadow scale 2부 꾸미는 규칙 그림자를 단으로 정해 화면 요소의 높이를 알아볼 수 있게 하는 방법과, 그림자 하나를 이루는 숫자 네 개를 보여 주는 항목입니다.
  • 공유 요소 전환Shared element transition 9부 움직임 두 화면에 있는 같은 요소를 이어서 움직이는 전환입니다. 두 화면의 관계를 눈으로 보여 주지만 구현 비용이 크다는 점을 다루는 항목입니다.
  • 공유하기Share · permissions 13부 화면 단위 패턴 남에게 보여 주는 범위를 정하는 화면입니다. 범위의 기본값, 권한, 이미 나간 링크를 다루는 법을 설명합니다.
  • 권한 요청Permission request 13부 화면 단위 패턴 OS 권한을 묻는 순간을 다룹니다. 한 번뿐인 OS 창을 아껴 두는 앞선 설명과, 거절당한 뒤 사용자에게 보여 줄 길을 설명합니다.
  • 그리드CSS Grid · grid layout 1부 뼈대 그리드의 트랙과 거터, 1fr과 auto-fit minmax, 그리고 1fr 칸이 긴 글에 밀려 어긋나는 문제와 이를 푸는 minmax(0,1fr)를 실물과 해부도로 보여 주는 항목입니다.
  • 글자 굵기Font weight 3부 글자 굵기 아홉 단과 실제로 쓰는 세 단, 가짜 굵게와 가변 글꼴을 실물과 해부도로 보여 주는 항목입니다.
  • 글자 위계Typographic hierarchy 3부 글자 크기·굵기·색 세 도구로 읽는 순서를 만드는 법과, 도구를 하나씩 뺐을 때 위계가 어떻게 흐려지는지 보여 주는 항목입니다.

ㄴ

  • 낙관적 UIOptimistic UI 8부 피드백과 상태 낙관적 UI가 무엇인지, 스피너·프로그레스 바와는 어떻게 다른지를 되돌림까지 포함해 실물과 상태, 해부도로 보여 주는 항목입니다.
  • 날짜 범위Date range 10부 데이터 다루는 화면 기간을 고르는 화면에서 자주 쓰는 기간 버튼이 달력보다 빠른 이유와, 끝날을 포함하는지에 따라 기간이 하루 달라지는 문제를 다루는 항목입니다.
  • 날짜 선택기Date picker 4부 조작 부품 달력으로 날짜를 고르는 부품과, 쳐서 넣기·자주 쓰는 날 단추·못 고르는 날을 다루는 방법을 보여 주는 항목입니다.
  • 날짜와 시간 쓰기Writing dates & times 14부 말투 상대 시간과 절대 시간을 각각 언제 쓰는지, 요일과 오전·오후, 기계가 읽는 형식까지 함께 다룹니다.
  • 내보내기Export 10부 데이터 다루는 화면 화면의 자료를 파일로 꺼내는 일을 범위·꼴·건수와 오래 걸릴 때의 처리까지 다루는 항목입니다.
  • 넘침Overflow 1부 뼈대 overflow 네 값의 차이와 말줄임, 그리고 가로 스크롤이 생기는 실제 원인을 실물과 해부도로 보여 주는 항목입니다.

ㄷ

  • 다이얼로그Dialog (modeless · modal) 6부 겹치는 것들 다이얼로그가 무엇인지, 모달과는 어떤 관계인지를 실물과 상태, 해부도로 보여 주는 항목입니다.
  • 다크 모드Dark mode · dark theme 2부 꾸미는 규칙 다크 모드는 색을 뒤집는 일이 아니라 값을 한 벌 더 따로 정하는 일이라는 것을 실물과 해부도로 보여 주는 항목입니다.
  • 대비비Color contrast 12부 접근성 대비비 기준 세 가지(4.5:1, 3:1)와, 같은 색이라도 글자 크기에 따라 판정이 달라지는 모습을 직접 재서 보여 주는 항목입니다.
  • 대소문자Letter case 3부 글자 영어 대소문자의 네 가지 꼴과 각각을 쓰는 자리, 대소문자 구분이 없는 한국어와 섞어 쓸 때 생기는 문제를 보여 주는 항목입니다.
  • 대시보드Dashboard 13부 화면 단위 패턴 지금 괜찮은지 한눈에 판단하는 화면입니다. 지표를 몇 개 둘지, 견줄 값을 어떻게 붙일지, 다음 할 일로 어떻게 이어 줄지 다룹니다.
  • 대체 텍스트Alt text 12부 접근성 그림을 글로 대신하는 대체 텍스트를 다루는 항목입니다. 무엇을 적을지는 '이 그림이 없으면 무엇을 잃나'라는 기준 하나로 정합니다.
  • 데이터 테이블Data table 10부 데이터 다루는 화면 관리 도구의 중심 화면인 데이터 테이블을 정렬과 고정 열, 숫자 정렬부터 상태를 주소에 담는 일까지 다루는 항목입니다.
  • 되돌리기Undo 8부 피드백과 상태 지운 뒤에 되돌릴 기회를 주는 방식을 다룹니다. 되묻기와는 어떻게 다른지, 되돌릴 수 있는 시간은 얼마인지, 어떤 한계가 있는지를 보여 주는 항목입니다.
  • 뒤로가기Back · up navigation 7부 길 안내 화면 안에 두는 뒤로가기 단추를 다루고, 방문 기록을 되돌리는 '뒤로'와 상위 화면으로 가는 '위로'가 어떻게 다른지 보여 주는 항목입니다.
  • 드로어Drawer · Side panel 6부 겹치는 것들 드로어가 무엇인지, 사이드바나 바텀시트, 모달과는 어떻게 다른지를 실물과 상태, 해부도로 보여 주는 항목입니다.
  • 드롭다운 메뉴Dropdown menu 6부 겹치는 것들 단추에 붙어 열리는 동작 목록입니다. 값을 고르는 셀렉트와 어떻게 다른지, 자리가 없을 때 위로 뒤집기, 키보드 조작을 다룹니다.
  • 디자인 리뷰Design review 15부 현장 용어 시안을 두고 의견을 주고받는 디자인 리뷰에서, 단계에 맞는 질문과 고칠 거리가 되는 말투를 보여 주는 항목입니다.
  • 디자인 시스템Design system 15부 현장 용어 디자인 시스템을 이루는 토큰과 부품, 패턴, 문서의 네 겹을 보여 주고, 스타일 가이드나 컴포넌트 라이브러리와 무엇이 다른지 가르는 항목입니다.

ㄹ

  • 라디오 그룹Radio group 4부 조작 부품 라디오 그룹이 무엇인지, 체크박스나 셀렉트와는 어떻게 다른지를 실물과 상태, 해부도로 보여 주는 항목입니다.
  • 라이브 리전Live region 12부 접근성 사용자가 보고 있지 않은 사이에 바뀐 화면 내용을 소리로 알리는 방법과, 리전을 미리 만들어 두어야 하는 이유를 보여 주는 항목입니다.
  • 라이트박스Lightbox 6부 겹치는 것들 그림 하나를 크게 보는 동안 뒤 화면을 덮는 겹침 부품입니다. 닫은 뒤 초점 돌려주기와 주소에 남기기를 다룹니다.
  • 로그인Sign in 13부 화면 단위 패턴 내가 누구인지 증명하는 화면입니다. 오류 문구로 계정이 있는지 흘리지 않는 법, 자동완성, 비밀번호를 잊었을 때 되찾는 길까지 다룹니다.
  • 리스트 아이템List item · row 5부 표시 부품 리스트 아이템을 이루는 세 자리(앞·가운데·뒤)와 말줄임, 카드와의 차이를 실물과 해부도로 보여 주는 항목입니다.
  • 링크와 버튼Link vs button 4부 조작 부품 이동인지 동작인지에 따라 링크와 버튼 태그를 고르는 규칙과, div+onclick으로 만들거나 둘을 서로 바꿔 썼을 때 생기는 문제를 보여 주는 항목입니다.

ㅁ

  • 말줄임Truncation · line clamp 3부 글자 한 줄 말줄임과 여러 줄 line-clamp, 글이 잘렸는지 알아내는 법과 전체를 보여 줄 방법을 다루는 항목입니다.
  • 말투와 높임Voice & tone 14부 말투 화면 문구의 말투를 합쇼체·해요체·반말 가운데 하나로 정하는 방법을 다룹니다. 말투가 섞이면 여러 사람이 따로 쓴 것처럼 보입니다.
  • 메가 메뉴Mega menu 7부 길 안내 분류가 많은 사이트에서 쓰는 큰 드롭다운인 메가 메뉴를, 대각선 문제와 지연으로 해결하는 방법, 키보드 처리까지 함께 다루는 항목입니다.
  • 모달Modal · modal dialog 6부 겹치는 것들 모달이 무엇인지, 다이얼로그·시트·드로어·팝오버와는 어떻게 다른지를 실물과 상태, 해부도로 보여 주는 항목입니다.
  • 모서리Border radius · corner scale 2부 꾸미는 규칙 모서리 둥글기를 단으로 정해 두는 방법과, 겹친 상자의 안쪽 모서리 값을 구하는 공식을 보여 주는 항목입니다.
  • 모션 줄이기Reduced motion 9부 움직임 어지럼증을 피하려고 OS에서 켜는 설정입니다. 움직임을 전부 끄는 것이 아니라 무엇을 끄고 무엇을 남길지 정하는 문제라는 것을 보여 주는 항목입니다.
  • 무엇을 움직이나Cheap vs expensive properties 9부 움직임 transform과 opacity는 배치를 다시 계산하지 않지만 left와 width는 다시 계산합니다. 화면이 버벅이는 원인 대부분이 이 차이에서 나온다는 것을 보여 주는 항목입니다.
  • 무한 스크롤Infinite scroll 7부 길 안내 무한 스크롤이 무엇인지, 페이지네이션·더 보기와는 어떻게 다른지를 실물과 상태, 해부도로 보여 주는 항목입니다.
  • 미디어 오브젝트Media object 5부 표시 부품 그림 하나 옆에 글 한 덩어리를 붙이는 미디어 오브젝트를 flex와 float의 차이, 그림 크기를 지키는 법으로 나눠 보여 주는 항목입니다.

ㅂ

  • 바텀 탭바Tab bar · Bottom navigation 7부 길 안내 바텀 탭바가 무엇인지, 탭·사이드바와는 어떻게 다른지를 실물과 상태, 해부도로 보여 주는 항목입니다.
  • 바텀시트Bottom sheet · Sheet 6부 겹치는 것들 바텀시트가 무엇인지, 모달이나 드로어와는 어떻게 다른지를 실물과 상태, 해부도로 보여 주는 항목입니다.
  • 박스 모델Box model 1부 뼈대 상자 하나를 이루는 네 겹(내용·패딩·테두리·마진)과 box-sizing에 따른 차이를 실물과 해부도로 보여 주는 항목입니다.
  • 배너Banner 6부 겹치는 것들 화면 꼭대기에 자리를 차지하고 계속 남아 있는 알림입니다. 토스트와 어떻게 다른지, 여러 개가 쌓일 때와 닫을 때 무엇을 챙기는지 다룹니다.
  • 배리언트와 프롭Variants & props 15부 현장 용어 같은 부품에 미리 정해 둔 변형을 다루고, 변형의 축을 하나 늘릴 때마다 칸 수가 곱으로 늘어나는 모습을 보여 주는 항목입니다.
  • 배지Badge · notification badge 5부 표시 부품 배지의 갈래(점·숫자·라벨)와 99+ 처리, 칩과의 차이를 실물과 해부도로 보여 주는 항목입니다.
  • 버전 관리Versioning 15부 현장 용어 시안 파일이 바뀌어 온 기록을 다루는 항목입니다. 어느 것이 지금 쓰는 파일인지, 무엇이 왜 바뀌었는지를 남기는 방법을 보여 줍니다.
  • 버튼 문구Button label 14부 말투 누르면 무슨 일이 일어나는지를 버튼 글자만으로 알리는 방법을 다룹니다. 동사를 써서 두세 어절 안에, 조사 없이 적습니다.
  • 버튼 위계Button hierarchy 4부 조작 부품 버튼을 주 · 보조 · 텍스트 · 위험 네 단계로 나누는 규칙과, 진한 버튼을 하나만 두는 이유를 보여 주는 항목입니다.
