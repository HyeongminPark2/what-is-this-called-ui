margin — 바깥 여백 border — 테두리 padding — 안쪽 여백 content — 내용

상자 하나는 네 겹입니다 — 내용 · 안쪽 여백 · 테두리 · 바깥 여백. 겉에서 차지하는 자리는 이 넷을 다 더한 것입니다.
box-sizing을 꺼 보세요. width: 200px이라고 적었는데 상자가 200px이 아닙니다. 기본값(content-box)에서 width 는 내용만의 너비라, 패딩과 테두리가 바깥으로 더 붙습니다. 그래서 거의 모든 프로젝트가 맨 위에 * { box-sizing: border-box } 한 줄을 깔아 둡니다 — 그러면 width 가 테두리까지 포함한 너비가 됩니다.
margin 은 상자 크기에 안 들어갑니다. border-box 를 켜도 바깥 여백은 따로입니다.
